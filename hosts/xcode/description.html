Muse Spark Code (Unofficial) for Xcode

An experimental companion app and source editor extension for Xcode. Open the shared chat panel, ask about or explain a selection, and approve a replacement in the original editor command. Bring your own Muse Code sign-in or Model API key. Installed editor feature parity remains under qualification. Unofficial; not affiliated with or endorsed by Meta.
