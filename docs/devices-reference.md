# Devices feature reference

Generated from `src/shared/featureCatalog.ts` and the English table.

This is an implementation inventory, not an installed command list. Devices
has no registered product command or setting on this integration base.
QR and mDNS have no qualified runtime binding. No board, Git-result or
physical-device support is claimed. All editors share the method port;
remote and headless receivers remain unqualified.

| Id                   | Feature                          | Availability | Contract                                                                                                                                                                                                        |
| -------------------- | -------------------------------- | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| devices.setup        | Devices                          | Unshipped    | Devices is off by default. Pairing and offering work each require an explicit local choice.                                                                                                                     |
| devices.pair         | Pair device                      | Unshipped    | Both devices must confirm. A public invitation alone grants no access.                                                                                                                                          |
| devices.invitation   | Copy public invitation           | Unshipped    | Scan QR or paste text                                                                                                                                                                                           |
| devices.confirmation | Copy confirmation                | Unshipped    | Compare this fingerprint on both screens before confirming.                                                                                                                                                     |
| devices.offer        | Offer lanes                      | Unshipped    | The receiving device must approve the repository mapping, base snapshot and local offer.                                                                                                                        |
| devices.checks       | Offer checks                     | Unshipped    | Only the approved repository snapshot, task brief and result go to this device. Its own model receives the context.                                                                                             |
| devices.caps         | Review and save local offer      | Unshipped    | Caps apply to this offered window only. Narrowing a cap takes effect at the next controlled boundary.                                                                                                           |
| devices.discovery    | Discover on this LAN             | Unshipped    | Enable optional LAN discovery for paired receivers that are offering work. Off by default. Advertises only an opaque service id, port and protocol version; discovery grants no trust.                          |
| devices.address      | Manual address                   | Unshipped    | Check {application} on {interface} at {address}:{port}: receiver offer, route and OS firewall permission. Ask an administrator for scoped access if needed. A timeout does not prove a firewall denial.         |
| devices.approval     | Waiting for approval on {device} | Unshipped    | Approvals and paid consent are requested on the executing device. Open that device to answer; pairing grants no approval.                                                                                       |
| devices.costs        | Payer                            | Unshipped    | Each device keeps its own sign-ins and charges. Its local paid modal asks before the first charge, showing the model price and shared daily budget. No fleet budget or subscription entitlement is transferred. |
| devices.status       | Last observation                 | Unshipped    | Status is the last observation, not proof that work has stopped.                                                                                                                                                |
| devices.pause        | Pause offers                     | Unshipped    | The receiving pool is at capacity. Wait for locally proved retirement; do not reassign uncertain work.                                                                                                          |
| devices.resume       | Resume queue                     | Unshipped    | Reconnect and reconcile before resuming. Uncertain work keeps its occupied slots and spending liability; a timeout or retry cannot release it.                                                                  |
| devices.route        | Offered roles and models         | Unshipped    | Only the approved repository snapshot, task brief and result go to this device. Its own model receives the context.                                                                                             |
| devices.results      | Task branch                      | Unshipped    | Only the approved repository snapshot, task brief and result go to this device. Its own model receives the context.                                                                                             |
| devices.unlink       | Unlink                           | Unshipped    | Unlink removes this pair’s local key and connections. It cannot recall code or stop work already admitted on an offline peer.                                                                                   |
| devices.hosts        | Offer lanes                      | Unshipped    | Pairing requires a qualified local desktop host. This host cannot offer lanes.                                                                                                                                  |
