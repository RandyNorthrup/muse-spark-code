# M104-E — JetBrains native plugin

Rig: Kubuntu, 2026-10-05. Base: `9af924aa`, frozen MHP 1.1.0. Lane owns
`hosts/jetbrains/**`; this record is explicitly required by the rig brief.
No shared contract, runtime, UI, localization, README, CHANGELOG or PLAN file
was changed. No live or paid model call was made.

The plugin is a development artifact. Full M104b conformance and the Supported
claim remain pending the runtime/UI integration, native UI qualification and
the verifier matrix. Passing an injected service or browser bridge test does
not certify the entire feature.

## Implementation

- Gradle 9.1 wrapper with a pinned distribution SHA-256, IntelliJ Platform
  Gradle Plugin 2.19.0, IDEA 2025.3.3, JDK 21, Kotlin 2.2.20, ktlint 1.7.1
  and detekt 1.23.8. No new npm dependency or unchecked cast/suppression.
- Frozen exported JSON Schema validation at stdio, result, panel and browser
  boundaries; duplicate-key, malformed UTF-8 and concatenated-frame refusal.
  Exact exported frame, message and byte budgets; one writer, surface
  fairness, lifecycle barriers, ordered acknowledgements and exact drop counts.
- JCEF support guard; intercepted bundled assets; restrictive CSP; blocked
  remote navigation, popups, context menus and developer-tools shortcuts.
  Real `window.museHost`, JSON-only state, isolated ordered subscriptions,
  surface-specific vocabulary and reload replay. A compatibility adapter
  connects the existing shared renderer until lane D's bridge lands.
- Native workspace, documents, editor, diagnostics, UI, window and surfaces
  groups. Trust/version/dirty/path/range checks precede one undo command.
  Native paid-choice presentation preserves all opaque choice IDs; the
  runtime alone owns consent, prices, budgets and provider capability gates.
- Child credential environment removal, fixed-word stderr diagnostics,
  project disposal, process-tree cleanup and opaque session identity storage.
- Generated chat, Tasks and What's New HTML comes from existing shared
  renderers. The shared React bundle and all 15 language tables are packaged.

## Scope and handoff

Lane B supplies the actual runtime; lane D supplies the final shared UI bridge,
tokens and fallback pages; lane H supplies LSP; lane I owns packaging and the
conformance runner; lane J owns shared documentation and registry status.
The base checkout has no runtime `panel` command, so it cannot produce an
end-to-end conversation receipt yet. Integration must not mark these rows W
until the scenario suite runs against the assembled product.

The frozen `initialize` method is `runtimeToHost`, while its parameters carry
host locale, theme, folders and trust and its result has only protocol version
and capabilities. This implementation follows that direction literally. Lane
0/B must resolve how native host metadata reaches the runtime without changing
the frozen contract silently; no invented notification was added here.

The full IC/IU/PC/WS/GO/CL/RR/RD/AS verifier matrix, Android Studio and remote
split-mode behavior, Starter/Driver JCEF UI tests, snapshots/axe, real-runtime
reload/resume, checkpoint and paid-budget scenarios need qualification in lane
I/J. Same-user process inspection and descendant-spawn races remain residual
risks; process snapshots do not claim an OS job-object guarantee.

Shared README/CHANGELOG/PLAN updates are handed to J: add the development
plugin, its build instructions and the pending qualification status. Do not
publish the ZIP or imply Meta endorsement.
