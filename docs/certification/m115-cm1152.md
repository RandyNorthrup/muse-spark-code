## Delivered scope

The runtime supplies workspace-scoped targets and runs to the existing shared
delivery engine. ACP lends its live sessions and refusal/question callbacks;
background targets retain full backend sessions, publish without switching
an editor, and release them after settlement. CLI target resolution opens the
existing backend managers lazily. `run-due` uses recorded workspace paths,
not the launcher's current folder, and retains the shared durable claim.

A missing Model API paid policy records a refused fire before backend lookup.
The existing paid reservation/settlement port is consumed when supplied;
per-schedule consent and its production installation remain C-M115-3.
The runtime installs no physical or vault adapters: portable UnattendedRun
class/path checks and the backend's classifiers remain mandatory.

Workspace roots are schema-validated, matched to their hashes and updated
under a shared lease. Legacy hash-only entries never invent a folder.
Workspace spellings normalize before holds and request routing. Child turns
cannot replace borrowed parent turn identity. Shutdown aborts idle waits,
stops owned background work and joins polling; borrowed sessions retain their
ACP owner. Concurrent grant-audit appends now share the durable lease.
