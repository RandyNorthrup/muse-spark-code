## Scope

F1b binds F1a's confinement to the session's approval path (D107
§9.2–§9.4, §9.6):

- `askApproval` splits past the hook's allow: a shell ask races
  `askApprovalReviewed` (today's Auto reviewer, then the card) against
  B1's confined run of the line. Anything but a skip runs today's
  path unchanged.
- The race (`raceB1Hold` over `raceApproval`) starts the reviewer as
  today; the reviewer reports each judge fence it starts, and the veto
  polls that one run — B1 starts no judge of its own. A non-veto
  inside the window plus a delivered run, both before the reviewer's
  verdict, wins the skip and cancels the reviewer.
- A skip holds its delivered output for `perform` (served as today's
  shell outcome), emits `judgeFastSkip` with the §9.6 audit and
  resolves the approval as the B1 fast path. Only a well-formed audit
  sends; a malformed one re-runs the reviewer fresh.
- The session's runner opens once (`openInspectSession`: helper
  present, platform confines, non-root, proven workspace, scratch
  made) over the governed bootstrap launcher, and closes with the
  session. The host file does no native I/O of its own.
- The audit journals through the flight recorder (off-schema or
  redacted details omitted, the skip fact kept) and the panel
  currently ignores the skip event; its row is a later lane's.

## Gate-fire drills

Twelve deliberate breaks, each observed to fail and restored
byte-exact (SHA-256 matched after every run). Suites ran directly at
repository default timeouts with `--maxWorkers=3`.

| Broken guard           | Named failing assertion (first failure)                                    |
| ---------------------- | -------------------------------------------------------------------------- |
| `floor-forbid-rule`    | fails settled rules first, even for an innocent line                       |
| `floor-sudo`           | names evaluators, sudo, installs and git                                   |
| `conditions-certified` | stays off everywhere until a receipt and the harm bound land (+3)          |
| `conditions-session`   | admits a certified platform once both land (+1)                            |
| `race-veto-meaning`    | skips on a non-veto and B1 output before the reviewer, and cancels it (+2) |
| `race-second-reviewer` | lets a slow B1 lose to the reviewer                                        |
| `race-window`          | skips on a non-veto and B1 output before the reviewer, and cancels it (+2) |
| `hold-share-fence`     | skips on the shared fence and the delivered run, with the parse            |
| `hold-conditions`      | starts nothing when the conditions fail (+4)                               |
| `audit-class`          | keeps a full audit with its pipeline detail (+3)                           |
| `audit-permille-bound` | refuses audit fields outside their bounds                                  |
| `audit-redactor`       | keeps a full audit with its pipeline detail (+1)                           |

One attempted break did not fire and is recorded as a finding, not a
gap: dropping the reviewer from the race's _first_ wait leaves all 14
race tests green. The first wait's reviewer arm is outcome-preserving
(a reviewer verdict first still wins, through the second wait or the
fallback); it buys latency and veto-abort hygiene. The second wait's
reviewer arm is outcome-determining (`race-second-reviewer` above).

## Hold drill

no race on an uncertified platform; the session probes its
confinement (output bytes on a root-owned rig, the rig's named
`systemFile` fail-closed refusal where the system files are

ABI in range; a fast reviewer waits for nothing. Real helper
binary, governed bootstrap launcher (governor configured as the
extension host configures it), real clock. No judge backend exists
on the rig, so the veto never settles here; the skip path's logic
stays covered by the hold and race suites over the ports.
