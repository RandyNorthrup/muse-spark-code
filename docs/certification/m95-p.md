## What was built

- `modelRef.ts` — `<providerId>/<modelId>` parse/format/validate
  (`meta` reserved, first-slash split so `openrouter/deepseek/…`
  survives), untrusted-label sanitizing (Cc/Cf/Zl/Zp stripped, 120
  chars, no split surrogate pair).
- `capabilities.ts` — tool/vision/reasoning/parallel flags with Zed's
  conservative defaults; agent mode gated on tool calling.
- `priceCard.ts` — price cards in USD/token, D74 source order
  (list, catalogue, user), OpenRouter decimal strings, xAI 1e-10 ticks,
  worst-case reservation (long-context tier, highest upstream),
  settlement from reported `cost`/`cost_in_usd_ticks`, unknown (never
  guessed, never Meta-Standard fallback) on invalid usage.
- `endpointPolicy.ts` — HTTPS-only except loopback; no userinfo/query/
  fragment; private HTTPS asks once; link-local/metadata/unspecified
  refused; mixed answers (incl. `localhost` resolving elsewhere) refused;
  per-request re-verification. Classifier over M69's ranges via stdlib
  `BlockList` (no duplicated parsing logic).
- `credentialRecord.ts` — `{v, auth, origin, …}` zod record; exact-origin
  binding (scheme, name and port — never hosts alone).
- `pkce.ts` — S256 verifier/challenge/`state` (RFC 7636 vector pinned),
  injectable randomness.
- `providersFile.ts` — zod schema of `providers.json` (ids, presets,
  addresses, chosen models, user prices, OpenRouter routing, default
  model, Ollama `numCtx`, private-network flag), read with
  missing/unparseable/invalid distinct, atomic tmp+rename write that
  validates before touching disk.
- `presets.ts` — 18 presets with formats, origins, auth headers, key
  pages/shapes, key tests, models-list specs, quirks as data and the five
  format defaults; `wireCapture` marks the 12 captured (rule 13:
  `listedPresets()` gates the panel); OpenRouter OAuth URLs, token
  exchange, key deep-link, exact D74 attribution, ZDR-default privacy
  choices; Azure resource builder.
- `wizardFlow.ts` — the add-a-provider flow as a pure state machine
  (pick, configure, credential, test, models, privacy-if-OpenRouter,
  suggestions, confirm, done): back/next/skip rules, shape-checked keys,
  paid-test cost consent, `wizardBlockers()` for Save, cancel-keeps-
  nothing by construction, confirm summary names who receives the code.
- `suggest.ts` — `defaultModel` (cheapest tool-calling model fitting the
  32k harness minimum, recommended winning ties, last default noted) and
  `sessionBudget` (history median, else a reference session at the
  default's rates), every value with its reason.
- `scanDiff.ts` — new/removed/repriced (exact, case-sensitive ids),
  "N new models since the last scan" summaries, 24 h staleness.
- `modelFilters.ts` — search (name/label/description/provider),
  every listed facet alone and combined, inclusive ranges, stable sort,
  the four badges (Recommended, Cheapest capable with tool/context/
  price/serverless gates, Largest context, New).
- `src/shared/constants.ts` — the M95 block (`PROVIDERS_*`,
  `PROVIDER_SCAN_STALE_MS`, `HARNESS_MIN_CONTEXT_TOKENS` and the
  endpoint range tables; the two context/scan values are stated
  assumptions, marked as such).

Tests: `test/unit/providers{Model,Policy,Presets,Flow}.test.ts`,
63 tests, each written to fail (acceptance items for this lane).
