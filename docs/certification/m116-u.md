## What U implements

Shared lazy React settings/status/record views, eight default-on switches,
required trimmed reasons before disabling, durable actor/time/reason details,
the immutable rule-nine information row, and a selector limited to one/two
fix rounds. The host alone supplies audit identity/time. Failed persistence
is shown before content and does not replace the last durable state. Late
replies after changing a workspace are ignored; a save reply for a different
team is rejected.

Why-notes render as host rows at use time; user items appear first, followed
by failure notes and then informational progress. Open redesign outcomes
also precede informational progress in status and record. Badges show
the maximum recorded review round per stable module id and finding class.
A changed display key never resets the count. Design status shows the latest
outcome per decision id; `caught` is visibly distinct from `impossible`.
The record preserves all outcome history, finding dispositions, normalized
priorities and explicit lead/owner override reason/time. Rendering grants no
override authority. P remains responsible for lineage inheritance and closure.

CLI/ACP use the same validated, localized presentation. Supported adapter
grammar (technical rule ids, unchanged across languages):

```text
playbook status
playbook record
playbook settings
playbook settings offload off worker maintenance
playbook settings offload on
playbook settings patchRoundsMax 1
```

ACP prefixes these with `/`. Both interfaces reject a missing/blank reason,
rule nine, an increased limit, unknown/trailing arguments and client-supplied
audit metadata. No backend, process, filesystem or credential access exists
in the command adapter. CLI errors go to stderr with exit 1 (unavailable) or
2 (syntax); exception text is never forwarded. ACP refuses extra content
blocks rather than dropping attachments.

The original U implementation used lane-0's `playbook*` keys, read at runtime.
RVM116U adds `playbookSaved` in English and all 14 translated tables for the
polite save announcement. Manifest text is unchanged. Counts/dates/durations
use the Intl helpers. Existing single-model/ordinary ACP prompt behavior
stays covered.
