  required injected configuration ports. An absent registry keeps the section
  hidden; there is no cached-provider substitute with guessed ceilings or
  empty controls.

  injected getters; suggestions use them, clamp to the selected level, and
  refuse invalid budgets. No preset substitutes for a remaining balance and
  no production empty array substitutes for learned history.

  new-conversation orchestrator overrides and Reset to Default, including the
  existing backend/contributor confirmations. The required confirmation port

  local previews call no model. Producing durable learning records, adaptive
  provider ceilings, recovery and running-task settings remain engine responsibilities.
- The remaining Models panel body split: **77.0 KiB / 75 KiB**. Two split
  attempts did not clear it; the common brief requires stopping that path.
  No existing cap was raised. This is an integration/release blocker.
