## Help reference (check:reference)

The M112 certification recorded `check:reference` as absent on its base. On the
merged tree it failed with eleven errors: no runtime default, reader or bounds
for `museSpark.questions.deferAfterSeconds`; no catalogue entry, description or
feature for `museSpark.nextOpenQuestion` and `museSpark.previousOpenQuestion`;
no feature for the setting. The fixes:

- `COMMAND_IDS` and `COMMAND_REFERENCE` carry both commands; the manifest test
  no longer lists them separately.
- `SETTING_DEFAULTS`, `MACHINE_SCOPED_SETTINGS` and `readSettings` (integer
  0–3600) carry the setting; the host still reads only the user's own value.
- The questions feature lists both commands and the setting, links to
  README#questions, is reviewed for VS Code and ACP on both backends, and adds
  a translated detail on the dock, deferral, late answers, navigation and the
  ACP commands.
- `referenceAcp` (14 languages) and the README Help section name the ACP-local
  `/questions` and `/answer`; ACP `/help` lists them after `/help`.
- The gate checks the parser's deadline normalization against the documented
  default, 0, the raised minimum and the maximum.
