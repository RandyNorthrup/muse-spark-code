# REDWINI96: all 214 native Windows case timings

Baseline is the lane's starting commit, measured again with operation IDs so concurrent calls have exact attribution. Final measurements use the same reporter. Every case keeps its default 5 s timeout and three workers. All four files run in two commands, at most three files per command. No case is filtered.

Times are milliseconds. P is time inside measured product entry points; F is fixture time excluding overlapping product time. Concurrent spans are unioned, so neither nested calls nor concurrent writers double-count wall time. Product invoked during fixture construction counts as P. Remaining case time includes assertions, direct verification Git, unwrapped file operations and cleanup. Shared beforeAll hooks are reported separately and are not assigned artificially to individual cases. Very small pure-call timings can round to 0.0.

Git triplets are product / fixture / other (verification or direct setup outside a fixture wrapper). R counts requests to the real-Git adapter, S counts direct Node-to-Git process starts. Git's descendants are included in duration but not separately counted. The baseline adapter's immutable-object cache means R can exceed S; the final adapter has no such cache. Synthetic fake adapter calls do not count as real process starts.
