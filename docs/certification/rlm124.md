## What landed

RVM124 finding 15 (Windows DACL / storage ownership) is closed:

- `src/runtime/connector/storageGuard.ts` (new): the guard. On Windows it
  secures a created path with an explicit owner-only DACL through the
  system root's own PowerShell (fixed script, credential-free
  environment, reset module path) and reads the whole tree's descriptors
  in one spawn through the CLR alone; on POSIX it chmods 0600/0700 owned
  by this user (macOS also refuses extended ACLs via the fixed
  `/bin/ls`). Verification refuses foreign owners, foreign grants (no
  foreign write on the trust anchor), links (symlinks, junctions via the
  reparse bit, hard links via the link count), wrong kinds and escapes
  from the root. Fixed OS scripts run only at startup and at creation,
  never per call; no timeout, retry or other limit of ours stands on
  them. A refusal carries a fixed reason word only, never a path.
- `src/runtime/connector/storageGuardPort.ts` (new): the port (types and
  the `ECONNECTOR_STORAGE` brand guard), safe to import on both sides of
  the bundle boundary.
- `src/runtime/connector/storageGuardBundle.ts` (new): the lazy loader
  in `dist/acp.js` for `dist/connectorStoreGuard.js` (15.1 KiB of a new
  18 KiB budget: 15565 bytes measured + 15%, rounded up).
- `src/runtime/connector/store.ts`: every level the store makes (root,
  grants, audit), every grant temp file, the kill switch, the audit key
  and new audit segments are secured at creation.
- `src/runtime/connector/entry.ts`: serve, grant, resume and status
  verify first and fail closed with the new `storageRefused` sentence
  (English plus all 14 tables); revoke and kill still narrow untrusted
  storage.
- `src/runtime/main.ts`: the `mcp` command loads the guard chunk before
  the connector and fails the command when it cannot load.
- Build and package wiring: `scripts/build.mjs`,
  `scripts/lib/acpBundles.mjs`, `scripts/check-bundle-size.mjs`,
  regenerated `src/shared/lazyBundles.generated.ts` and
  `docs/ide-compatibility/host-api.md` (count-only).
