- Strict capability is optional in ModelCapabilities. The host binds it before
  hashing tools, and the Responses/Chat seams accept authoritative model facts.
  Meta factory supplies explicit named facts for panel and ACP/headless alike.
  Unknown/false overrides a strict-capable preset. Original optional schemas
  restore only synthesized null omission; required/nullable values stay intact.
- Image resize is shared core; only a disposable worker carries pngjs/jpeg-js.
  One active worker, at most 20 queued jobs, 10 MiB input/output, 16M source
  pixels, 256 MiB worker heap and codec allowance, 5s conversion deadline;
  abort terminates before releasing the queue. CRC and bounded inflation reject
  malformed PNG. Encoding retains aspect up to integer rounding, never enlarges.
  No native helper or subprocess dependency. Real PNG/JPEG and valid pixel-limit
  fixtures contain generated test pixels only. GIF/WebP need a codec before
  oversized input can be accepted; explicit refusal preserves safety.
- New exact dependencies: jpeg-js 0.4.4, pngjs 7.0.0, lz-string 1.5.0;
  @types/pngjs 6.0.5 compiler-only. Installed manifests have no peer dependencies;
  scratch-only npm ci audit: zero vulnerabilities. npm info was unavailable
  offline and network calls beyond npm ci were forbidden by shared rules.
  Existing original dependency contents were preserved under temp; fresh
  private root npm ci --ignore-scripts succeeded. Notices regenerated.
- Release plus lanes exceeded three unchanged caps. Lossless browser fallback
  compression, repeated usage markup and Node-only Brotli model text restore
  them. Every model instruction value/key and complete English tree round-trips
  exactly. Literal text keys retain the unmodified sentinel checks; unreferenced
  blocks and decoders still disappear. Chat review text reader follows the
  ReviewPane graph rather than the unrelated new Models graph.
- No startup cap increased. New lazy raster worker measured 58.7 KiB and has a
  75 KiB cap (measured + 15%, rounded to the next 25 KiB), codecs excluded from
  every parent bundle. Worker is packaged in both VSIX and ACP distributions.
- No new user strings, translated keys, escapes, wire fields, or paid calls.
  `featureCatalog.ts` / `gen-reference.mjs` / `check:reference` do not exist on
  this assigned base; the README accurately documents the added developer script.
