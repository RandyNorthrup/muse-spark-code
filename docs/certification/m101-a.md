## Items 2 + 22, 7 and 17

The base already declared recall for a packing session; this lane preserves that
behavior and proves it cannot drift back to waiting for the first placeholder.
`modelFacts(modelId)` reads the selected M95 `ModelCapabilities` and `FormatQuirks`

a BYO reference without injected facts fails closed for packing and diagnostics.

`search` is optional case-sensitive literal text, 1–4,000 characters. `offset`
remains a character position (validated as before) and becomes the inclusive
search start. A successful page starts at the first match, backing off a split
surrogate pair, keeps exact original bytes, and retains the existing page size,
untrusted notice, source tool and fresh markers. A missing match is an explicit
translated failure; no regex is evaluated. Paging without search is unchanged.
The schema changes once, with search shipped alongside the stable declaration.

`packedCallIds` is optional in the internal store schema and keeps the version.
Resume registers retained original outputs, restoring the sticky swap immediately.
Fork/rewind carries only ids surviving the cut. Snapshots prune stale ids even
while packing is off, so a window with packing off preserves useful sticky ids
without resurrecting dropped originals. Legacy files without ids still send their
originals whole twice. The savings ledger remains independent; a corrupt ledger
restarts at zero while valid sticky ids remain packed. Compaction clears the
active pack store as before and does not face a new admission guard.

The detector compares consecutive valid usage reports for the same sent model:
`min(previous input, current input) - cached input > 1024`. A first report or
model switch has no predecessor; formats with empty `cachedUsageFields` remain
silent. The warning contains only the missed token count, localized at use time.
It adds no request, replay entry, transcript row, paid dispatch or budget change.
The request/usage/transcript equality test pins this log-only property.
