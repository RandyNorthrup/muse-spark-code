## Native identity and exited state

Extend **the existing** `native/darwin/Dictation.swift` helper, because its
universal binary, package route and ad-hoc signature already ship. No sibling
binary or dependency is needed. `proc-identity <pid…>` dispatches before the
responsibility relay, audio, microphone or Speech setup. It reads only
`proc_pidinfo(PROC_PIDTBSDINFO)`: pid, pgid, parent, start sec/usec and zombie
state. Start microseconds are serialized as decimal strings with checked
UInt64 arithmetic. Missing processes return null; inaccessible processes
return an explicit unavailable row. Nothing reads names, arguments or
environments. `build.sh` now verifies the signature and this read-only mode.

`MacResourceTreeReader({ helperPath })` binds the production mode; the absolute
path is supplied by the trusted host from its existing installed helper.
The native seam remains additive for other hosts/tests. Full-table probes
batch identities; each final membership check gets a new native inspection.
Native output is strictly schema-validated, including array length, requested
pid correspondence and exited/unavailable distinctions. There is no lstart
fallback. Process samples now carry parent and exited state. Linux Z/X/x and
Darwin Z rows are exited; identities/membership exclude zombies.
