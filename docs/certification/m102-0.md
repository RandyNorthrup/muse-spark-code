## Frozen interfaces

- `usageJournal.ts`: v1 usage and limit entries, open editor/client names,
  fifteen feature kinds, seven certainty values, optional counters, cache-write
  TTL splits, timing/retries, strict nested privacy boundaries, ASCII header
  allow list, and a UTF-8 record cap strictly below 4 KiB. Unknown is absent.
- `usagePage.ts`: inclusive local-day queries; all page/service messages;
  totals, buckets, breakdowns, limits, budgets, model details, attempts and
  savings. Deletion accepts no path or caller-supplied grant; the service's
  confirmation port owns approval. Localisation messages validate table shape.
- `HostBridgeFactory`: explicit host kind chooses VS Code or an injected HTTP,
  JCEF, WebView2 or SWT transport, caches acquisition, and throws when a native
  host has supplied no transport. Concrete native adapters belong to lane U.
- Separate `USAGE_EN` / `USAGE_TEXT`; the loader validates shape, chooses exact
  or primary language, and falls back without logging source errors or content.
