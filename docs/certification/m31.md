# M31 certification — MCP servers and hooks, read-only (PLAN.md M31, D30)

Recorded 2026-09-24.

## What Muse Code reads

- **Docs vs binary.** Meta's docs (dev.meta.ai/docs/muse-code/extending,
  read in the browser) show `mcp_servers` with `transport`. The 1.3.0
  binary's bundled migrate skill writes `mcpServers` with `type`, calls
  `mcp_servers` legacy, and records two faults that make Muse Code drop
  every user MCP server:
  - both keys in one file;
  - `required` beside `mode` on one server.
- **Settings file:** `~/.config/muse/settings.json`, or under
  `XDG_CONFIG_HOME`. Its `hooks` block, `managed_hooks_path` and the
  project's `.muse/hooks.json` are the three hook sources. The docs say
  there is "no active muse hooks command family".
- **Sign-in:** `muse mcp login|logout <server>` signs in to a remote
  server; its help calls the server "a streamable-HTTP entry".

## The change

- **`src/core/backends/musecode/museConfigView.ts`:** a tolerant,
  read-only view of both spellings. It reports:
  - each server's transport and target (a URL cut to scheme and host);
  - required or optional, and on or off;
  - the _names_ of its environment variables and headers;
  - both faults, and missing versus unreadable versus empty.
- **`src/host/commands/museConfigCommands.ts`:** the MCP and hooks picks.
  - The faults are raised as warnings.
  - A remote server offers Sign in and Sign out in a terminal.
  - Each file opens with one click.
  - Restart Muse Code to load changes, and the docs link.
- **`src/host/cliFeatures.ts`:** the VS Code side.
  - The settings path is where `muse serve` reads it.
  - An unreadable file (permissions, a directory) is reported, never shown
    as "no servers".
- **`src/core/shellQuote.ts`:** PowerShell and `/bin/sh` quoting, and the
  fix found on the way.
  - PowerShell treats U+2018 to U+201B as quote characters, and the
    helper's old quoting doubled only `'`.
  - The job helper (M27) and the terminals now use this module.
  - The terminals single-quote the CLI's path and every argument, where
    the path used to sit in double quotes, which PowerShell expands.
- **Palette:** MCP servers… and Hooks… in Customize, on the CLI backend.
  Muse Spark: MCP Servers and Muse Spark: Hooks in the Command Palette.
