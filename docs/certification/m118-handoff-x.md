# M118 lane X — ACP, CLI, TUI, MHP and companion

Use the exact shared contracts in `src/shared/prompts.ts` and
`src/shared/share.ts`, plus menu definitions `promptMenuEntries` and command
ids `PROMPT_COMMAND_IDS` in constants.ts. P and C handoffs describe every
field and storage/privacy rule; these formats are ours, not guessed MSP/ACP
wire methods. Add host bridge messages through their existing zod boundaries.

Use `src/runtime/dataFolder.ts:agentDataFolder` for user scope in every editor
and surface. Its `prompts/<slug>.md` is shared across workspaces; combine with
the current workspace's `.muse/prompts/<slug>.md` via `mergePromptScopes`,
label scopes and preserve identical titles across them. CLI/TUI/ACP/companion
must not create a separate personal library or key it by workspace. Preserve
the imported-untrusted flag; show declared built-in and named variables.
Copy to my prompts creates a portable user copy. No automatic network sync.

MHP/native context menus adopt these entries from `promptMenuEntries`:

| Id                    | Menu               | Command                  | Condition                                                  | Source          |
| --------------------- | ------------------ | ------------------------ | ---------------------------------------------------------- | --------------- |
| prompt.save.message   | transcript/context | museSpark.savePrompt     | museSpark.transcriptRole == user && museSpark.messageIsOwn | userMessage     |
| prompt.save.composer  | composer/context   | museSpark.savePrompt     | museSpark.composerHasText                                  | composer        |
| prompt.save.selection | editor/context     | museSpark.savePrompt     | editorHasSelection                                         | editorSelection |
| prompt.use.composer   | composer/context   | museSpark.useSavedPrompt | museSpark.chatAvailable                                    | library         |

Each adapter interprets the conditions natively, snapshots the exact selected
text and validates its source identity. Own-message Save excludes assistant,
tool/system and foreign message rows. Use saved prompt lists personal prompts
everywhere and current-workspace prompts too. Loading inserts into the active
chat's composer or creates a chat in that workspace, never auto-sends.
`promptLoadSchema` is the validated insert-only request. CLI/headless surfaces
without a composer may return prepared text as an explicit result; they must
not turn Use into model execution. Native menus must cover JetBrains, Visual
Studio, Eclipse, Zed, Xcode, Neovim/Emacs/Sublime and companion as each adapter
lands; do not report implemented parity based only on these contract entries.

Sharing uses inclusive from/to message ids, full/conversation mode, md/html/json,
code blocks on, attachment names on, diffs off, attachment content ids empty.
Only copy/file/browser releases validate in phase one. Reuse C's portable
history projection and privacy adapters; use the same live confidential flag.
For TUI/CLI, show exact scrubbed output and obtain an explicit final confirmation
bound to that preview. Noninteractive commands without confirmation fail;
ordinary execution permissions or remembered paid grants are not sharing
confirmation. ACP uses the host UI's explicit final action through its bridge,
not a new guessed protocol method. Recheck confidentiality immediately before
release, even after a pending editor prompt. No paid or live model calls are
needed to save, list, import, insert or share prompts/chats.
