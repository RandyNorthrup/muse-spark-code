The native peer embeds both unchanged schema exports. Its 1.1 negotiation
matches `selectMhpVersion`: legacy wide offers remain 1.0; explicit offers
bounded through 1.2 select the newest implemented minor. The C# validator now
implements the export's `oneOf` and recursive root references. UTF-8 caps apply
before parsing, including unknown fields and CRLF framing. One FIFO writer
accounts queued and active messages, caps 128 messages / 32 MiB, waits for
actual writes to complete, and never duplicates a frame during drain.
Service admission reserves one response slot and the maximum legal response
bytes before editor side effects. Converting a reservation to the actual
response is atomic; cancellation/failure releases it. Upstream reads pause
when capacity is exhausted and resume on completion. Header shape, surface,
direction, sequence and readiness are checked before the payload vocabulary.
Malformed scalar headers produce fixed typed feedback, with invalid refusal
surface/sequence fields replaced by null so the feedback itself is valid.

`MhpPanelChannel` supplies the authored MHP 1.1 carrier directly. It binds a
fresh opaque surface to a nonempty immutable session/kind; validates shared
payloads, surface kind, receiving direction, readiness and the next sequence;
and emits opened/ready/reloaded/hidden/closed lifecycle frames. Rejections do
not advance a counter. Reload retains UI state and both counters and requests
one replay from the runtime. Closing purges pending writes for that surface,
counts them exactly and logs only `MHP_PANEL_DROPPED` and the count. Completed
writes are excluded; a transport drain never claims the page rendered a frame.

WebView2 injects `window.museHost` before page scripts, with actual shared zod
boundaries. Listeners receive payloads; unsubscribe removes only its listener.
State is JSON-only and copied on read/write. Local backpressure throws before
sequence allocation. Native refusals are typed panelError frames and never
payload callbacks. Private WebView2 controls for subscription, state and
transport drain stay inside the browser/native boundary, are validated on
both sides and never enter MHP. A drain frees transport capacity; it is not a
public delivery acknowledgement. The frozen React entry's compatibility
adapter uses this same real API until lane D selects the embedded bridge.
The previously missing MEF factory is removed. Remote navigation/resources,
subframes, downloads, new windows, permissions and release devtools remain
restricted.

## Native implementation and final headless evidence

The in-process `AsyncPackage` registers a View → Other Windows tool window.
WPF WebView2 embeds `dist/webview`, with installed-language pages and the
existing translated product/error/undo labels. No shared strings, manifest
tables, TypeScript sources, gates or dependencies were modified. The native
SDK/thread analyzers run with warnings as errors, without suppressions.

Implemented host groups: lifecycle, documents, editor, tab and window;
diagnostics is advertised only when the native Error List service is available.
The Running Document Table supplies current buffers, versions, changes, saves
and closes. WPF views supply selection/focus. Agent edits use the validated
plan in one text edit and one undo transaction; any failed native edit cancels
the transaction. The Tab command filter supplies ghost text, invocation,
acceptance and rejection against the captured snapshot/caret. Error List
changes are polled and cleared diagnostics are emitted. Other groups are
withheld and fail explicitly as unsupported.

Runtime startup reuses the unchanged Windows suspended-start job helper.
A private current-user pipe and random nonce authorize resume. The helper's
configuration contains only the sanitized child environment; the runtime
does not inherit the helper configuration. Stderr is drained and cleared
without logging paths/accounts. Closing the helper closes the job, terminating
descendants. Startup has a 30-second initialization deadline, releases partial
resources and reports a fixed error identifier. An empty solution uses its own
scratch directory, rather than the user's profile as a workspace.

The strict JSON reader rejects Json.NET extensions such as comments, single
quotes, unquoted keys, trailing commas and non-JSON numbers. It preserves
paired Unicode escapes and refuses unpaired surrogates rather than silently
normalizing them; this is a stronger refusal than JavaScript JSON parsing.
Patterns use ECMAScript semantics; equivalent JSON number spellings have the
same request id. Outgoing cancellation sends the correlated id and validates
late results without reviving the request. The panel inbox validates before
posting, bounds pending messages and retains a clone until navigation finishes.

test assembly, no filters. TRX: `temp/visualstudio-test-results/m104-f-headless.trx`.
