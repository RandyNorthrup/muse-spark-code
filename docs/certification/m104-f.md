## Contract and integration boundary

The C# host consumes the **unchanged exported MHP v1 JSON Schemas**, embedded
directly from `src/shared/hostApi/mhp-v1.schema.json`. Initialize is
**runtime → host**, as the frozen export specifies. Optional capabilities are
negotiated sparsely; a group must have every method and notification to be
advertised. No credential or password method is introduced.

The export has no React message relay, although research §3.2 describes `ui/*`
messages carrying the panel. Lane F does not invent a wire shape or change
lane 0's contract. `IPanelChannelFactory` / `IPanelChannel` are an explicit
injected boundary for lanes B/D: the provider must supply the authored bridge
bootstrap, zod validation in both directions and the runtime channel. A missing
provider is an explicit error. Full chat and feature qualification remain open
until that binding exists and the experimental-instance scenarios pass.

## Headless foundation

`SchemaContract` validates calls, request results and failures from the
committed export. `MhpPeer` implements NDJSON with strict envelopes, numeric
semver negotiation, direction checks, typed response ids, request replay
refusal, cancellation and pending-request cleanup on EOF. Raw exceptions do
not enter the pipe. `EditPlan` checks dirty buffers, snapshot versions, UTF-16
positions, reversed/overlapping ranges and undo labels before any edit starts.
`AssetPolicy` restricts the embedded browser to the asset origin and sanitizes
the child environment, including every `*_API_KEY` and the named hook
credential variables.

Initial headless run: **21 passed, 0 failed, 0 skipped** with
`dotnet test hosts/visualstudio/Test/MuseSpark.VisualStudio.Test.csproj`.
The tests compile the actual protocol, edit planner and asset policy sources;
fakes are confined to `hosts/visualstudio/Test/`. Native buffer undo and the
actual WPF/WebView2 lifecycle need a VS experimental instance; a headless
edit-plan assertion is not evidence of native undo.

## Native implementation and final headless evidence

The in-process `AsyncPackage` registers a View → Other Windows tool window.
WPF WebView2 embeds `dist/webview`, with installed-language pages and the
existing translated product/error/undo labels. No shared strings, manifest
tables, TypeScript sources, gates or dependencies were modified. The native
SDK/thread analyzers run with warnings as errors, without suppressions.

Implemented host groups: lifecycle, documents, editor, tab and window;
diagnostics is advertised only when the native Error List service is available.
The Running Document Table supplies current buffers, versions, changes, saves
and closes. WPF views supply selection/focus. Agent edits use the validated
plan in one text edit and one undo transaction; any failed native edit cancels
the transaction. The Tab command filter supplies ghost text, invocation,
acceptance and rejection against the captured snapshot/caret. Error List
changes are polled and cleared diagnostics are emitted. Other groups are
withheld and fail explicitly as unsupported.

Runtime startup reuses the unchanged Windows suspended-start job helper.
A private current-user pipe and random nonce authorize resume. The helper's
configuration contains only the sanitized child environment; the runtime
does not inherit the helper configuration. Stderr is drained and cleared
without logging paths/accounts. Closing the helper closes the job, terminating
descendants. Startup has a 30-second initialization deadline, releases partial
resources and reports a fixed error identifier. An empty solution uses its own
scratch directory, rather than the user's profile as a workspace.

The strict JSON reader rejects Json.NET extensions such as comments, single
quotes, unquoted keys, trailing commas and non-JSON numbers. It preserves
paired Unicode escapes and refuses unpaired surrogates rather than silently
normalizing them; this is a stronger refusal than JavaScript JSON parsing.
Patterns use ECMAScript semantics; equivalent JSON number spellings have the
same request id. Outgoing cancellation sends the correlated id and validates
late results without reviving the request. The panel inbox validates before
posting, bounds pending messages and retains a clone until navigation finishes.

Current headless receipt: **33 passed, 0 failed, 0 skipped**, win11, full native
test assembly, no filters. TRX: `temp/visualstudio-test-results/m104-f-headless.trx`.
The runtime fixture performs initialize and documents/list using frozen export
shapes, checks that fixture credentials and the helper configuration are absent
from its environment, creates a real child and proves that shutdown removes it.
Package tests inspect the actual release VSIX, shared React assets, all 15
locales, CSP, native dependency licenses and the exact frozen schema. They
reject production test fixtures. Locale tests exercise German and Brazilian
Portuguese through the installed culture.
