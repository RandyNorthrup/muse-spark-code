  token variables no `*_API_KEY` rule catches: `AWS_BEARER_TOKEN_BEDROCK`,

  with `isProviderCredentialVariable()`; stripped at start, never inherited

  `meta`), `parseStoredProviderSecret()` /
  `formatStoredProviderSecret()` composing lane P's `parseCredentialRecord`
  into the `{v, auth, origin, key}` envelope.
- `exec/providerExec.ts` (new) — user-file-only `resolveProvider()` (takes
  file content plus `resolveHost`; no cwd/repo read, so a workspace
  `providers.json` cannot redirect); per-codec `requestPathFor()` /
  `customRequestPath()` with `isPathAllowed()` / `allowedProviderPaths()`
  (exact paths carry no query; the Gemini family rule bounds the query to
  `?alt=sse`); `isEndpointBindingCurrent()` re-verification;
  `readProviderKey()` with exact-origin binding (mismatch names `{stored}`
  and `{current}`); `pinProviderFetch()` (exact origin, `https:` — `http:`
  only to the pinned loopback — no userinfo/fragment, `redirect: 'error'`);
  `assembleProviderRun()` plus the explicit `ProviderExecRunner` seam.
- `cliArgs.ts` / `exec/execArgs.ts` — `auth set|status|clear --provider`,
  `providers list|add|test|remove` (add: `--preset/--as/--address/--format/`
  `--model/--privacy/--private-ok/--key-stdin`), `exec --provider/--model/`
  `--key-stdin`; `--provider` requires `--backend modelApi`; a bare model
  qualifies to `<provider>/<model>` while a ref must name the provider in
  full (`qualifyProviderModel()`); `NON_SERVE_OPTIONS` keeps serve/login
  free of provider flags.
- `providersCommands.ts` (new) — `providersList/Add/Test/Remove` driving
  lane P's pure `wizardFlow` (draft in memory; writes begun only at `done`; the original
  file-before-secret order is corrected below); free probe is the models-list or provider-key

  so `test` leaves it to the panel.
- `authCommands.ts` — `authSet/Status/ClearProvider()`: stdin-only keys,
  shape-checked, stored bound to the entry origin.
- `exec/keyInput.ts`, `exec/runExec.ts` — `readProviderKeyLine()` (TTY
  refuses `--key-stdin`) and `runWithProvider()` assembly; past argument
  parsing, failures are the run's, not usage (`execProviderNotReady` names
  the missing lanes T/I).
- `backends.ts` — `modelApiReadiness()` ready for a stored provider key or
  a keyless local server.
- `src/acp/agent.ts` — unchanged: BYO refs flow through the existing
  `listModels`/`setModel` model options; proven by the ACP BYO test
  (FakeAgentHost lists Meta + provider refs side by side and selects one).
- Strings: `execProviderModelRequired` plus ~25 `provider*` /

  real translations; the gate-equivalent reports 14 tables, 0 problems
