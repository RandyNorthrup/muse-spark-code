## Bundle and harness decision

The first build deliberately exposed the unchanged aggregate deferred cap:
**82.3/50 KiB**. The schedule UI and schema add roughly 32 KiB beside an
already nearly full legacy cohort. D95 expressly permits a separate page
entry. W owns build entries and budget registration, so V did not edit
`scripts/build.mjs`, budget gates or split rules. The schedule page is
prepared as a separate entry; the conversation uses the small typed
settlement renderer and stays inside its existing caps.

The harness server calls `buildScheduleHarness()` from
`test/harness/build-schedules.mjs` on the first schedule-scene module request.
It builds the production surface source into ignored `temp/m115-v/surface/`
and shares that one build across the scan. `test/harness/schedules.mjs`
supplies fakes only inside `test/**`; a Node import exposes only the scene
registry and never runs the browser fixtures. The scenes need no manual
preparation beyond the regular build. W must replace the test-only module
import with its packaged entry when registering it. This receipt does not
certify the not-yet-bound shipping page's own budget or other editor rows.

The production build passes all unchanged size/split/host-global/notices
checks: extension **438.4/600 KiB**, Model API **446.9/475**, ACP
**818.2/850**, shared English **50.5/125**, webview startup **807.9/900**,
legacy deferred **49.7/50**. No schedule page is eagerly shipped in the
conversation bundle. The final harness passes axe on **64 pages**: list,
editor, timeline and the real conversation's sent/refused/missed rows,
normal width and **320 px**, four themes, in English and the pseudo-locale.
Both 32-page runs have **zero violations, undecided findings, exemptions
or missing results**. Axe could not measure eight scrolled/covered contrast
instances in the English run, and zero in the pseudo run; no exemption was
introduced. Geometry readiness also verifies the narrow document has no
horizontal overflow. The initial narrow receipts were superseded after
visual review caught the harness's inherited fixed 690 px document width.

The independent harness entry measures **450,252 bytes minified**
(**439.7 KiB**) and **137,387 bytes gzip** (**134.2 KiB**), including its own
React and inline browser fallback. This is evidence for W's separate-page
registration, not an existing shipping budget or a request to raise one.
