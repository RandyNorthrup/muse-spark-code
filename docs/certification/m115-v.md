  cards, argument-free audit, Revoke, Pause/Resume, Run now, Remove,
  creator/session attribution, interrupt warning and migration pause reason.
- An editor for all eight trigger kinds, weekday-specific weekly times,
  IANA zone, UTC-labelled absolute date inputs, optional date/count ends,
  capability-qualified targets, five deliveries, four permission modes
  without Bypass, standing tools/commands/workspace paths, paid cap,
  parallel (fresh conversation only), pinning, closed-target and catch-up
  policy. Invalid drafts and unavailable targets/sources do not submit.
- T's five-fire preview through an injected port, formatted in the stored
  zone. E's filtered history count and explicit no-history reason use the
  frozen channel; retained event text never becomes authority. Editing
  hides the old preview. The report action uses RA's injected verified
  picker and remains free; unavailable report support is labelled.
- The host's collision timeline, 24/168-hour ranges and creator marks.
  No second time engine or collision calculation is invented in the UI.
- A versioned, validated request-id channel, rejection on invalid outbound
  input, timeout, synchronous transport failure and close. Rejected CAS
  edits close the old editor and reload; no stale grant is retried with a
  fresh revision. Other-workspace snapshots and another schedule's audit
  are refused.
- `/schedule` routing and the existing `/loop` grammar through an injected
  parser, including its seven-day default end. Creation opens the editor
  for host admission/consent. Palette actions are injected when bound on
  either backend; the existing unbound single-model behavior remains.
- Transcript rows for sent, refused and missed settlements, preserving
  target, delivery, refusal reasons, cost certainty and retained liability.
  `ToolRow` recognizes the existing internal `scheduled_prompt` tool; the
  captured M52 tool shapes retain their rendering.
- Background status, explicit Yes/Not now/Never and removal controls. V
  installs no OS entry and makes no request before the user's choice.
- New English UI text and real translations in all 14 UI tables. No
  manifest key was added without a registered command; W owns manifests.
