## Scope and seams

This baseline lacks M95's providers file, M102's usage journal, M100's
shared device contracts and M104's host API. The files introduced at those
paths contain only lane 0 schema fragments; their owners must compose them
with the real envelopes and dispatch. No file reader, device transport,
journal implementation or bridge dispatcher is invented here.

The account schema is strict and credential-free. Events store opaque ids,
never labels. Device offers contain only provider headroom buckets.
The bridge does not accept machine ids, policy versions or credential fields
from a page. Thresholds retain separate settled/reserved/uncertain usage
through an injected journal-reader interface. These are local contracts,
not guesses about a vendor response.

Lane W owns package.json and CHANGELOG. New manifest keys cannot pass the
existing localization gate until package.json references them; manifest
contributions therefore remain for W. Lane H owns execProtocol: changing
only generated exec JSON would cause drift. The v1 docs stay byte-identical
until H versions its runtime contract and regenerates them together.
