## Incomplete replies (findings 1 and 12; research item 8)

Every function call in an incomplete reply is refused, including a call
marked completed. Each gets an error output in replay and a visible failed
tool row. The turn ends failed with a localized explanation; no additional
model call is dispatched automatically. A later user turn sends every
paired error. This applies to the shared core in all editors and runtimes.

`modelApiCutShort.test.ts` mutates counted M95 capture shapes for Responses
(OpenAI 02), Chat (Groq 02), Anthropic (03), Gemini (02), and Ollama (04).
Each decoder must produce an incomplete response; a valid completed write
inside that envelope must leave memory I/O untouched, show failed rows,
end failed and replay paired errors on the next user turn. Five tests pass.
`modelApiHost.test.ts` also covers mixed completed/uncompleted calls (559
passing tests in the complete file on macmini).

Red drills: restore the completed-item exception in `adoptOutput` (finding
1); suppress the incomplete terminal failure (finding 12). Each mutation
fails the named codec/host regression, then restores the production file
byte-exact by SHA-256. Full hashes and remaining repairs follow below.
