## Integration contract for the lead

1. **J/S/W writer composition.** R's `UsageWriter` structurally matches J's
   `UsageJournal.noteUsage`, `append`, `read` and `flush`; J alone normalizes,
   settles and validates records. Export
   `createUsageWriter({ dataFolder, writerId, isEnabled, now, onWriteError })`
   from `dist/usageService.js`, returning `Promise<UsageWriter>`. Compose J's
   journal with `NodeUsageFs` under `<agentDataFolder>/usage/v1/`. The factory
   passes `onWriteError` through to J so asynchronous write errors and R's
   loader/read errors share the same once-per-process diagnostic. This
   bundle/factory is absent here. Missing or invalid exports throw and the
   recording queue logs fixed words once; calls keep running. The read port
   rejects explicitly. There is no substitute production implementation.
2. **E/W ordinary ACP.** Create the same recorder from the shared data
   folder and `clientInfo.name`; inject it into the process ports
   `MuseCodeHost.usageRecording` and
   `ModelApiBackendManager.usageRecording` before constructing hosts; flush
   during shutdown. Inject the backend and authoritative BYO settlement into
   `new UpdateTranslator(cwd, isReplay, readCost, backend)`. Its safe default
   is Muse Code (no API dollars). VSIX activation and headless `runExec`
   already install the shared recorder. Agent/runtime entry files belong
   to E/W and were not edited.
3. **T transport.** Forward `ResponseAttemptGuard.observe` across the real
   provider transport. `ResponseObservation` holds `headers`, `firstTokenMs`,
   `retries`, `rateLimited` and `retryDelayMs`; native Ollama additionally
   exposes `{totalNs, loadNs, promptEvalNs, evalNs}` through `onDurations`.
   T must supply the captured Gemini RetryInfo delay and forward/convert
   native timing. This checkout has no Gemini retry-body capture; R wrote
   no guessed parser. The frozen journal has only the existing millisecond
   timing fields, so preserving all native timing/TPS needs that composition.
4. **M94 Tab.** `tabLedger.ts` is absent on this base. Its settle tap remains
   blocked on M94; no fake ledger or unused Tab producer was added.
5. **J/M95 price follow-up.** J supplies the one-hour `settleUsageUsd` fix.
   The existing M95 registry's one-hour-cache guard still withholds a legacy
   budget settlement. R preserves both cache-write details and the price
   context, demonstrated by the reviewer test, while leaving the registry
   file outside R ownership unchanged.
6. **L/W final gates and docs.** Finish translations, manifest contributions,
   validation exports, generated host API and bundle/package membership;
   update PLAN/CHANGELOG/public guides; run integrated full quality and all
   editor/service checks. This lane does not claim the usage page, companion
   service, native-editor UI or complete shipped journal is certified.
