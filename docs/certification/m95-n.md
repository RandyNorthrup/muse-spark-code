## Record and integration contract

`resolveModelCapabilities(identity, evidence)` is the only resolver. Each
evidence item is `{ source, fields }`; order is user > capture > models-list >
catalogue > preset regardless of input order. Missing/unknown fields add no
evidence. Known fields are atomic (including arrays and modality payloads),
while scalar policy objects merge per leaf. Every accepted leaf is indexed in
`sources`; yes/no fields additionally carry source inline. Route identity is
registry-owned; evidence may supply the served version.

`nativeCapabilityEvidence` parses native JSON and interprets only retained,
known native fields. List parsers expose the original JSON as `native` or native
rows. A price, model name, text-only call, generic file modality or parameter
syntax does not establish tools, PDF, logprobs, native multiplicity or hosted
search. These stay unknown without specific evidence.

`providers.json` accepts `modelCapabilities[<nativeModel>]` partial families.
Yes requires a correctly typed value; no refuses support. User-file parsing
stamps known fields as user evidence, even if a source was supplied. Existing
custom context/output limits remain required. Limits are positive integers;
reasoning budgets validate their bounds. No credential belongs in this data.

Lane I must pass the configured record to Anthropic/Gemini encoders, to
`AttachmentStore.add`'s fifth argument and `MediaBudget.fit`'s second argument.
It projects `capabilityEffortLevels(record)` through its native-to-UI effort
translation into `ModelOption.effortLevels`; the Modes menu and slash palette
read that projection. Missing projection retains the existing CLI/Meta view;
an explicitly empty projection supplies no effort buttons. Haiku manual
thinking remains available even though its effort list is unsupported.

Direct codec callers use exact model facts from committed captures as fallback;
unknown native models do not inherit adaptive/level thinking. The manual budget
default is 1024, must fit below output allowance, and may be supplied within
record bounds. Gemini 2.5 uses budget; captured 3.5 uses level. These are offline
encoder regressions, not new service receipts for Haiku or Gemini 2.5.

Media checks support, MIME, bytes, image count and PDF pages separately.
An unknown page count refuses a bounded non-Meta PDF. Meta records derive from
current constants and use the exact legacy combined image/page and encoded-size
policies. Backend document permission, text and product transport budgets remain.
