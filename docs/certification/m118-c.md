## Implemented in C's regions

- A single explicit portable projection for full/conversation mode and all
  formats. Full preserves every snapshot kind, including future kinds;
  conversation uses lane 0's two-kind allow-list. Activity, replay data and
  live output/patch handles never enter conversation messages or the share
  document. Shown decisions and resolved diffs have injected display ports,
  rather than invented history wire fields.
- Inclusive ranges are checked against the selected session before filtering.
  Missing, reversed, activity-only and ambiguous endpoints refuse. The existing
  export item/UTF-8 byte limits remain unchanged; empty exports refuse.
- Markdown-parser code-block removal keeps prose/inline code. Attachment names
  and explicitly selected string contents are independent; names/code default
  on, diffs default off, contents default empty. Metadata-only history retains
  names with stable generated ids; unavailable selected contents refuse.
- Every portable string uses M84's existing credential/digest/account scrub,
  current registered-value callbacks and path/user normalization. Workspace
  paths become relative with forward slashes; home/user/other absolute paths
  become markers. POSIX, drive, UNC, local file URIs (including localhost and
  percent encoding), escaped separators and names with spaces are covered.
  Scrubbing runs before and after decoding/normalization; scrubbed id collisions
  have stable mappings across items, range and selected contents.
- Deterministic Markdown, static self-contained HTML and lane 0's share JSON v1.
  Existing M84 resumable JSON and ordinary export behavior remain distinct.
  HTML escapes text, has a restrictive CSP, loads no remote assets, supports
  light/dark system colors and wraps at phone width.
- A host-owned immutable preview, one-use token and matching request protect
  exact release bytes. Preview is memory-only. Confidential or unavailable
  policy refuses before history/preview and immediately before each sink.
  Close/options/session invalidation, late history reads, double clicks,
  changed confidentiality after a save picker, and newly registered secrets
  all refuse. A changed registry requires a new preview, never silently edits
  the bytes the user approved.
- Shared React dialog: mode/format/range/toggles/content selection and only
  copy/file/browser destinations; exact text preview with highlighted markers;
  explicit final confirmation; safe localized errors; workspace mode/format
  preferences through a port. Browser selection uses HTML. The existing Modal
  supplies keyboard/focus behavior. Header exposes Share only with an injected
  live action. All eleven new UI keys have real translations in all 14 tables.
- Real local destination adapters are injected: clipboard, save picker, guarded
  writer and local browser opener. No production fake, secret store, network,
  paid feature, external service, guessed wire frame or new dependency was added.
  The generated host API inventory records the dialog's four new theme variables.
