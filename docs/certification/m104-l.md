be that current supervisor's child; descendant and group discovery extend

individual signal re-reads its PID/birth and refuses a changed identity.

after each query. A sixth synthetic scenario expires that deadline during
the final read and proves no signal is sent; removing the deadline guards
makes it fail. The birth/signal drills preceded this deadline refinement;
each table hash identifies the exact source restored at that drill.

F2: the new lane-local registry module shares checks between broker and Stop.
New directories are 0700 and records 0600; existing metadata must already be
safe, never repaired. It refuses foreign ownership, symlinks, hard links,
wrong permissions, macOS extended ACLs and Windows non-owner/unprotected ACLs.
New Windows paths receive an owner-only protected DACL and every receipt is
validated. Record opens use no-follow where available and compare exact
BigInt native identities and metadata from the checked path and held handle.
Only a verified private namespace is used for worker/recovery/startup/owner
records. Stop filenames use UUIDs so the ACL child sees no bearer in a path.

The original broker fails all six forged-authority regressions: broad root,
broad workspace directory, broad record, symlink root, symlink record and
foreign owner. No real cross-user attack or credential read was performed.
The new real two-frontend factory test initially exposed a disappearing
recovery lock during the async macOS ACL read; missing paths are rechecked
and an absent recovery lock is retried, without admitting unsafe live paths.
That existing factory regression is green again.
