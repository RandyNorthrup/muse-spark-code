# M114-A before capture index

These are observations of base `6c048ed33`, not reviewed regression goldens.
The [audit](../m114-audit.md) maps every component to a scene. The
[manifest](manifest.json) records the exact PNG SHA-256, browser, rendered
component/element inventory and computed styles. The two widths are actual
320/690 px viewports, each 760 px high at scale 1.

The 804 PNGs are archived outside git at
`/home/randy/archive/m114-a-before-17d7` to bound repository size. CI does not
have these images; the links below work only on the archive's rig. The
manifest stays in git and records each scene, theme, width, SHA-256 and byte
size. Set `MUSE_M114_CAPTURES_DIR` to that archive to verify every PNG against
the manifest; without it, the audit test always checks the complete matrix
and explicitly names byte verification as out of tree.

All six themes use their supplied captured colours. Reduced motion and
animation disabling make these still before views. M104 companion/native
surfaces are absent; see the named C handoff in the audit.
