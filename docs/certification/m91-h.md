## Guard drills

Run `python3 docs/certification/m91-h-drills.py` on Kubuntu through rig-run.sh.
The script refuses Windows. It requires green baselines, mutates only named
source files in its disposable rig snapshot, runs whole owned test files,
requires the intended failing test, restores the original bytes in `finally`,
compares SHA-256, and finishes with restored green and localization parity.

| Guard           | Deliberate defect         | Required failure                       |
| --------------- | ------------------------- | -------------------------------------- |
| User scope      | Remove source restriction | Managed HTTP handler refused           |
| Per-type fields | Ignore mixed fields       | Mixed handler rejected                 |
| HTTPS           | Remove scheme restriction | Plain HTTP refused                     |
| Allowlist       | Skip host admission       | Off-list host refused                  |
| Wildcard        | Include bare domain       | Subdomains-only assertion              |
| IP literal      | Skip literal restriction  | Non-loopback literal refused           |
| Network         | Ignore network posture    | Disabled network sends nothing         |
| Redirect        | Accept 3xx                | Redirect refused                       |
| Payload         | Remove input cap          | Oversized input sends nothing          |
| Typed answer    | Keep approval grant       | PermissionRequest cannot grant         |
| Paid switch     | Ignore setting            | Disabled feature starts nothing        |
| Tariff          | Ignore missing price      | Unknown model denied before popup      |
| Consent         | Ignore denied consent     | Denial starts no request               |
| Daily budget    | Skip reservation          | Refusal starts no hook request         |
| MCP approval    | Ignore denial             | No helper dispatch after denial        |
| Read-only agent | Expose all tools          | Only three read tools offered          |
| Side session    | Stop reuse                | One session serves two turns           |
| Side tools      | Ignore tool items         | Completed reply after tool use refused |
| Localization    | Remove translated key     | Parity check rejects missing key       |
