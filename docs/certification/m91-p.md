## Behavior and integration contract

- Cursor takes `sourceEvent` on both builder and parser. Generic hooks remain
  generic; specialized shell/read/MCP hooks get their documented fields. A read
  contract without content is explicitly refused. Invalid permission JSON,
  schema or verdict blocks independent of failClosed; crash/non-2 errors keep
  the source's fail-open default unless failClosed is set. Deny messages,
  prompt `continue:false`, ask and followup continuation survive translation.
- Copilot takes `flavor` on both sides. CLI camelCase and PascalCase inputs stay
  distinct from Local snake_case inputs and nested outputs. PermissionRequest
  uses behavior/message/interrupt, including exit 2's stdout merge and ignored
  stderr. Stop/SubagentStop continuation is preserved. Foreign allow never
  becomes an approval or permission grant.
- Copilot cwd rejects drive-relative and UNC/device inputs before admission.
  Root boundaries and case follow the chosen platform path API. This is lexical
  confinement, not physical containment through links or junctions; the latter
  remains the integration gate. env/environment remain refused.
- Windsurf always uses agent_action_name plus tool_info. Native find/replace
  becomes the documented edits array. Prompt, response, MCP and worktree
  fields retain their envelopes. File/shell post-event contracts have no result
  field and are explicitly refused rather than losing the preview.
- Gemini maps BeforeModel/AfterModel to PreLLMCall/PostLLMCall and keeps their
  veto and observation outputs. Request/response modifications are refused,
  without erasing a simultaneous valid block. Both shells map to
  run_shell_command. BeforeToolSelection returns only allowedToolNames in
  **Gemini names**; the caller compares translated calls at admission and
  intersects with available tools. It must never change the declared tool list.
  NONE restricts to no tools; forced ANY selection is refused. The event name
  in hookSpecificOutput is validated and accepted.
- Kiro file scopes call the existing V8 matcher, with pattern/value caps and
  warning-to-refusal routing. Match misses skip before command execution. The
  scope-only HookDefinition is never dispatched. Only exit 2 blocks among exit
  codes; documented Stop JSON can request continuation. Success context is
  capped at 1,024 characters; task/file triggers cannot change event meaning.
- Post-tool builders carry the runtime's bounded string (`ModelApiHost.ts:7546`,
  `toolHookOutput`) or refuse explicitly. Cursor generic/MCP JSON-result fields
  JSON-encode that string, preserving its bytes on decoding; shell output,
  Gemini tool_response, Kiro tool_response, Local tool_response and Windsurf
  mcp_result carry it directly. CLI toolResult/tool_result wraps it in the
  documented success-result object. Missing previews are never empty success.

The caller supplies available documented metadata and source-specific fields.
No synthetic transcript, account, Cursor version or full model request is
invented. Actual imported-command admission, timeout/crash routing, read-content
availability, physical cwd confinement, approval-card display, admission of
restricted tools and request-byte preservation after wiring remain lane W's
integration evidence. This pure-module record does not certify those flows.
