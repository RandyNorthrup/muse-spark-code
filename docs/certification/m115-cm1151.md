## Hidden delivery composition

The lazy factory accepts host-owned targets/runs/prompt policy and the real
authority store. `ScheduleAgentSession` uses the backends' existing
`sendScheduledTurn`/`steerScheduledTurn` entry points; input and events retain
the previously captured wire shapes. It never treats admission as settlement.
It buffers terminals and user-message promotion during admission, reads the
live grant at each action, fences events inside user input and requires a
paid policy before a Model API send. Cost comes from the injected ledger once;
a failed cost read or lifecycle abort throws and retains S's recovery fence.
It never cancels an unrelated user/queued turn to manufacture shutdown success.
Explicit port forwarders preserve prototype methods and their owning receivers.
The regression first failed with `this.deps.host is not a function`; the
restored adapter completes all three host/options/publication calls.
The post-commit review also found the copied safety callback. Extending the
same regression first observed three owner calls instead of four; forwarding
safety through the original ports fixes the unattended action's receiver.

The production extension supplies no delivery ports and calls no new workspace
hold. The bridge refuses a hold without those ports, even when the setting is
on. The candidate is therefore off, unregistered and unsurfaced. The existing
v2 record-management UI and manual Model API `/loop` flow retain their roles.
README and Help now state that distinction; the Help text has all fourteen
translations. No command, setting, paid call or new visual surface was enabled.
