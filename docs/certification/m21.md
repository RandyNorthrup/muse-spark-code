## Findings recorded during the milestone

- The Windows lookup the audit left unverified, probed: with
  `hostname.exe` copied to `git.exe` in a folder, `execFile('git', …, { cwd:
folder })` ran the planted copy whenever the parent process's
  environment lacked `NoDefaultCurrentDirectoryInExePath` (Node 24.20,
  libuv 1.52.1), and ran it regardless with a `.` entry on `PATH`. This
  session's shell had the variable set, which is why a naive probe shows
  the real git.
- The §8 register row that justified the glob's `new RegExp` ("bounded
  pieces … short relative paths") was wrong; the row is gone with the
  regular expression.
- Muse Code's Manual mode applies edits inside the workspace without an
  approval (M4, live), so the Modes menu's Claude Code wording ("ask for
  approval before making each edit") was false on that backend; the menu
  now words each mode per backend.
- ESLint had started linting `.claude/worktrees/` (the M25 and M26 agents'
  worktrees are whole copies of the repository inside it); `.claude/**` is
  now ignored by ESLint and semgrep as it already was by git and Prettier.
