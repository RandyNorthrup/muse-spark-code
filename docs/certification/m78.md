## Confirmed defects and source draft

- Reviewer consent originally preceded key identity capture; its final guard
  checked only the feature. A changed key could bill an old confirmation to
  a new account. Existing ConfirmedModelRequest now binds the key and model
  before consent and fences the actual HTTP credentials. Current turn,
  mode, trust and policy also fence consent and automated approval.
- Hooks, reviews and approval cards could outlive the policy they judged.
  Fresh policy/mode checks now run after those waits and before dispatch;
  target/source file denials are refreshed after paid/file approval.
- The original standing rules allowed fully covered chained/pipelined
  commands despite milestone acceptance. The bounded lexer is preserved,
  with only one plain command eligible for standing/automated grants.
  Complex syntax and evaluators cannot reach the reviewer or a hook allow.
  Existing explicit user exact-command grants stay exact; Bypass skips
  ordinary nonpaid asks and never skips a forbid or paid-use popup.
- Unknown selected profiles originally allowed all files. Missing,
  overlong, invalid-type and malformed definitions now fail closed. The
  settings reader preserves raw selection for core validation instead of
  replacing an invalid selection with the permissive empty profile.
- External MCP tools, even with a read-only hint, ask under an active profile
  outside Bypass. That hint cannot enforce local file rules; no automatic
  reviewer or session rule can pretend that it does. Builtin file denials
  remain enforced independently of mode.
- Project add_memory requires both note and possible MEMORY.md index paths;
  edit_memory remains note-only. Placement/card awaits recheck trust, mode
  and textual/canonical file-policy names before dispatch. No existence
  shortcut or new memory transaction mechanism was introduced.
- An empty `ALLOW:` reason originally parsed as permission. It now falls
  back to the user. Logs use fixed failure words, not backend error text.
- PaidUsage tracks unknown review requests until a validated per-response
  delta is reported. The row suppresses a zero-dollar claim for wholly
  unreported usage and uses existing localized reported-cost/unknown text.
- No new parser/dependency/framework, guessed wire field, fake conversion,
  automatic permission-mode raise or config/hook execution was added.
  Existing approval subjects retain their approved command/file data.
- README/CHANGELOG, unknown-profile UI notices and command-rule manifest
  guidance were updated, including all 14 translated tables.
