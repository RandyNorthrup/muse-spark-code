## Final service and companion handoff

- `usageService.ts` supplies one checked page protocol over injected journal,
  clock, history setting, live subscription/account limits, read-only budget,
  attempts, price, export/save, confirm and host-action ports. No path or
  caller-supplied approval enters the journal deletion port. Actions are
  serialized, failures are fixed translated codes, and history off retains
  live sources. The `UsageBudgetReadPort.readToday` signature is portable;
  concrete D78 and M94 methods still need their missing source regions.
- Both current and earlier limit snapshots are retained for step charts;
  duplicate provider/source/observation snapshots are collapsed. Budgets use
  admission spend, including uncertain liability, rather than journal totals.
- Model detail distinguishes providers with identical model ids. The optional
  `priceUnpriced` port supplies a view-only total and matching trend, explicitly
  marked priced later; no stored settlement is rewritten. The adapter must
  use lane J's price-card settlement, including cache TTL and context tiers.
- `usageText.ts` renders the same state as plain text or Markdown, with Intl
  formatting, unknown values, separated certainty, plan API equivalents,
  stale/reset/pace status, caps, Stop, today's raise and uncertain liability.
  Markdown labels are escaped. ACP/CLI summaries should query `groupBy: model`
  to include provider and model together.
- `usageServiceEntry.ts` installs both caller language tables before use and
  exports `createUsageFeatures` plus `serveUsageStdio`. Native plugins pass an
  AsyncIterable of complete NDJSON lines and a sendLine port; malformed and
  oversized messages receive checked error frames, never source error text.
- `usageCompanionEntry.ts` exports `startUsageCompanion`; its caller supplies
  the packaged webview directory, the real page HTML, and a service factory.
  It binds only IPv4 loopback on a random port, uses a 256-bit fragment
  capability and constant-time matching, rejects foreign Host/Origin, sends
  no CORS headers, and serves only JS/CSS at the root or under chunks/.
  Realpath rejects symlink escapes. The policy is D82's exact policy.
  Authenticated RPC activity extends the thirty-minute idle timer; rejected
  requests do not. Close is bounded, closes active sockets and is idempotent.

### HTTP bridge contract for lane U / adapter contract for lane E

- URL: `http://127.0.0.1:<random>/#<capability>`. Do not log it. Read the
  fragment, then POST the frozen page-to-service message to `/rpc` with
  `Authorization: Bearer <capability>` and `Content-Type: application/json`.
  The browser supplies its same-origin Origin header. Query tokens are refused.
- The checked reply envelope is `{messages, download?, confirmation?}`.
  `messages` are the frozen service-to-page frames. `download` is
  `{name, mimeType, content}` for the browser's requested download only;
  MIME is application/json, text/csv or text/plain. Validate the envelope in
  the browser bridge without importing the Node server into a browser bundle.
- The first delete request returns the service's fresh confirmation prompt
  `{title, detail, action, cancel, count}`. Display it in the in-page dialog.
  If accepted, repeat the same request with `x-usage-confirm-delete: confirmed`
  and `x-usage-confirm-count: <count>`. The service compares that count with a
  fresh journal read; a stale count returns a new prompt and does not delete.
  The bridge handles this transport handshake before forwarding the eventual
  action result. The page protocol accepts no grant or path.
- The factory's save/confirm ports replace only those two host actions;
  AsyncLocalStorage keeps concurrent exports and confirmations separate.
- VSIX family and remote hosts load the same service through E's adapter.
  JCEF/WebView2/SWT use its NDJSON entry; ACP, terminals, Xcode, Jupyter and
  RStudio use the text or companion route. Native tabs remain M64/M65 work;
  the browser and page bridges remain U, CLI/ACP wiring and stdio input line
  framing remain E. No surface is claimed shipped by this isolated lane.
