## Extraction boundary

`src/core/judge/lint/units.ts` uses explicit injected symbol and syntax
adapters. Declarations use symbols where available; comments, doc comments,
statements and missing symbol providers require syntax extraction. Package
adapters return unknown and are parsed before use, with source-range and
requested-kind checks. TS, TSX, JS, Python, Go, Rust and Java comprise the
declared set. Unsupported languages, missing extractors and empty extraction
each produce visible not-checked rows, never a clean checked result.

Grammar installation, npm/VSIX packaging and dispatcher registration belong
to Z/G and follow their dependency reviews. No grammar or npm dependency is
added here. Injected test adapters live only under test. This boundary is not
a claim that seven real grammars are installed or that upstream extraction
parity has been certified.

The host adapter in `src/host/judge/lint.ts` consumes the existing
`LanguageServiceHost.documentSymbols` result and injected SymbolKind mappings,
walks nested declarations, excludes foreign/virtual locations, and counts
UTF-16/CRLF offsets correctly. It adds no VS Code API calls. Missing kinds
fall back to the injected installed-package syntax adapter.

`cache.ts` hashes the exact request and endpoint/model/source/profile/criteria/
credential-fingerprint/provenance identity. It stores only digests and bounded
outcome/confidence primitives, rejects extras and mismatched counts, copies
mutable inputs/outputs and enforces its injected capacity. There are no raw
wire responses, source strings or credential values in stored entries.

## Evaluation and runtime entry

`rules.ts` builds pass/fail choices and offers skip/abstain only under their
flags, preserving injected criteria and exceptions. Routing respects kind,
include/exclude and the existing bounded glob matcher. `evaluate.ts` batches
rules per unit and callee-context need, preserves complete state, validates
bounded callee and result data, uses the existing judge request/result
schemas, redacts before cache/dispatch, computes entropy confidence locally,
and refuses misaligned model/source/answer/probability data. Partial or unsure
answers stay inconclusive. Cancellation and identity changes after waits
discard results before caching. No separate transport or admission ledger.

`src/runtime/judge/lint.ts` is G's injected entry, not a registered CLI command.
It validates run options, forwards changed-file selection and the run's USD
cap (zero by default), gathers truthful coverage, performs bounded localization
after a fail, and produces text/JSON/SARIF with 0/1/2 exits. Default findings
are advisory. An explicit severity gate may fail an independent result;
Jev/TypeSafe findings stay advisory without independent corroboration.
Incomplete input/extraction/judgment/localization is exit 2. Provider messages
are never echoed; only a fixed reason-code allowlist reaches the formatter.
Coverage counts completed judgments, not merely extracted units. A failed,
abstained or inconclusive judgment leaves the affected kind/region visibly
not checked (`no-answer`), including after a partially completed run.

The host's injected path resolver maps relative report paths to the absolute
paths the existing language services expect. It must be the caller's existing
workspace-authorized resolver, not another file-permission implementation.

Six real criteria are in `skills/judge-lint/standards.md`, with twelve
independently hand-labelled pass/fail fixture files and a local label manifest.
Fake prediction replays prove fixture and evaluator mechanics, not accuracy.
That label manifest deliberately does not impersonate upstream eval format.
