`team.ts` imports it from there; `providerRouting.ts` re-exports it for the
provider code. `providerText` is no longer browser text; no string moved,
shortened or changed, and no budget changed. `browserUiText` now pins that
neither the installed entries nor the browser table hold `providerText`.
Headroom is 344 B; the next addition to the deferred surface text will need
its largest groups (`paletteTips` 4,007 B, `playbookNotes` 2,522 B, `planUi`
1,764 B as JSON) moved to chunks of their own surfaces.
