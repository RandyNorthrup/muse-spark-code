## Installer

`src/host/skills/bundledSkillsInstall.ts` derives `first-party-skills` beside
`vendor/high-quality-projects-skill`, so existing callers need no new port.
Install copies the complete first-party tree inside the existing marked
package copy, then links its skills alongside the vendored skills. The one
marker governs both trees. The source remains unchanged, and no first-party
bytes are added to the pinned vendor tree. First-party ids have the same
precedence as the shared catalogue. User folders and outside links are left
alone. Remove requires the valid marker and only removes links into the
marked copy's two skill roots. An obsolete first-party link is removed on
update. The existing Windows junction / POSIX symlink selection applies.

The installed tag includes the SHA-256 of sorted first-party paths and bytes.
This makes old vendor-only installs, new skills, and topic edits eligible for
the existing Update offer without changing the vendor release. A package
without the first-party root retains the old tag and behavior. Linked roots,
linked skills/entries/topics, invalid ids and missing entries are refused
before installation writes. A failed first-party link install undoes its new
copy and links.

`bundledSkillsInstall.test.ts`: 40 tests passed, including nine new first-party
cases (the link refusal is parameterized over four locations). Real symlinks
and the actual lazy built bundle are used. Cross-platform link types are
checked on Kubuntu; a native Windows/macOS run remains integration evidence.

## Installer red drills

All rows exit 1 from named assertion failures in the whole installer test
file. Every mutation restores the exact pre-drill bytes and compares SHA-256.
The local runner and logs are in gitignored `temp/m103-s-drills.mjs` and
`temp/drill-*.log`; the summarized receipts are `temp/installer-drills.json`.

| Drill           | Mutation                                         | Named test that fails                                                                                                                       |
| --------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| Before fix      | Restore HEAD's vendor-only installer temporarily | copies and marks first-party topics; offers Update; keeps user folders; drops obsolete links; linked first-party cases; rejects invalid ids |
| Copy            | Omit the first-party copy                        | copies and marks first-party topics and exposes them through real Muse Code links                                                           |
| Update identity | Remove the first-party digest from the tag       | offers Update for old installs and changed topics without a new vendor tag                                                                  |
| Root link       | Accept a linked first-party root                 | refuses a linked first-party root before writing                                                                                            |
| Skill link      | Accept a linked skill directory                  | refuses a linked first-party skill before writing                                                                                           |
| Skill id        | Accept an invalid id                             | rejects invalid skill ids and missing entries, and undoes first-party link failures                                                         |
| Entry link      | Accept a linked SKILL.md                         | refuses a linked first-party entry before writing                                                                                           |
| Topic link      | Ignore a linked topic during hashing             | refuses a linked first-party topic before writing                                                                                           |
| Precedence      | Keep duplicate vendor ids                        | drops obsolete first-party links and gives first-party ids precedence over vendor ids                                                       |
| Removal         | Exclude the first-party root from owned links    | keeps user folders and outside links, removes only marked first-party links                                                                 |
