  `judge` before ACP parsing. `ask`, `calibrate`, `report`, `mcp` accept

  score range, source/model metadata and output bytes.

  refuse. The local run cap is not a new shared ledger or permission.

  injected adapter until their command contracts arrive. Missing surfaces

  the advisory `judge` tool with a generated input schema and read-only /
  non-destructive annotations, validates request/result, and reports no

  share one run cap. Stalled output stops queued dispatch; late work after
  transport shutdown is discarded. Errors do not echo private provider,
  method or tool text, including an unknown tool after an earlier refusal.
  Each serialized call tracks its own known tool failure; state reads stay
  explicit across the awaited handler, as required by type-aware lint. Stdout contains MCP only.
- The main judge branch uses the bounded descriptor writers, owns SIGINT /
  SIGTERM cancellation, installs localization within the deadline and
  exits 0 answered, 2 input/configuration, 4 no answer/delivery failure.
  Input, setup and even an injected engine ignoring abort are deadline
  bounded. Judge code is dynamically initialized only for judge commands;
  ordinary ACP commands do not load its schemas. No runtime backend, ACP
  agent or Muse child starts on the judge path.
