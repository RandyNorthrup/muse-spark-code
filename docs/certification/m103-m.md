## Integration seams

Lane I's `MakerHost`, maker constants and `makerProtocol`, lane 0's strings,
and M95's `endpointPolicy` are absent at this base. Lane M does not edit
those lanes' files. Structural interfaces and injected policies are explicit:
`MachineHost`, `MakerSecrets`, `MakerLanPolicy`, `MachinePolicy`,
`SerialMachinePort`, `PrinterTelemetry`, `FluidNcConfigPort`,
`PrusaLinkTransport` and the CAD runner port. The classifier must be the
shared endpoint classifier; only its `private` verdict is admitted. Policy
values come from host constants, never model arguments. Failure/warning
codes are technical identifiers for the surface's translated strings; this
lane adds no user-visible English text or model prompts.

OctoPrint's REST operational flag is never treated as homing. It needs a
certified firmware telemetry reader for sends. Marlin M503 alone cannot
supply travel, temperature limits or homing. FluidNC network ports are not
guessed. PrusaLink has no documented raw G-code or emergency-stop endpoint;
its unsupported operations return explicit errors, rather than silently
calling job cancel as Stop. Lane V/R must surface these capabilities.

## Machine, registry, log and CAD checkpoint

Printer sends run through the host's detached, strict Send once/Reject answer,
UUID, original payload SHA-256, exact registration and device identity, and
both wall-clock and elapsed-time expiry. The guard requires a current
cross-editor lease, trust, hardware switch and interactive host. It persists
intent, re-reads status after that write, and asks again on any fingerprint
change with a bounded retry count. Macro overrides of built-ins are refused.
The registration and HTTP transport each keep private copies. Stop invalidates
pending approvals and bypasses those gates, queued sends and audit failures.
Failed Stops are logged; post-dispatch logging/notification have deadlines.

Moonraker limits intersect config and live axes/velocity; heater caps stay
below firmware maximums. Missing stepper minima fail rather than defaulting.
Klipper's inherited speed is converted from mm/s to mm/min. Transformed
coordinates/speed factors cannot be sent. OctoPrint's firmware state joins its
REST flags; a busy firmware cannot be overridden by an operational REST flag.
Marlin approvals include the terminating newline actually sent. GRBL/FluidNC
remain read-only even if mislabelled. The GRBL reset warning covers startup
motion, including unknown startup slots. Empty slots do not cross newlines.

The registry validates strict secret-free records and serializes writes, with
secret rollback if storage fails. HTTP pins each fresh, all-private DNS answer,
uses the original Host/TLS name, forbids redirects and embedded credentials,
and caps responses. It has no proxy/environment discovery. Response bodies
are redacted before parsing; raw remote errors and headers are not exposed.

The outside-repository JSONL log redacts exact stored keys while retaining
hashes of the original bytes and structural approval outcomes. Binary Stop
bytes have a hex display and a digest of the bytes, not the display text.
The writer serializes entries, uses a separate exclusive writer lock, rejects
symlinks/hard links, sets owner-only permissions, syncs, and enforces entry and
file caps. A full/unwritable log prevents sending; it never prevents Stop.
A stale writer lock fails closed and needs host/operator recovery.

CAD uses user-installed executables through a host-owned runner, fixed argument
arrays, deadlines/cancellation and bounded source/output/artifact reads. STL
checks bytes before copying, triangle counts, finite normals/vertices, strict
ASCII structure and coordinate bounds. File reads reject nonregular files and
use no-follow/nonblocking opens. Output folders are unique per call; a missing
or stale artifact cannot report success. PNGs are bounded and checked for
signature/dimensions, and are returned only while the selected model has vision.
KiCad reports validate severities and include unconnected/parity issues.

## Integration handoff

The shared core is portable Node code with no VS Code imports. Lane W binds
these ports for VS Code/ACP and the other editor controllers. The host owns
trusted-workspace and hardware enablement, interactive/headless posture,
serial/network connection approval and the current lease. Stop uses the
already registered/connected target; it must not create an implicit serial
connection. The host supplies clean-environment, shell-free, process-tree
CAD execution, certified printer telemetry/FluidNC YAML, LAN classification,
secrets, and outside-repository storage. A transport refuses both public and
private DNS retargeting after its first validated address; a new address
requires a new machine instance and fresh status/approval.

The UI must map these technical failures/warnings through lane 0's translated
runtime table, expose physical-stop warnings/unsupported capabilities, and
show the exact framed payload and expiry in its own dialog. No model tool
accepts approval material. PrusaLink remains explicit read-only plus an
unsupported-Stop error requiring the physical switch; do not label job cancel
as emergency Stop. Marlin/OctoPrint cannot send without a certified telemetry
binding. FluidNC needs the host's captured YAML reader. These seams return
errors/unknown state rather than fictitious successful actions.

Lane W owns lazy bundle wiring, README/CHANGELOG/PLAN integration notes, CSP
preview UI and editor/ACP surface acceptance. The lane does not edit those
shared files or claim full M103 certification. All simulators/temporary
processes are stopped; scratch installations remain private and ignored.
