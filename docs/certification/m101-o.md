## Owned changes and capability reads

- Item 6: the public pure `src/core/providers/overflow.ts` facade exposes
  the independently implemented core-context classifier and its event types.
  Error matching reads the selected preset's format; usage heuristics, pressure
  and admission read `ModelRow.contextTokens`. HTTP 429 and rate-limit
  message/code/kind text cannot classify as overflow. A completed reply above
  the window or an empty reply at 99% is classified, its usage counted once,
  and its tool calls remain unexecuted.
- F4 window: `ModelApiHostDeps.contextModel(modelId)` supplies the row and
  format. Ordinary sends check the whole projected canonical input before
  pre-model hooks and again after key retrieval on each actual attempt. The
  reserve is a quarter of small windows, capped at the existing 32,768-token
  Muse output allowance. Pressure and model-list limits use the row, including
  pressure after compaction. The guard exempts manual compaction. Only a bare
  Muse-prefixed model retains Meta's documented 1,048,576-token fallback; a
  BYO provider with that prefix cannot inherit it.
- Item 13 budget: `readFileCharacterBudget` lives beside `read_file` in
  `tools.ts`; a known window gives at most half its size in characters, up
  to the unchanged 64,000-character Muse cap. Both model and visible output
  use that budget. Offsets, paths, editing, incomplete calls and packing stay
  in lane T's ownership.
- The host emits `onContextOverflow` with session, turn, sent model, kind
  and window; it emits the ordinary `turnCompleted` with
  `errorKind: context_overflow` and the runtime-localized recovery message.
  This lane makes no automatic retry or extra billed call; C2 owns recovery
  through the shared D78 gate.

The UTF-8 admission estimate reuses the existing conservative budget estimator
(one token per serialized byte). It can refuse before a provider's true token
window is full, particularly for media or dense Unicode. It does not add a
counting request. Provider-specific output caps remain P2's responsibility.

The implementation is in `src/core/context/overflow.ts`, consumed only by
`dist/modelApi.js` in the final metafiles. The provider facade's public
types are consumed as erased imports. The split gate initially rejected
unlisted new files in the backend directory; placing the pure context logic
in core context and keeping the tiny read helper beside its caller restores
the existing split contract without changing its manifest or exemptions.
