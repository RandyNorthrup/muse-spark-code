# M33–M35 certification — the paid features: web search, images, Muse Voice (PLAN.md M33–M35, D30, D34)

Recorded 2026-09-25.

The owner said "do it" (2026-09-25) to the three paid Model API features
under D30's rule: opt in and loud, so the user never spends without
knowing. The three milestones share their machinery and go out in one pull
request, so the gate runs once.

## What Meta's documentation says

A research agent read Meta's public pages (no sign-in, no key, no call)
and saved them to the session's scratchpad. The facts the code relies on
are in PLAN.md D34, each with the page it came from. The two that shaped
the most code:

- **Muse Voice is not OpenAI-shaped.** There is no `/v1/audio/transcriptions`:
  the realtime endpoint is a WebSocket whose first text frame carries the
  key (Meta ignores the Authorization header there), followed by binary PCM.
  So Node's own WebSocket works without custom headers, and no third-party
  code is needed.
- **Nothing counts searches.** The response's usage has token counts only,
  and Meta does not say how a call with several queries is billed. The
  tally counts each query and errs high.

## How the work was split

The lead built everything in TypeScript and the Windows helper. One agent
wrote the Swift helper's `--capture` mode, in `native/darwin/Dictation.swift`
alone, and built it on the owner's Mac mini (universal binary, no warnings).
Seven agents translated the 41 new strings and 3 setting descriptions, two
languages each, each editing only its own locale files; the lead added the
three allowlist entries ("Muse Voice" everywhere; French "Image" and
"Sources", which are French words too).

The Mac build agent's smoke run, over SSH, left macOS permission prompts
queued on the Mac mini's screen, because the helper relaunches itself as its
own responsible app, which can prompt. The owner was told to decline them;
the binary they name is deleted.

## What was checked by hand

- **The Windows recorder, for real:** `capture.ps1` compiled its C# type and
  was ready in about 0.4 s; a one-second press on this PC's default
  microphone returned 27,768 bytes (0.87 s of 16 kHz audio, the rest lost to
  the driver's start). Bytes were counted, never kept or sent.
- **The protocol, without a microphone:** a synthesised WAV replayed through
  `-InputWav` came back byte for byte (also a unit test on Windows).
- **The screens** (harness renders, viewed): the paid badge, a paid search
  row with the reply's sources, the tally in Account & usage, the palette's
  three toggles, the image card with its prompt and price, and the
  microphone on Muse Voice.

Not done: a live call. Web search and images need a Model API key, which the
owner does not hold since 2026-09-22; Muse Voice needs a key and a voice.
Each is a fraction of a cent, and each waits for the owner.

Two drills from the owner's rule need no code of their own: the settings
are machine-scoped (the manifest test ties `MACHINE_SCOPED_SETTINGS` to

all fourteen tables had the new strings.

## What the gates found

- **Duplication (jscpd, threshold 0):** six copies, now shared code: the
  Windows and macOS helper lookups of the two locators, the child-exit report
  of the two spawns, and four test fixtures.
- **Accessibility (axe, WCAG 2.2 AA):** the reply's source list put short
  links such as "vite.dev" under the 24 px target size in all four themes
  (2.5.8 exempts links in a sentence, not a list). Each link is now a 24 px
  target.
