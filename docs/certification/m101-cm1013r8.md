## Item 2 — canonicalDigestText folded a lone CR

`canonicalDigestText` (`src/core/eval/mechanisms.ts`) folded CRLF
pairs and any lone CR to LF. A lone CR inside a string or template
literal is program text: folding it lets two different programs hash
equal. Only the CRLF pair folds now (what a checkout can add and Git
normalises); a lone CR hashes as it is; LF is unchanged. The doc
comment states the R8 reason.

`test/unit/eval/evalFrozen.test.ts` ("hashes one value for a CRLF
tree and an LF tree, but not for a lone carriage return") asserts
`canonicalDigestText('a\rb')` is `'a\rb'` and not `'a\nb'`, and that
`frozenSourceDigests` gives different digests for `'a\rb'` vs
`'a\nb'` sources while CRLF and LF checkouts of the same tree still
agree.
