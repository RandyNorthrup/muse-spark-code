The exact lane-0 disk contract is `<agentDataFolder>/prompts/<slug>.md` and
`.muse/prompts/<slug>.md`. IDs determine opaque SHA-256 filenames; metadata
and exact Markdown bodies use lane 0's JSON-subset front matter. User storage
is independent of workspace and editor. No credential is saved into a prompt
by these adapters. The editor states that prompt files are plain text and
must not contain passwords or keys.

The store rejects damaged/conflicting/wrong-scope files, static file and
directory symlinks, invalid UTF-8 and oversized input, and retains damaged
files. Per-scope caps are 200 prompts, 80 title characters, 10,000 body
characters and 128 KiB per portable file, including metadata. Exclusive locks,
checked file identities, synced temporary files and atomic rename protect
ordinary writes. Imported status cannot be upgraded by edits, copies or sync.
Sync validates the entire mirror before writing, accepts only unique user
IDs, takes the newest edit, and conservatively preserves untrusted status.

Imports remain host-owned in memory, single-use and generation-fenced;
public preview mutation cannot change accepted content. A file/link/gist read
happens only after Import. Remote reads are refused in confidential or unknown
policy. Import acceptance only stores text. Use reviews each variable and
the complete expansion; cancelled review and overlarge expansion insert
nothing. Substitutions are literal and do not recursively expand user input.

Shares scrub body, title, tags and exported identity; a portable safe export
round-trips metadata and exact body deterministically. Confidential/unknown
policy refuses every release. Neither clipboard nor file is touched before
the final confirmation. Policy and live registered values are checked again
at release; changed scrubbed bytes require a new preview. Native file export
checks again after its save dialog. Registered values stay in memory and are
cleared after the share operation.

Storage limitations: a killed writer may leave `.write-lock`; files are
retained and further mutation refuses until an owner reviews and removes the
stale lock. Sync is a newest-edit mirror, not a tombstone/deletion protocol
or multi-machine atomic transaction. Portable Node filesystem operations
cannot protect against a local same-user actor swapping an ancestor after
the final identity check. Privacy recognizes known/registered shapes and
known roots; unknown secret/path shapes may survive, so the exact preview
remains the user's final check. None of these limits authorizes automatic
share, send or spending.
