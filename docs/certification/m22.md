## Findings recorded during the milestone

- The SDK's `spawnMspConnection` takes no `windowsHide` and spawns without
  it; no console window appears because the extension host's own console
  is hidden and inherited. Every spawn the extension makes passes it.
- On Windows a background child started by a test command held the test's
  temporary folder open after the command returned, so its removal failed
  with `EBUSY`; the drill now starts that child in another folder.
- An earlier run showed why "the pipes closed" is the wrong end of a
  command: with `ping` left running by `Start-Process -NoNewWindow`, the old
  runner waited the full 30 seconds.
