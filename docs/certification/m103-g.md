## Limits and handoff

This is a command guard, not an OS device sandbox. A program the model
writes can reach a device after the user permits its execution. Shell
encoding/indirection and arbitrary aliases cannot all be classified.
Known physical MCP namespaces are guarded; a host must inject its own
physical marking for arbitrary aliases, never trust MCP readOnlyHint.

Muse Code Bypass emits no approval event. Start/change is refused where
the extension sees the mode; commands already executed by the CLI cannot
be undone. Muse Code Auto skips some commands without an approval event;
lane E's required live capture and possible Manual cap remain open.
Muse Code file tools can edit a CIRCUITPY/config workspace without an
approval; detection/switch lanes must provide the stated residual notice.

README, SECURITY, CHANGELOG and PLAN are lane W's files. Permission to add
minimal standalone-guard sections was requested; they remain untouched
until the owner resolves this conflict. No push, merge or rebase occurred.
