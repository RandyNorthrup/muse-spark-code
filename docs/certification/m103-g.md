## Limits and handoff

This is a command guard, not an OS device sandbox. A program the model
writes can reach a device after the user permits its execution. Shell
encoding/indirection and arbitrary aliases cannot all be classified.
Known physical MCP namespaces are guarded; a host must inject its own
physical marking for arbitrary aliases, never trust MCP readOnlyHint.

Muse Code Bypass emits no approval event. Start/change is refused where
the extension sees the mode; commands already executed by the CLI cannot
be undone. Muse Code Auto skips some commands without an approval event;
lane E's required live capture and possible Manual cap remain open.
Muse Code file tools can edit a CIRCUITPY/config workspace without an
approval; detection/switch lanes must provide the stated residual notice.

README, SECURITY, CHANGELOG and PLAN are lane W's files. Permission to add
minimal standalone-guard sections was requested; they remain untouched
until the owner resolves this conflict. No push, merge or rebase occurred.

## REDM103G redesign (2026-10-05)

Base: `e981b642045eec8c904b76f29a04091b6aa65bad`, branch `m103/guard`.
Read REDM103G, common.md, the full RVM103G report, AGENTS.md and PLAN D83.
The redesign is recorded in D83 before implementation. No dependency,
credential access, live model request or physical device operation was added.
All UI behavior uses the existing accessible approval/mode surfaces; no
layout, CSS, native modal or new host-only editor feature is claimed.

Reuse: the captured MSP subjects/stages and decision-failure fixtures, the
permission engine, host approval flow, ACP translation, worktree candidate
host and the single secret detector/redactor. The new conservative literal
parser is required because M78's command-rule lexer does not represent
redirection direction or cmd. Unknown evaluation is retained, not allowed.
The first-use bundle keeps the parser and approval state out of activation.
Its same-build secret-reader port avoids duplicating the original detector;
missing readers refuse. Private host symbols carry hardware classification
through host-side card copies, never through a guessed MSP field or a
translated-title decision. The rule table's unused IDs were removed, then
its private rows compacted to typed tuples without changing regexes/classes.
