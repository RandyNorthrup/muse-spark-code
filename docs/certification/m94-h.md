## Integration on `feature/m94-tab` (lanes C and L wired, 2026-10-04)

Recorded after the merges of P, C, L, H and U (`215f4004`). The lead's brief:
wire H's seams to the real C and L modules and adapt anything that assumed
Tab off by default to the owner's ask-once ruling.

### What changed

- **Seams removed.** `unwiredEngine`, `unwiredSpend` and `unwiredConsent` are
  gone. The bundle builds the engine and the spend gate itself
  (`createTabServices` in `tabEntry.ts`, a sixth entry `isTabBundle` checks)
  from what activation hands it: the key client's stream, the ledger folder
  (`TAB_LEDGER_DIR`, global storage's `tab-spend`) and a per-window id.
  Activation keeps the question (`paid.consent.allows({ feature: 'tab', … })`)
  and the tally (`PaidUsage.addTabRequest` / `addTabUsage`).
- **Engine** (`src/core/tab/tabEngine.ts`, new, pure): the typing-through
  cache first, then the scheduler (Automatic debounced, Invoke at once); a
  replaced or cancelled waiting trigger is answered with no suggestion and
  zero usage. The request is lane C's body; the client gets one HTTP attempt
  (`retriesUsed: MODEL_API_MAX_RETRIES`), since the reservation prices one
  (RVM94LC's integration note). The suggestion is published as soon as a
  complete tag pair has streamed; `usage` settles when the stream ends and
  rejects when it reports none (the reservation then stands, M82).
- **Spend gate** (`src/host/tab/tabSpendGate.ts`, new) over lane L's ledger:
  `reserve` returns a `TabReservation` carrying its own worst case, and
  `settle(reservation, usage)` replaces exactly that one. The status bar's
  total is the last one the ledger answered, refreshed after each change.
- **Provider:** the window is lane C's `contextWindow` (anchored prefix,
  bounded suffix), redacted before pricing; the worst case is priced on the
  instructions plus the one user message actually sent (was: the whole
  file). A token cancelled before sending releases its reservation (was: kept
  with nothing to settle it). The snapshot carries the model, the cursor
  line's text before the cursor (lane C's whitespace normalisation), the line
  above, the lines below and the token's state for the debounce.
- **Ask once, no turn-on modal (owner 2026-10-04).** `PaidFeatureGate` gains
  `asksOnFirstUse` (`tab` in `createPaidFeatures`): the gate's review and
  palette Turn on never show Tab's price confirmation; the acceptance follows
  the setting silently, so turning Tab off still voids its "always" grants.
  The first request's D48 question (lane L's wording: rates, budget, training
  note) is the only consent, and nothing is sent before it. Lane L's two
  paidHost tests that drove the old turn-on modal now assert this flow.
- **Pre-existing test faults fixed.** `tabBundle.test.ts` failed 7 of its
  tests at the H merge (`c484309f`, slot m94int-hbase): the activation harness
  returned a spread copy, so `settingOn` never reached `isTabSettingOn`, and
  the entry test left `registerInlineCompletionItemProvider` returning
  undefined. `test/integration/tab.test.ts` never called `tab.refresh()`, so
  no provider registered; it now does, and runs the real engine and ledger
  with a faked key-client stream.

## Review fixes (RVM94HU, 2026-10-04/05)

Codex's review of lanes H and U, fixed on `feature/m94-tab` after the
integration and the RVM94LC fixes. Findings 3, 4, 16, 18, 19, 20 and 22 were
already closed by the integration commit `f4baea19` (see above); their
regressions and drills are listed there, and 3 and 16 gained provider
regressions here. Green runs: provider 48/48 (`m94hu-g1`), bundle and status
45/45 (`m94hu-g2`, then `m94hu-g3` with the engine and paidHost, 60/60), App
129/129 (`m94hu-g6`), and the whole `tab*`/`paid*`/privateFiles/manifest/
settings/UsageDialog sweep `m94sb-1…7` (378 tests, kubuntu and macmini).

### Fixes

- **1 (P1) stale ignore verdict.** `TabIgnoreCache` keeps a generation the
  watcher moves; an answer begun before a change is asked again, never
  cached (three outdated answers in a row refuse the read).
- **2 (P1) checks after the waits.** After the question and the reservation,
  every state check runs again (snooze, setting, key, trust, folders,
  language, Copilot; the path again if the ignore files changed); a refusal
  releases the reservation. A disposed provider sends and reports nothing.
- **3 (P1) the token reaches the engine.** The snapshot's `isCancelled`
  reads the editor token (and disposal) when the engine's debounce or slot
  wait ends.
- **5 (P2) full accept after its change.** A change inserting the whole
  suggestion waits for the item's command, which reports it once, exactly.
- **6 (P2) partial accepts advance.** The tracked position moves past each
  accepted part (lines and columns).
- **7 (P2) startup.** `extension.ts` calls `tab.refresh()` at activation;
  with Tab on, the shim registers the one provider and sets `museSpark.tabOn`
  at once, and its provider waits for the deferred secret read and loads
  dist/tab.js on the first request. The bundle's provider no longer
  registers itself (`TabProviderHandle.provider`).
- **8 (P2) context cleared.** Teardown and the status item's dispose both set
  `museSpark.tabOn` false.
- **9 (P2) snooze redraw.** The palette's Snooze redraws the bar; a timed
  snooze redraws each minute, so its end shows without another event.
- **10 (P1) cursorignore always.** `.cursorignore`/`.continueignore` are
  checked whatever git's own answer.
- **11 (P1) nested ignore files.** With git blind, an ignore file in the
  file's folder or any folder above it up to the root refuses the read.
- **12 (P1) links.** `realPath` (`canonicalPath` in production) resolves the
  file and its folder; a target outside the folder, a private or protected
  target, or a path that does not resolve is never read.
- **13 (P1) nested folders.** The path checked, given to git and shown to
  the model is relative to the innermost folder holding the file; every
  folder is served (no first-folder rule).
- **14 (P1) files.exclude.** Matched with the extension's own glob compiler
  (`**/*.ts` excludes a root `file.ts`), against the file and each folder
  above it; `{ "when": "$(basename).ext" }` conditions are kept and
  evaluated against the sibling.
- **15 (P1) secrets at the cursor.** The whole text is redacted at the
  cursor's split before the window is cut; a secret spanning the cursor
  (the halves redact differently from the whole) refuses the request
  (`secret-at-cursor`), and the window's edges can no longer cut a secret.
- **16 (P1) everything sent is priced.** The provider regression now pins
  the reservation's input bytes to the instructions plus the whole message.
- **17 (P2) no read before the path.** Name, link, `files.exclude` and
  ignore checks run before `getText`.
- **21 (P2) Account & usage.** A new host message `openUsage` (protocol,
  `usageRequests` in the reducer, an App effect) opens the dialog in the
  conversation in view, or in the sidebar it brings forward.
- **26 (P3) tooltip.** The snoozed tooltip is the filled sentence.
