## Consumer contract

`src/shared/team.ts` has a separate scheduler region. M96 lane 0 can add its
agents/pools/ledger region without changing these schemas. Export names are
camelCase schemas with inferred PascalCase types. `teamSchedulerFieldsSchema`
composes into delegate's task schema; an absent dependency `on` must be
resolved by the board from the dependency's workspace mode. Scheduler fields
use the tool's snake_case; durable board/event records use camelCase.

- The board binds workspace/window instance ids, paused state, task ids and
  attempt histories. Its cap is 64 **open** tasks; retained terminal history
  has a separate bounded envelope. DAG validation, transitions, stale-event
  mutation refusal, charging and reload pause are lane S behavior.
- Attempts are numbered from 1 and sequential within each task. Cancel is
  not proof: retirement requires terminal time and either Windows job/Linux
  cgroup proof or a distinct user decision. Child exit, group shutdown, hints
  and remote endpoint liveness are not proof values.
- Leases and events carry attempt identities. Late usage remains attributable
  to its original attempt; the schema does not decide whether to apply events.
- Metrics carry raw numerators/counts with reported and estimated usage apart;
  absent time samples are null, so absence cannot masquerade as zero.
- Runners contain environment **names**, never values. The filter rejects
  `*_API_KEY`, the hooks' credential names and the headless child deny list,
  including SSH agent and GitHub token names. Destinations are SSH aliases or
  user@host, never command options or shell fragments. Runtime trust, SSH
  options and remote slot ownership remain lane O's duties.
- New scheduler guidance is fixed English in `TEAM_MODEL_TEXT`; the base's
  charter/roster block has not landed yet and can expand this object.
