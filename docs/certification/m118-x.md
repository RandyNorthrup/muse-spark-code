## Delivered and limits

- `src/acp/sharing.ts` and the command region in `agent.ts`: ACP's
  `/share chat` and `/prompt save|list|use|share`, announcements through existing
  SDK command updates, exact text-only command admission, reserved skill names,
  current-session identity, and no model turn in any mode, Bypass included.
  Preparation stays busy through confirmation. Cancel/close/reload/backend exit
  invalidates late final actions before any release/insert.
- `src/runtime/sharing/args.ts`, `commands.ts`, and the injected parser region
  in `cliArgs.ts`: strict action-specific standalone/slash syntax; portable
  personal/current-workspace storage ports; explicit scope/id selection and
  search/tags; exact saved text, variable declarations and untrusted review;
  validated insert-only prepared text. Use without a composer returns text,
  never submits it. Damaged/wrong-scope/duplicate-id reads and P's cap/write
  failures propagate without removal or a fake success.
- Exact-preview final confirmation: schema-validated renderer output and
  redaction offsets; target/mode/options/range/time association; copies isolate
  renderer/UI mutations. CLI confirmation and output paths are snapshotted
  before awaiting anything. A digest binds request, content, time, cwd and path.
  Unconfirmed/noninteractive commands return a nonzero cancellation result.
  Live confidentiality must be exactly false at render, preview and sink;
  permissions/paid grants/stale/changed actions never authorize sharing.
- `src/runtime/sharing/bridge.ts`: lane 0's native Save/Use menu ids, runtime
  localized labels, strict native context/invocation boundaries, current exact
  text/identity and own-message checks, and fresh insert-only composer admission
  after a pending picker. Fakes prove the shared adapter, not native parity.
- `m118-x-handoff.md`: named P/C, runtime/main, MHP/native/companion, TUI,
  feature-catalog/help, docs and lazy-bundle bindings. Those dependencies are
  absent or owned by other lanes and are not replaced by production fakes.

## Findings caught while building the controls

- ACP notification completion acknowledges sending, not the remote handler.
  The first cancellation fixture resolved its final answer too early. It now
  waits until the originating command is inactive before resolving the answer;
  cancel/close/reload/exit all pass and release nothing.
- A body delimiter found with a whitespace regex could split inside a quoted
  title. The parser recognizes an unquoted standalone `--` token instead and
  preserves body bytes/trailing whitespace. A new CRLF delimiter test failed
  with an unwanted leading LF; recognizing the CRLF pair fixes it.
- A path read again after preview could redirect a confirmed file. Snapshot it
  before awaiting the UI. A mutating command-object test and red drill fire.
- Final review's renderer mutation and CLI-confirmation mutation tests both
  failed: the first broadened conversation to full, the second supplied a digest
  after preview without a final action. Passing the renderer a copy and
  snapshotting the original confirmation fix both; each has a red drill.
- An imported prompt without variables still needs review; prepared replies are
  parsed as string/undefined before insertion. Trusted prompts that need inputs
  report their variables rather than falsely labelling them imported/untrusted.
- The first chat-action drill stayed green because its invalid fixture also
  lacked a session id. An independent invalid-action fixture with a valid id now
  fails when the action guard is removed. The final control set records the
  observed failures, with that initial gap disclosed here.
