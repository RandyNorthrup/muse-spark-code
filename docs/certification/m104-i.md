assigned. Build/conformance have no channel credentials. Sign/publish use the
existing tag-only `marketplace` environment, expose only the host's supplied
credentials to its trusted command, suppress captured native output, and never
mint a credential. Partial signing credentials fail. Recovery downloads the
prior run's signed bytes and does not re-sign. Xcode without signing/notary
