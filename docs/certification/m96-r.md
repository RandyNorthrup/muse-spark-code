## Owner rulings applied

- Single-model invariant: `sameModel.ts` dedupes by model id across
  providers and backends; `teamModelIds`/`isSingleTeamModel` give lane T
  the count. With one model, no team file is consulted by this lane.
- Paid tools (`webSearch`, `images`) resolve only while the caller's
  allowance says so; the allowance (ask-once modal, daily budget) is lane
  A/U's decision, injected as `{ webSearchAllowed, imagesAllowed }`.
- Enhancements on by default: the capability check refuses only for
  missing tool calling and a below-minimum window; everything else warns.
