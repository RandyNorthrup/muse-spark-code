### Design and caller contract

1. `loadRoles` captures all built-in, personal and project definitions and
   the complete runtime environment before resolving anything. An existing
   empty directory is known absence; a missing directory or listed file is
   Unknown. Missing runtime input also refuses. Root paths and project
   confinement, file decoding/caps, selectors, permission modes, tool and
   delegate identifiers, paid flags, ceilings and allowance hashes validate.
2. Every error becomes typed `RoleUnknown`; any Unknown invalidates the
   **whole** snapshot. No lower role is offered, even for an unrelated id or
   a higher-precedence project role. `resolveRole` reads its translated
   refusal at call time. All three new messages have 14 real translations.
3. `meetRolePermissions` is the sole pure permission computation. Tools,
   delegates, workspace and permission mode intersect every applicable
   ceiling; read-only/empty-path permissions remove file-write tools.
   Personal definitions replace built-ins by D75's user authority; project
   definitions meet that personal ceiling, otherwise the built-in ceiling,
   otherwise the new-id ceiling until the exact file hash is allowed.
   Session availability, paid gates and explicit runtime ceilings always apply.
4. Write-path narrowing uses one bounded conservative inclusion proof.
   Confined identical patterns, matched literals and patterns rooted under
   a literal `directory/**` ceiling prove inclusion. Unproved inclusion
   refuses. Brace alternatives refuse, including an apparently confined
   `docs/{../src,foo}/**`; no prefix heuristic authorizes that escape.
5. Charters consume the final tool names, including aliases and partial
   groups. Delegate tools are separately authorized by `delegates`, then
   meet session/runtime ceilings. The orchestrator save/update contract and
   workspace slot keep full agent identity and settings; Default carries
   settings and contradictory old/new model identities refuse.

`loadRoles` now needs `{ inputs: { kind: 'known', value: environment } }`
with explicit session catalogues, permission mode, ceilings and allowances,
or a typed Unknown from the caller. Omitting it refuses; it never supplies
runtime defaults. Returned roles are **effective** and deeply frozen. The
Roles editor reads original requests from a known
`snapshot.value.definitions` (for `newRoleAsks` and editing), while admission
and charters use `roles`/`resolveRole`. Capture a new snapshot when files,
allowances or runtime policy change; a running capture owns its detached
inputs. The existing helper exports remain, with `[]` meaning no write paths
at the new-id ceiling. No production caller outside lanes R/0 changed.
