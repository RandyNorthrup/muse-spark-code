## Lint findings fixed during the milestone (not suppressed)

- `unicorn/consistent-boolean-name`: booleans renamed (`isFocused`,
  `hasModifier`, `isCtrlEnterMode`, `isInputFocused`, `shouldPreserveFocus`).
- `unicorn/no-unsafe-string-replacement`: `redactSecrets` uses literal
  replacement strings.
- `@typescript-eslint/no-unnecessary-type-parameters` on a fake implementing
  `WorkspaceConfiguration`: the settings reader now depends on a one-method
  `SettingsSource` interface, so the fake is a plain object.
- `stylelint no-descending-specificity`: state rules ordered by specificity.
- Two rules disabled for `test/**` only, with reasons in `eslint.config.mjs`:
  `@typescript-eslint/unbound-method` (vi.fn assertions) and
  `unicorn/no-useless-undefined` (explicit "no surface" fakes).

## Security

- Logger redaction covers `LLM|id|secret`, `Bearer …`, `META_API_KEY=` and
  `MODEL_API_KEY=`; tested at all three log levels.
- Settings reader validates every value with the same zod schemas the wire
  protocol uses; invalid values are logged (redacted) and replaced by defaults.
- `environmentVariables` documentation tells users not to put keys there.
