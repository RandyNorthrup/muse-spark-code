## Joined bindings

`DevicePanel` owns one increasing revision stream per document. Complete
snapshot acquisition is serialized, including off states and action replies.
Strict UI envelopes carry view/request/revision; pairing replies echo both ids
and return the imported invitation. Abort drops the UI result without retiring
an attempt or releasing liability. The keyboard test waits for the focus effect.

`deviceMethods` loads the real `devices.js` module only on explicit use, installs
the caller's language and requires local authority dependencies. The service
binds P's current grants, real pinned mutual TLS, E's receiver/journal and the
shared U method port. Listen/connect use saved pairing endpoints. Authenticated
channel resets start local cancellation before reporting or observation; Stop
does not wait for a journal operation. Disposal revokes transports and refuses
new UI work. Construction opens no listener and starts no model.

mount sends no request; Pair returns its generated invitation; Import displays
and focuses the peer fingerprint; confirmation stays disabled until the user
checks the full comparison. The signed confirmation reaches P, all three UI
requests carry an abort signal, and the host revisions increase without granting
execution. A completed-factory/disposal race also closes the actual service and
refuses subsequent UI work or publication.
