## M121F round 3 redesign (RVM121F2, 2026-10-10, kubuntu)

Base `216b03d37`, branch `m121/f3`. Scope `test/unit/helpers/moneyTypeGuard.ts`
and its tests only; no production source changes. Tests ran on the kubuntu

### Cause

Three patch rounds each fixed one shape and opened another. Round 1 walked
wrapper properties with a per-instance visited set, but every instantiation
of a generic is a new `ts.Type`, so `Chain<T>` → `Chain<T[]>` → … overflowed
the stack (RVM121F). Round 2 stopped expanding a second instantiation of a
declaration already on the descent path. That hid finite nesting of one
generic (`Box<Box<Record<'fooUsd', number>>>`), and marking a pruned
instance as seen let sibling order decide the finding (RVM121F2). The same
unbounded recursion was still latent in `hasNumber`: a money-named key
holding a recursive generic (`fooUsd: Chain<string>`) overflowed it too.

### Design

Both type walks (the alias walk and `hasNumber`) now run through one
breadth-first iterator, `reachable`, bounded at `MAX_TYPE_DEPTH = 12` edges
from its start. Declaration pruning (`declarationOf`) is gone. Breadth
first, each type is met first at its shortest distance and expanded once
with the most depth any path could give it. So the set of judged types
depends on the type graph alone, never on sibling order. Finite nesting of
one generic is judged in full up to the bound, and every infinite
instantiation chain stops at it. The edges are unchanged. `structure`
follows the apparent type, union/intersection members, interface bases,
non-callable property types and, for a schema, its `_zod.output` only,
never into `_zod`. `holdings` (for `hasNumber`) follows members, a type
parameter's constraint, schema output, array/tuple elements, a container's
value, index signatures and properties. The mapped-key walk and its
remapped-name base-constraint fallback are unchanged.

Headroom, measured on `src` with the bound swept from 1 upwards in the same
program: every flagged money key is found by depth 2, and the whole
numeric-hint inventory by depth 7 (depth 6 misses only
`runtime/backends.ts:retryAfterCapMs`). Twelve keeps five levels spare.
