# M89: bundled skills (PLAN.md D68)

The high-quality-projects workflows (`project_setup`, `feature_delivery`,
`quality_retrofit`) on both backends. This record covers lanes 0 (strings),
S (the `bundled` skill source), I (the Muse Code install) and W (docs) on
`feature/m89-bundled-skills`, 2026-10-03. Lane V (the vendored release, its
sync script, `.vscodeignore` for `vendor/`, the notices and the VSIX size)
records its own rows; acceptance items 4 and 7 are its.

The tests use fixtures in temporary folders shaped like the vendored package
(`skills/<id>/SKILL.md`, `scripts/`, `docs/`, `VENDOR.json` with `tag` and
`files[]`), never the real vendored files, so these lanes do not depend on
lane V's commit order.
