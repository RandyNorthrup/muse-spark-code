## Findings recorded during the milestone

- The SDK hands every frame of one read to its handlers synchronously and
  only then lets the awaiting command resume (`connection.js` `#ingest`), so
  a server request written in the same chunk as the `session/resume` answer
  reaches the extension before the handle exists. That is why events for an
  unknown session wait while a start, resume or fork is in flight.
- Muse Code 1.3.0's `session/tokenUsage` (live capture 2026-09-21) carries
  `usage` (raw), `promptTokens` / `totalTokens` (counted once) and
  `cumulative`; the fake CLI now sends the same shape.
- An unreachable safety net in the Model API turn (steered input queued as a
  new turn after the loop) was removed: the loop returns only with nothing
  steered, and `steer` is refused once the turn has ended.
