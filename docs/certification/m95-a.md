## What was built

`src/core/backends/modelapi/codecs/anthropic.ts`:

- `encodeAnthropicRequest(body, options)` — canonical `CreateResponseBody` to `{path, headers, body}`
  for `POST /v1/messages`. Same input encodes to the same bytes (no clock, no randomness).
- `decodeAnthropicStream(frames, options)` — Anthropic SSE frames (as `parseSse` yields them) to
  canonical `StreamEvent`s ending in one terminal `response.completed` / `response.incomplete` /
  `error`. Every frame is zod-parsed; unknown event types are tolerated; malformed known frames throw.
- `parseAnthropicError(status, body)` — the error envelope to `ModelApiError`, with the spend-cap
  reason as `code` so the transport never retries it (research [A-rl]).
- `parseAnthropicModelsList(body)` — the `GET /v1/models` entries (lane P maps them further).

## The lane's three rules

- **Breakpoints (corrected by FIXM95A).** The last system block plus the
  last cacheable message block of the request, rolling; TTL `5m` unless the
  caller injects `1h`. All text messages use block arrays from the first
  request, so moving the marker changes only the marker. Earlier message
  content, tool-result content, system and tool schemas keep their bytes.
  Signed thinking/redacted blocks are never annotated or rewritten.
- **Thinking replay.** `thinking` / `redacted_thinking` blocks go back byte for byte, first in
  their turn, only for the model that produced them and only while thinking is enabled. Another
  provider's envelope, a damaged envelope, a model mismatch, or thinking off drops the block —
  never sent, never synthesized. The canonical carrier is the opaque JSON envelope in the
  reasoning item's `encrypted_content`, which only this codec reads (research §4).
- **The edit rule.** Whenever a request replays thinking it sends
  `anthropic-beta: thinking-binding-controls-2026-08-01` with
  `thinking.block_binding.prefix_mismatch_behavior: "drop_block"`, so a packing swap or an omitted
  image earlier in the history drops the stale block server-side instead of refusing the turn
  (acceptance 9). Without replayed thinking no beta is sent. Lane I needs no edit tracking for
  this codec. The beta/body shape comes from research [A-pt] (no capture exercised it); step 13's
  live turn through this codec rechecks it.

## Mapping decisions (for the record)

- Effort: canonical `none` disables thinking; `minimal` maps to Anthropic's lowest tier `low`;
  the other five map to themselves; anything else throws. Lane I must send `none` (not `minimal`)
  for thinking-off.
- `tool_choice: {type: "auto"}` only when tools are sent; the `tools` key is omitted when empty
  (captures 05/10); message-only `system` is omitted when instructions are empty (capture 10).
- Consecutive same-role items merge into one native message; commentary text and images sort into
  assistant turns with thinking first, as the wire requires.
- Extra native fields on `tool_use` (`caller`, …) round-trip through `toolExtras` (encode) and
  `onToolExtras` (decode, called at block finish), keyed by call id — the channel lane I's replay
  wrapper fills from the stored session (rule 13; the canonical item has no room for them).
- `developer` role reads as `user`; `web_search` tools and past `web_search_call` items are left
  out, never declared (acceptance 11). PDF (`input_file`) parts throw rather than vanish.
- Usage (corrected by FIXM95A): canonical total input is fresh + written +
  read, matching the local `m95/pfix` pricing contract. Separate
  `input_tokens_details.cache_write_tokens` retains total writes;
  `cache_write_tokens_1h` retains the one-hour subset when captured, so the
  difference is five-minute writes. Missing TTL stays unknown. Captured
  `cache_creation` from message start survives its omission in the final
  delta. Equal total inputs with different writes remain distinguishable
  even after canonical zod validation. Cached reads and thinking tokens
  retain their existing fields. `service_tier` / `inference_geo` have no
  canonical home and are dropped.
- No `count_tokens` mapping: no capture exercised it.
