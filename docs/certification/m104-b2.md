## Integration limits discovered

D's `src/webview/bridges/**` and shared HTML renderer are absent from this
base. B must hand off the renderer rather than create D's files. MHP 1.1
HTTP/SSE carries panel payload/lifecycle only; it has no editor-service
request/result bridge. A native stdio host can supply those services, but
a browser cannot supply them over the frozen HTTP routes alone.
ACP still has its translation view, not the full shared panel controller.
M104 feature parity and M110a0 are not certified by transport tests.

The common help-reference files (`src/shared/featureCatalog.ts`,
`scripts/gen-reference.mjs`, `check:reference`) do not exist at this base.
Integration must apply command entries when that owning lane lands.

A provisional standalone connection unit fixture was retired under the
common two-failed-fixes rule. Adding initialize fields and then theme tokens
did not fix it: the fixture also invented `min/max` version keys and omitted
mandatory lifecycle. The authoritative contract uses
`minimum/maximumExclusive`, `mhp/…` values and lifecycle. It was never a
production gate; no existing test was removed or skipped. Process fixtures
now validate initialization against the frozen schema before sending it.
The failed attempts are preserved in `temp/panel-connection*.log`.
