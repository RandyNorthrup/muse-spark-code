## Is it of benefit to the code?

The owner, 2026-10-07: "is it benificial to the code thats the real
question … if it does not benefit the code it should go away".

**Android is not a target.** The README's requirements name Windows, macOS
and Linux; no PLAN.md decision adds Android or Termux (its Android mentions
are Android Studio and the Android SDK); no file under `src/` tests for
`'android'`. The four cases run `platform: 'android'` through the code any
platform other than Windows, macOS and Linux takes: the POSIX launcher
search, the POSIX credential path, and "no voice" in the dictation and Muse
Voice locators.

**Overlap.** The dictation case (`stays unavailable on Android/Termux…`)
repeats the existing `freebsd` assertion in
`says why Linux and other platforms have no microphone`: same branch, same
expected value. The other three have no counterpart: no other test passes a
platform outside `win32`, `darwin` and `linux` to `resolveMuseLaunch`,
`credentialFilePath` or `locateCaptureHelper` (searched `test/` for every
other Node platform name; the other hits test unrelated functions).

**Drills (2026-10-07, this worktree).** One mutation at a time in
`src/core/backends/musecode/launch.ts` or `src/core/voice/helperLocation.ts`,
then `vitest run test/unit/launch.test.ts test/unit/helperLocation.test.ts`,
then the file restored and its SHA-256 compared. Baseline and final runs:
35 of 35 passed, exit 0; both files' hashes matched the originals. Script
and results: `scratchpad/pr51-drills.mjs`, `scratchpad/pr51-drills-result.json`.
