# M92e certification — secret guards on prompt send and shell approvals (lane M92-E, Part 2)

## 2026-10-05 — implementation, drills and checks

Scope (PLAN.md D71/M92, lead decision "robust and feature rich"): the M92a
lane found no prompt, commit or shell secret warning anywhere, so M92e
builds the asked-for guards on the ONE shared table in
`src/core/redact.ts` (`countSecretMatches` / `redactSecrets`, no second
pattern list).

- Prompt hold: `ConversationController.send()` scans a plain composer send
  and posts `secretPromptDetected` (with the redacted text) instead of
  starting the turn; only a re-post with `secretAccepted` sends it on
  (`src/shared/protocol.ts`, the controller, `src/webview/state/uiState.ts`,
  `src/webview/App.tsx`, new `SecretPromptDialog.tsx`). The transcript card
  shows the redacted text either way; the session store keeps the raw text
  once the user accepts (resume needs it); logs and exports never hold it.
  The webview cannot scan itself (`src/webview/tsconfig.json` forbids
  `src/core` imports). Slash-command, review, goal, handoff, loop and
  `!`-command sends are out of scope.
- Commit guard skipped: no commit-writing path exists (`git.ts` only runs
  git, best-of-N snapshots with `write-tree` explicitly without a commit,
  review only reads). A `git commit` the agent proposes as a shell command
  meets the shell guard.
- Shell guard: the Model API engine settles a secret-bearing command
  `secretDetected` (no allow-rule or session-rule auto-allow, no Auto
  reviewer, no session choice, no hook auto-allow;
  `src/core/backends/modelapi/permissions.ts`, `ModelApiHost.ts`), the
  controller scrubs every approval card before the panel on both backends
  (value redacted, secret note, session-scoped approve choices dropped; new
  `src/core/agent/approvalSecrets.ts`), and the Auto reviewer on Muse Code
  never sees one (`isReviewableApproval` excludes them). An explicit user
  approval still runs the command as proposed. Bypass mode still runs
  without a card, as for every gate: an explicit run-everything choice, not
  an allow rule.
- Strings: 5 keys in `src/shared/l10n/en.ts` (no slots, spans or plurals)
  with real translations in all 14 `l10n/ui.*.json` tables.

Secrets in tests are runtime-built (`sk-` + repeated characters), never
literals. The vitest runs below point `TEMP`/`TMP` at a writable sandbox
dir and pass `--root` in regular form (the `\\?\` cwd breaks Vite's root
check); `node` invokes the repo's own binaries.
