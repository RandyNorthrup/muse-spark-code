## Limitations and next work

OpenRouter production OAuth exchange and key usage remain unavailable;
pasted-key model requests retain their existing implementation. Enable those
surfaces only after captured real services are wired and certified. Local
server tests use fakes; no live server or model certification is claimed.
SecretStorage and providers.json cannot share a filesystem transaction:
cleanup failure may clear some keys, and a later file-write failure leaves
old configuration with keys cleared. Both cases fail closed and require
credential re-entry; configuration/default are never half published.
The lead should integrate this lane with the separate runner/usage repairs,
then run full quality and the installed-editor/platform checks.
