## Findings recorded during the milestone

- `ToolIo.listDirectory` lost its last caller when the context loaders moved
  to `ContextIo` (m24-context.md) and was removed.
- One full gate run failed in teardown only: removing `toolIo.test.ts`'s
  temporary folder raised `EBUSY` with all 1,164 tests green. A probe
  (`scratchpad/probe-taskkill-race.mjs`: the tree-kill test's command, killed
  at every 50 ms from 100 ms to 1.5 s, then the folder removed) found no
  process escaping `taskkill /T`, so the hold was transient. The suites that
  use real temporary folders now remove them through `removeFolder`
  (`test/unit/helpers/temporaryFolders.ts`), which retries five times, 200 ms
  apart and growing, and still fails on a folder held longer, as one a leaked
  process sits in would be.
