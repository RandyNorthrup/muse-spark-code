### Finding 3 — fixed: clipboard cancellation/disposal owns completion

The browser service adapter owns each admitted clipboard request until settled.
Abort rejects immediately with `MHP_CANCELLED`; disposal rejects pending work
with `MHP_UI_DISPOSED`. Settlement unregisters the listener and ownership.
An awaited browser write consumes late success/failure without changing that
refusal, starting another write or reporting success. Non-Error browser failures
become `MHP_CLIPBOARD_FAILED`; ordinary denied-write Errors still propagate.
An already initiated browser write cannot be undone by this adapter.

tests pass). After the fix, **17 interaction tests pass** at the repository
