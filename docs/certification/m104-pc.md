### C3 — native-independent report and release-note adapters (F19/F26/F45)

`createPortableReports` reuses the actual persistent, bounded, scrubbed journal
and sealed-preview report handler. Startup cleanup is owned before awaiting;
crash markers are consumed once. Clipboard/save/issue operations receive the
exact final text; failed and cancelled exports remain failures/cancellation.
The VS Code issue reporter is explicitly unavailable outside that host.

`PortableWhatsNew` validates packaged content and incoming messages, renders
real note/link/action indices, dispatches only allowlisted commands/settings,
and publishes through an awaited carrier port. Reload uses a fresh nonce.
Replacement/session retirement/disposal reject stale input; close begins by
retiring input, while failed cleanup stays acquired. An admitted action drains
before release. An actual carrier-close notification can retire failed cleanup.
Errors produce fixed log words and localized notices rather than private paths.

The frozen three-argument runtime factory now has a configurable builder for
real installed assets, HTML publication, report facts/save and close events.
It installs the caller's language before owner configuration, owns resources
immediately and makes disposal/subscription removal idempotent. Defaults still
provide Tasks only; A must configure the additional ports explicitly.

regression suite: **202 passed**. Source/code owns no paid or model dispatch;
model attempts and credential reads are zero. Full runtime/native composition
