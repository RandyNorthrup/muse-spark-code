## Never-creates-accounts drill (R3 arm-check + structural green)

(`sizes`/`images`/`create`/`status`/`delete`; node: `install`/`pair`/
`teardownAndWipe`) — no account API exists. In-code enforcement:
`src/core/estimator/provision/provider.ts` refuses any operation or body
field named `billing`, `payment*`, `creditcard`, `cardnumber`, `signup` or
