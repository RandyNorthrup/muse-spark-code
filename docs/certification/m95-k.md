## Findings

- **Drill 17 survived its first mutation.** Dropping `'oauth'`
  from `AUTH_KINDS` kept all 4 entry tests green: no test stored an
  OAuth entry. The guard was real but unproven, so the drill added
  `keeps a stored OAuth entry across a restart` (an OAuth pending
  removal must still be recognised after a restart); the break then
  fails exactly that test. Fix verified green (5/5), lint/format
  clean.
- **The origin-bind test had a typo.** `refuses another scheme…`
  asserted an `https:` URL would be refused — the same origin the
  neighbouring test accepts. The code was right (origin comparison);
  the test meant `http:` (the scheme leg). Fixed, with the
  `unicorn/prefer-https` disable the downgrade leg requires (logged
  in `PLAN.md` §8).
- **Full-suite failures are environmental.** See the blocked-gates
  section: git-ownership (`importIo`), real-filesystem PDF fixtures
  (`Composer`), parallel-load flake (`App`, green alone). Base-vs-lane
  worktree comparison shows zero lane-K regression.
