## 6. Real-life steps for the lead

Previews (needs a Model API key and the contributor model):

1. Set the Model API backend, pick `muse-spark-1.3-contributor`, send a
   message that calls a file tool. The tool row shows the streamed argument
   text with a bounded indicator while the call runs, then the settled
   result. Nothing executes before `.done`.
2. Repeat in an ACP editor: the session shows a `tool_call` with the same
   preview text, then the completion update.
3. Run the same turn headless (`exec`): the sink records completed tools
   only; no preview payloads appear.

Native readers (needs Muse Code sign-in, no model call):

4. The Modes footer and model palette list the served tiers with the
   catalogue default pressed; an unfamiliar tier is shown disabled with its
   reason.
5. A reply's actions menu → Send feedback to Muse Code: classification
   defaults sensibly, the note counter stops at the protocol maximum, the
   scrubbed preview names what leaves, upload reports **Feedback uploaded**.
   With no `muse` CLI sign-in the dialog reports the refusal it carries.
6. History → delete a session: refuses with the unsupported-session-delete
   line before anything is sent; History stays archive-only.
