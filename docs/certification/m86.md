**SPEC 5.3, `after.mode`.** The conditional writer runs a `staged` step once
the content is staged beside the file and before the rename
(`ToolIo.writeFileIfUnchanged`'s `staged` option, `fsAtomic.ts`); the
recorder journals the write's intent there, with `after.mode` read from the
staged temp file's handle and `createdFolders` from the folders the
publication made. This is the implementation of SPEC 5.3 step 4's
"`after.mode` from the published temp file's handle before the rename":
the intent is still durable before the publication (step 2), and a failure
to journal it leaves the file as it was.

**A child turn's top turn.** The Model API host hands each child session the
checkpoint of the parent's turn that spawned it; each of the child's turns
inherits that decision. A child brought back from an earlier window keeps the persisted recording
decision, never its former io. An unknown historical decision or unavailable
recorder refuses the child; a record failure also prevents it running.
