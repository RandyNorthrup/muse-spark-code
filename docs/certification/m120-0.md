# M120 lane 0: contracts and the D212 borrow/recall engine

Branch `m120/contracts`, from `docs/d109-secondary-roles` `360baccfc` (the
0.17.0 candidate plus D212). Built on the Linux rig `kubuntu` on 2026-10-09.
PLAN.md D103, D212 and M120. No UI, no wiring, no handoff execution: those
are lanes P, W, S and H.

## What the lane adds

- `src/shared/teamPreference.ts`: the contracts (zod/mini schemas and their
  types). One preference model: each schema extends D75's existing shapes in
  `src/shared/team.ts` instead of standing beside them.
- `src/core/team/borrow.ts`: D212's decisions as pure functions over a
  snapshot and the caller's `nowMs`. No timers, no I/O.
- `src/shared/constants.ts`: the five D212 timer defaults and the demand-wait
  floor (`TEAM_BORROW_*`).
- `src/core/reporting/plan/statusPhrases.ts`: the reviewed status phrase
  `lane 0 built` (maps to `building`), so `check:plan` reads M120's new
  status line.

## Decisions this lane made (within D212)

- **Windows are half-open.** "At least" holds at the boundary; "within"
  holds strictly before it. Demand at 60 s borrows, 59.999 s does not; work
  due in 9:59 keeps the agent home, 10:00 does not; a task due in 4:59
  finishes, 5:00 is recalled; the recall wait stops at 2:00; the cooldown
  ends at 3:00.
- **Whose timers.** The demand wait is the borrowing role's. The lookahead,
  cooldown, finish grace and recall wait are the agent's main role's: they
  protect the main role.
- **Expected finish** is start plus the role's recorded median, capped by the
  time box; the time box alone when no median is recorded; an overdue task is
  due now.
- **A main candidate freeing inside the window** is the caller's
  `unmetSinceMs`, reset whenever a main candidate frees. A free main candidate
  now, or a reset less than the demand wait ago, answers `mainFree`.
- **Recall pairing (lead decision, fix round).** Unmet main-role tasks pair
  with borrowed agents that meet their conditions by maximum bipartite
  matching (augmenting paths; tiny at this size). Agents already asked go
  first, then the earliest to finish, only as a deterministic tie-break
  among maximum matchings. Once asked, a recall is not relaxed to `finish`;
  it is cancelled only when a main candidate frees (`keep`,
  `mainCandidateFree`).
- **Finish grace expires (lead decision, fix round).** The grace counts from
  when unmet main-role work first appears for that borrowed agent (the
  earliest `unmetSinceMs` it can take, recorded on the queue — no new field).
  The borrowed task finishes only while `now` and its expected finish are
  both inside that window; after it the agent is recalled at the next safe
  point, bounded by the recall wait. A task already past its expected finish
  gets no grace. (Replaces the lane-0 choice that kept `finish` past the
  expected finish.)
- **Queued main work always blocks borrowing (lead decision, fix round).**
  An agent with queued main-role work it can take is never lent, whatever
  the lookahead (0 included); the lookahead only covers work that is not
  queued yet (a producing task's expected finish).
