## Handoff review and behavior

Tab owns one consent key, implicitly feature `tab`, plus model and price
fingerprint. Pending questions share only that key. Only Always stores a
keyed record; window and request scopes stay in memory. A feature-wide grant
alone cannot authorize any model. Legacy Always therefore asks a migration
question. Existing records are validated before use. Every scope carries
revocation, including a request-only fallback after an unrememberable Always;
revocation during the keyed write clears the stale record and refuses.

The runner advances its policy epoch synchronously on configuration detection
and remains reloading through observation and publication. Tab reads refuse
meanwhile. Read permissions bind path, content digest, model and epoch.
The provider captures its model before lazy hook loading. Consent and policy
are checked after waits and before exposing a suggestion. Its engine hands a
pure policy check to the real Model API client alongside the existing attempt
guard. The pure check does not repeat stateful paid admission: it checks after
credentials, endpoint verification, pacing and admission and finally after
HTTP body construction, before the send. Refused sends settle at zero and
never increment PaidUsage. A dispatched request continues to settle its usage.

Four added assertions failed on the handoff code before repairs (34 others
passed): request-only revocation, revocation during keyed Always persistence,
and stopping before the next wait after credentials and pacing. All four
passed after repair. The expanded production-path suite uses real
PaidUseConsent, ExtensionHookRunner, lazy Tab provider factory, Tab engine and
ModelApiClient, with fake hooks, storage, credentials and transport.

Fake-clock interleavings cover consent, debounce, free-slot waiting, ledger
reservation, credentials, pacing and asynchronous admission. Model, hook
epoch, consent revocation and cancellation each move while requests wait;
price changes also refuse. Hooks and model requests use existing documented
wire shapes; no new wire shape or capture is claimed.
