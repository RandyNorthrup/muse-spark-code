## Kept, fixed and removed

Kept the implementation's connection capability/handler seam, per-call pool
routes, backend pending forms and timeout, schema-only/action-only events,
webview protocol/controller path, ACP adapter and form card structure.

Fixed:

- Corrected the capability to this protocol revision. Replaced permissive,
  handwritten schema/date checks with zod's restricted primitive schemas
  and ISO checks. Retained bounds, enum labels, defaults and the four formats
  the negotiated spec supports. Reject unknown keywords, nested structures,
  inconsistent constraints, bad defaults and answers outside the schema.
- Validate unsupported schemas before hooks. Only an explicitly user-scoped
  hook can answer; project or missing scope cannot. Hooks-off bypasses hook
  dispatch. Both hook events use the explicit `ElicitationHookSeam` dependency.
- Cancel on timeout, Stop, tool-call deadline, connection close and the last
  panel releasing its session. Reject invalid submissions without settling
  the form. Connection exceptions expose fixed diagnostics, not answer text.
- Cancel ambiguous concurrent pool routes instead of guessing the newest
  session. Forward child forms and route their answers to the owning child.
- Preserve ACP Decline distinctly from Cancel, retain all supported schema
  constraints, name the requesting server, and contain expired-form races.
- Accessible fieldsets, labels, enum group names, required/error associations,
  Enter submission and Escape cancellation. Inputs and labels fit 320px;
  submitted cards lock until settlement/refusal. Drafts stay component-local.
- Corrected the timeout test's watcher race by capturing its turn promise
  before the watcher rotates. Shared test fixtures remove duplicate code.
- Registered the module as lazy-only in the existing bundle-split gate;
  added form scenarios to existing browser harness, including real 320px
  viewports. Regular form scans also wait for the real browser's axe result.
- Corrected light-theme error text using the theme foreground and bold weight after axe detected contrast 3.15:1.
  Updated README and Unreleased changelog; reused all translated keys.

Removed unsupported numeric/boolean enums and arbitrary formats, hand-written
calendar/time checks, the redundant item stack, and unchecked exception text.
No unrelated feature or refactor was retained. No gate, cap, timeout, ignore
or rule level was weakened.

Form answers never enter logs, event history, saved drafts or exports. The
requesting server's own subsequent tool output remains ordinary tool output.
ElicitationResult receives only field names and action, including for project
hooks. User-answer hooks still pass through schema validation.
