## Live drills (the real CLI, the owner's sign-in)

`XDG_CONFIG_HOME` holding a settings file with
`run.subagent_delegation_mode = "auto"` and a copy of the CLI's credential
file, deleted on every exit path; the owner's own config was not touched.
`scratchpad/live-subagents*.log`, `live-e2e-0.4.3.log`.

| Drill                                        | Result                                                                                                                                                                                                                                                                                                                                                          |

## Security

- The drills' temporary config copy lives in the scratchpad for the run
  and is removed by a trap on every exit; the credential is never echoed.
- Owner controls go through the CLI's own commands with the session id it
  minted; the Model API backend refuses them.
- The harness runs against a fake host in headless Chrome; nothing reaches
  a network.

## Findings recorded during the milestone

- `subagent_spawn` is approval-gated by the CLI (above); Plan mode refuses
  it by policy.
- A finished child session is not readable through `session/read`; the map
  relies on the items the CLI streams live and on the result envelope.
- The CLI's reminder agents make a single-turn attempt count vary between
  25 and 45; the extension adds one hidden text part per turn.
- 0.5.0 was published to the Marketplace by hand on 2026-09-23 from the
  release vsix (`npx vsce publish --packagePath`, the PAT from the
  clipboard, never stored); 0.2.0–0.4.3 were never published, each tag's
  GitHub Release carries its vsix. The three Windows CLI faults went
  upstream the same day: meta-models/muse-code-sdk#29 (approval ledger
  fence), #30 (`session/rename`), #31 (`session/fork`).
