## Ruling 1 — the P3-2 test died at its own line 640 (test-only fix)

a pass-through `vi.spyOn` on the client socket captures the status frame,

and the corrupt reply is emitted on the client socket. No
`Reflect.get(client, 'pending')` remains in this case. The server reply path
stays silenced, so the injected frame is the only answer the pending request
gets.
