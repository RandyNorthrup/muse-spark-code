# M96 lane F certification: autofill, intensity, validation, preview, transfer

Lane F of M96 (PLAN.md D75) on `m96/f` from `feature/m96-agent-roles` at
`e23ec61c`. Pure core only; no UI, no request path, no model call.

## What was built

`src/core/team/` (new):

- `templates.ts` — Solo / Pair / Full team / Custom drafts: roles, modes,
  tool groups and suggested pools from the user's agents. Pair puts
  `code-review` on another vendor (the owner's split).
- `autofill.ts` — suggestion kinds `roleModel`, `roleBudget`,
  `reviewVendor`, `poolFallback`, each with its reason; per-role
  dismissals; typical use from `TEAM_ROLE_TYPICAL_TASK_TOKENS` until the
  local record has five tasks, then its median.
- `intensity.ts` — the five levels' running caps, effort steps, task
  tokens and daily budgets; custom roles kept until Re-apply; Max clamped
  to the lowest ceiling; the 429 throttle backoff and recovery; each
  level's cost per hour.
- `modelSettings.ts` — exactly the settings a model supports (sampling
  and verbosity hidden for Muse Spark models), one-line cost notes, role
  base efforts, the intensity shift clamped to the model's tiers.
- `capValidation.ts` — each case D75 lists (token floor, task above day,
  dollar cap unpriced, unpriced key without task+day caps, concurrent
  above global, day above the team budget).
- `preview.ts` — roles, entries, forced switches and the cost range for
  the three sample tasks over the unsaved draft, from injected selection
  (lane A's seam) and price cards; cached input priced at the cached rate.
- `teamTransfer.ts` — export copies allowlisted fields only (no
  credential, endpoint, provider or command line); import parsed with zod,
  refused whole on an unknown key (checked on the raw value, since zod
  strips), opened as a draft with missing entries marked.

Strings: 37 keys in `src/shared/l10n/en.ts` plus the
`teamIntensityLevels` group, with real translations in all 14
`l10n/ui.*.json`; 7 genuinely identical words allowlisted per locale in
`l10n/untranslated.json` (`node scripts/check-l10n.mjs`: 0 problems).

Seams for the parallel lanes (explicit interfaces, no fakes in
production code): M95's catalogue/capabilities/prices arrive injected;
lane R's capability check and charter arrive injected; lane A's selection,
ceilings and ledger record arrive injected; lane 0's `TEAM_*` constants
are defined in these modules with PLAN.md's values and move to
`src/shared/constants.ts` at integration.
