## 2. The fan and uniform pills

The menu already was the panel's one radial menu (`GooeyMenu`): a fan of
stacked blue pills, icon and label in one pill, bursting from the row's ⋯,
side chosen by room, arc kept inside the panel, arrow keys, Escape returning
focus to ⋯, reduced motion without the burst, forced colours. What changed is
the width.

- Before: every pill was a fixed 272 px (`GOOEY_MENU.narrowPanel` 320 less
  padding and bow), whatever the labels.
- Now: on each burst's first layout pass every pill is drawn at
  `width: max-content`; `useLayoutEffect` reads each pill's laid-out width
  (`getBoundingClientRect`, rounded up) before paint, and the widest becomes
  the burst's shared width (`gooeyPillWidth(viewport, natural)`), capped only
  by the panel less its 8 px edge padding. A new label set (another burst, a
  re-render with other labels) measures again. No fixed pixel width remains;
  `GOOEY_MENU.narrowPanel` is gone. A label wider than the panel still ends in
  an ellipsis with its whole text in the tooltip.

Other menus on the same component (`useRowMenu`/`GooeyMenu`): every row's ⋯
menu (replies, tool outputs, edits, restore notices, queued cards), the quote
menu on highlighted text, and the rewind group's second burst. They all get
the content width; nothing else was converted.

## 3. Title Case sweep

Rule: Chicago-style, as the brief states (short prepositions as, at, by, for,
in, of, off, on, per, to, up, via, vs, the articles and the coordinating
conjunctions stay lower case unless first or last; 4+ letter words
capitalized; hyphenated parts capitalized; phrasal-verb particles
capitalized: "Turn Off", "Sign In", "Set Up"; identifiers, file names, slots
and brand casing untouched; "id" becomes "ID").

Method: every English string was extracted from `en.ts` and `usageEn.ts`
(4911 strings). Candidates were the strings that are not sentences (no
terminal `.`/`!`/`?`/`;`, no inner sentence break, at most eight words) and
that Title Case would change: 1837, plural forms aside. Automatically left in
sentence case: strings starting in lower case (spliced fragments: "already
exists", "running"), strings with `{slots}` (sentences around a value),
keys naming placeholders, details, hints, descriptions, tooltips, prompts,
reasons, errors, notices and empty states, progress text ("Preparing
arguments…"), CLI syntax. The remaining list was read by hand: statuses,
tooltips that are sentences, notes and messages stay sentence case; 14
lower-case badges or labels shown alone (history's "current"/"fork", the
"paid", "background", "estimated" badges, model price kinds, git's staged
state) and the slot labels ("Use {model} for This Message", "{feature}
(Paid)") were taken in. `package.nls.json`: 29 command and walkthrough
titles (descriptions and `config.*` untouched).

Help-reference strings that quote a menu's labels were brought in line with
the labels they quote (`referenceTabMenu`, `referenceTabSnooze`,
`referenceTabOff`, `referencePaid`), so the generated reference still names
the menu items exactly.

Counts (all against `bd2d617c8`, generated from the two tables, so they
include the fork labels): English UI table 1056, usage table 74, manifest 29
= 1159 strings.

Other locales follow their own convention; only labels and titles that began
with a lower-case letter were given a capital, plus the shortened fork labels
and the key cap `⇧ + Tab` (which every table had copied as `⇧ + tab`). UI
tables: cs 15, de 11, es 16, fr 15, hu 15, it 15, pl 16, pt-br 16, ru 16,
tr 15, ja 3, ko 3, zh-cn 3, zh-tw 3. Usage tables: de, hu, ja, ko, tr, zh-cn,
zh-tw 1 each (`p95` → `P95`). Identifiers kept as they are: `dev.meta.ai`,
`sudo`, `diff`. German now matches English in two loanwords ("Pull Request",
"Limits & Budgets"), added to `l10n/untranslated.json` for `de`.

Kept in sentence case on purpose:

- Text the model reads (`MODEL_TEXT`), wire strings (ACP's "Internal error",
  "Authentication required"), ROADMAP.md headings (generated from PLAN data).
- Labels that arrive from Muse Code itself (approval choices such as "Allow
  once", "Always allow in this workspace: …", tool output such as "Scheduled
  prompt sent."): the panel shows the captured wire text verbatim (AGENTS
  rule 13), so neither the code nor the fixtures were recased.
- `vault.noAccess` ("No access"): it is above all the error every refused
  secret raises (`mcpVault`, `toolIo`, `mcpProcess`, `ideMcpServer`).
- Log lines (`Reverted Muse edit …`), fact lines ("This window: $0.12",
  "Daily budget: …") and tooltips that are sentences ("Stop recording
  (Ctrl+D)", next to "Tap or hold to record (Ctrl+D)").

Short phrases that are both a chip and an internal error
(`media.durationUnknown`, `teamRunners.busy`, `media.uploadStop`) do take
Title Case: the person sees them as the chip or status label.

Docs: README and the Marketplace README bold label quotes, the ACP guide,
code comments quoting labels; the help reference regenerated
(`docs/reference.md`, `docs/sharing-reference.md`, `reference.generated.*`).
The report renderer goldens (`test/fixtures/reports/*.{md,html,text}.golden`,
45 files, JSON unchanged, plus the CLI golden) were regenerated the way their
README describes, plus the same label edits in `project.cli.html.golden`; the
diff is only the section and column titles ("Needs You", "Pull Requests",
"Next Steps", "Observed At", "Not Applicable"…). The harness scenes in
`test/harness/index.html` click buttons by their English label, so those
labels (`Session History`, `Pick a Provider`, `Preview Fixes`…) follow.

Historical records (PLAN.md, released CHANGELOG sections, earlier
certification records) keep the words they recorded.
