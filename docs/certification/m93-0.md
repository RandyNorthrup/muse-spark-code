## Wire shapes

- `reportEventRefSchema` (strict): `{ kind: REPORT_EVENT_KINDS,
entryIndex: uint }`. The sanitized handoff: which journal event, never row
  text. Lane W embeds it in its messages.
- `reportWebviewErrorSchema` (strict): `{ kind:
REPORT_WEBVIEW_ERROR_KINDS, source: WEBVIEW_ERROR_SOURCES, code:
1..64 chars, frames: ≤16 × { path: 1..260 chars, line ≥ 1, column ≥ 0 } }`.
  D72's scrubbed `window.onerror` / `unhandledrejection` / React-boundary
  post. No message/stack/text/prompt/session-id field exists, so free text
  has nowhere to go; every object is strict, so a forged extra field fails.
- What the schema does NOT check is deliberate: package-relative path shape
  and code vocabulary are lane R's semantic validation, not transport
  bounds. An over-long absolute path fails on length; a short absolute path
  passes transport and must fail lane R.
