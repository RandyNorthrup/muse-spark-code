## What was built

- `src/core/redact.ts` — eleven new rules, each with its literals in
  `MAY_HOLD_SECRET`:
  - Whole-token shapes (D74; the shapes the captures scrubbed): Groq
    `gsk_`, xAI `xai-`, Fireworks `fw_`, Hugging Face `hf_`, Together
    `tgp_v1_`, Bedrock `ABSK` and `bedrock-api-key-`. Floors follow the
    existing style (`sk-` needs 20): 20 past `gsk_`/`xai-`/`fw_`, 16 past
    `tgp_v1_`, 8 past `hf_` (whole key at least 11, past the preset's
    minimum of 10), `ABSK` and `bedrock-api-key-`. A key with no such
    prefix (Mistral, Azure's 32 hex) stays caught by the header and field
    rules and by the exact value the transport registers per request; the
    tests pin all three paths.
  - Account ids (captured 2026-10-04): OpenRouter's `user_id` (top level),
    `creator_user_id` and `workspace_id` (quoted and bare, name kept);
    OpenAI's `openai-organization` and `openai-project` and Anthropic's
    `anthropic-organization-id` and `anthropic-workspace-id` headers
    (name kept); a UUID after "team", "account", "organization" or
    "project" in prose (word kept, only a UUID replaced).
  - `tgp_v1_` is in the captures' scrub list but in neither D74's
    parenthetical nor its preset's `keyShape` (`any`); it is covered
    because the captures show the shape on the wire.
  - Z.ai's `<32 hex>.<16>` shape is deliberately not a rule: it holds no
    fixed literal, and every rule's matches must hold one of its literals
    (the prefilter test enforces it). It is caught by the header, field
    and exact-value paths, which the tests pin.
- `src/shared/constants.ts` — `HOOK_FORBIDDEN_ENV_NAMES` gains the three
  D74 names: `AWS_BEARER_TOKEN_BEDROCK`, `ANTHROPIC_AUTH_TOKEN`,
  `HF_TOKEN`. Every other preset's key variable ends in `_API_KEY`, which
  `isCredentialVariable`'s suffix rule already strips; the tests pin both
  the three names and a representative `_API_KEY` list. No edit to
  `toolIo.ts` or `runtime/credentialVariables.ts` was needed: both read
  this set through `isCredentialVariable`.
- `test/unit/providersThreats.test.ts` (new, 64 tests): key shapes in
  prose, headers and error envelopes; the prefilter atoms; account-id
  fields, headers and prose UUIDs with negatives; prefix-less keys by
  header, field and exact value, plus the standing-alone residual; the
  three named variables (any case), the suffix list, non-credential
  negatives, hook withholding and the agent strip.
- `test/unit/redact.test.ts` — corpus rows for the eleven new rules,
  which that file's prefilter test requires of every rule. Rows only; no
  existing expectation changed.

No new dependency, no new module, no new import in `src/`: only data in
two modules the activation bundle already loads (`logger` imports the
redactor), so nothing new loads at activation. No user-facing string was
added, so `en.ts`, the 14 `l10n/ui.*.json` and `package.nls*.json` are
untouched.
