# M95 lane M — Models panel UI: certification record

Lane M of M95 (PLAN.md D74, M95) — `src/webview/models/**`, the panel's
entry, the section registry, the Providers and Models sections, the ten
shared components, the panel's reducer, `src/shared/modelsPanel.ts`, and
the harness scenarios and accessibility cases for every state.

Branch `m95/m`; lane 0 strings and the M95 plan under it; lane P's
providers core read from `refs/remotes/kubuntu/m95/p` (`722c30ec`) and
coded against, never copied. No new npm dependency.

Owner rulings applied (2026-10-04): enhancements on by default; paid
extras ask once through the existing three-choice paid modal (the price
and the shared daily budget `museSpark.paidDailyBudgetUsd`) — the
panel's `CostNotice` states the one-token test cost and waits for Accept,
and never auto-accepts; a user with a single model sees today's
behaviour (the panel renders its empty state and nothing else changes).

## What was built

- `src/shared/modelsPanel.ts` — the panel's wire contract: host-owned
  state slices (presets, providers, models, scans, suggestions,
  lastChoices, drafts, pendingRemovals), the wizard's editable fields,
  and the `providers/*`, `models/*`, `suggestions/*` messages plus
  `modelsPanel/ready`, `modelsPanel/state` and `modelsPanel/navigate`.
  Every message object is strict, so a smuggled credential fails
  validation instead of riding along (acceptance 5/17). Shapes mirror
  lane P's core field for field (`ModelRow`, `ModelFilter`, `WizardStep`,
  `OpenRouterPrivacy`, the provider entry); the webview never imports
  `src/core` (its project forbids it) and codes against these schemas.
  `lastChoices` is carried minimally (the suggestions step shows the
  last default as a hint); anything else host-side stays host-side.
- `src/webview/models/**` — `models.tsx` (entry → `dist/webview/models.js`,
  a second entry in `scripts/build.mjs`), `panel.tsx`, `sections.ts`
  (the `{id, title, icon, Component, reducer}` registry; M96 adds roles
  and agents the same way), `ProvidersSection.tsx`, `ModelsSection.tsx`,
  `Wizard.tsx` (all nine steps), `reducer.ts` (navigation, overlays,
  deep links, host-cleared drafts), `models.css` (theme tokens only,
  container queries to cards at 340 px), and the ten shared components:
  SearchableSelect (combobox), DataTable (grid, arrows/Enter/Escape),
  FilterBar, Badge, SuggestionCard, InlineError, UndoBar, ScanStatus,
  KeyState, CostNotice.
- The wizard's pick step is local until the host draft arrives; cancel
  writes nothing (no provider, no secret). **Save** stays disabled while
  blockers are non-empty, with each blocker inline in plain words.
- Strings: the M95-M block in `src/shared/l10n/en.ts` and real
  translations in all 14 `l10n/ui.*.json`. No `package.nls*.json`
  change: the lane adds no commands or settings.
- Harness: 21 `models-*` scenarios in `test/harness/index.html` behind a
  fake host that answers the panel's protocol (`?bundle=models`, wired
  through `harness-shots` and the a11y gate per scenario), registered in
  `scripts/lib/harnessServer.mjs`.
