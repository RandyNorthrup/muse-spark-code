## Wire grounding (rule 13)

No new live call was made in this lane (none authorized). The schemas follow
TypeSafe's documented `/v1/systemone` wire as re-confirmed live through
OpenRouter on 2026-10-04 (`docs/certification/m98-research.md`): request
`{state, model?, questions: {id: {type, instructions, criteria}}}` with
`noul` criteria over `true`/`false`, `choice` criteria as option-to-
description-or-null, `score` criteria as an ordered array; response `{model,
answers: {id: typed answer}, usage: {input_tokens, output_tokens}}` with
`noul → {type, noul, probabilities}`, `choice → {type, choice, confidence,
probabilities}`, `score → {type, score, confidence, legend, probabilities}`.
Cross-checked against independent third-party field-for-field mirrors found
by web search (notably the `choice`/`score` confidence mapping, the noul
without confidence, the legend as level numbers as string keys, and the live
`abstain` addition the byte-compatibility test preserves). Lane G certifies
the shapes against M91-G's harness and fresh captures when it starts.

Bound values: the 64/26/10/64 KiB wire bounds are the services'
intersection (D77); the 0.8 top-1 floor sits above the RVM98 0.60
counterexample (which must fall back) with the probe's ~0.99 matches still
passing, bounding the residual error at 0.2; the 0.7 advisory bar is
conservative for uncalibrated output that can only add caution; the 0.5
ready rate turns a mostly-unready backend off by default; the 60 s timeout
bounds background calls Muse Spark served in ~14 s.
