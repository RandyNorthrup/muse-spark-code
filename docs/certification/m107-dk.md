## First finished piece: disk policy

`disk.ts` reads watched locations with bigint `fs.statfs` counters, caches
30 seconds (5 seconds below twice the floor), preserves unknown readings,
and estimates time to the floor over a bounded five-minute history.
G retains its levels, hysteresis, dwell, stepwise recovery and override.
Disk entry uses the existing `disk` event reason, preserving the frozen
exec-event contracts. The disk setting reads only inspected machine values.
Local volume roles contain no user path; peer headroom contains only free
and floor bytes and a missing/unknown field refuses disk-heavy placement.
Critical write checks use a fresh destination/nearest-existing-ancestor
reading and name that volume in the localized refusal. All 14 tables have
real translations. The Model API/CLI never provides these local readings.

## Integration contracts and outstanding receipts

- **U/H/W watch roots:** supply `ResourceHostSettings.diskTargets` for
  workspace, worktree parent, data, logs and optional node state. The
  default factory can watch the actual OS temp volume without guessing
  VS Code's workspace or runtime state locations.
- **C2/H safe points:** call `resourceSafePoint` between background lane
  operations. It never suspends or kills a process mid-write. Cancel and
  host disposal reject the wait immediately.
- **Agent write adapters:** call `assertResourceWrite` after their final
  permission/identity checks and immediately before writes, excluding the
  checkpoint that saves a pause and user edits. The SDK's internal Muse
  Code writes remain outside the harness's adapter, as in D87.14's residual.
  The tool-write region is outside DK's granted spawn-environment region.
- **W registry recovery:** supply/discover per-harness `registryFile`
  manifests in app data. Roots with durably proved exit can honor retention
  after reload. A crashed harness's unknown active owner remains protected
  until T supplies exact whole-tree completion; absence of a PID is never
  substituted. Archive/dirty checks for worktrees and dependency copies
  require M96c/M109's injected proof.
- **M100/R:** adopt `deviceResourceSchema.diskFree` and
  `hasDeviceDiskHeadroom`; unknown or below-floor devices must refuse
  disk-heavy routing. No new guessed offer/dispatch wire shape is authored.
- **Lane 0:** capture per-OS leftovers, including actual macOS code-sign
  clones, and prove their creating registered tree through
  `CreatedPathProof.createdByTree`. No per-user cache sweep is inferred.
  Run the killed-browser receipt on the Mac mini; Kubuntu cannot certify it.
- **W manifest/help:** contribute machine-scoped
  `museSpark.resourceDiskMinFreeGiB` with a null/default adaptive floor,
  minimum 2 GiB, using `resourceDiskMinFreeGiBDescription` in every manifest
  table. There is no `featureCatalog.ts` on this base; add its feature and
  regenerate the help reference when that owner integrates. U consumes
  `sample.diskVolumes`, `resourceDiskFree`, and the localized refusal.

The registry checks exact native file identity through the existing
`fileIdentity.ts` and rejects changed roots, symlinks and noncanonical
aliases. Same-user concurrent directory replacement after the final check
is an explicit Node path-removal residual; it is not a claim of race-free
fd-relative deletion. No secrets or process identity enter public status,
peer disk headroom or resource events.
