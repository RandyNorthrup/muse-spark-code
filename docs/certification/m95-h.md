## Review of the inherited, uncommitted Muse work

Kept the codec's data-driven preset interface, native request types, pure
encoding, streaming decoder and capture-based request/stream tests for all
eight captured Chat presets: OpenRouter, Groq, Mistral, Together, Fireworks,
DeepSeek, Hugging Face and Z.ai. No inherited file was out of scope; none
was removed.

The initial test run was 37 passed / 6 failed (43 tests). Fixed:

- OpenRouter duplicated reasoning from `reasoning` and `reasoning_details`.
  Details now take precedence; fragments with the same index and type are
  assembled in arrival order, retaining their unknown fields. The assembled
  block matches the captured follow-up and is replayed in its original order.
- Replay was bound only to a preset, allowing it onto another model. The
  opaque payload now names the configured provider and native model. Both
  must match; reasoning on earlier plain assistant turns also survives
  DeepSeek's every-turn rule. Other history is retained on a switch.
- The rolling-breakpoint test incorrectly required the old marker to stay;
  cached message content now keeps the same text-part shape as the marker
  moves. The system block and last text block are marked for Anthropic
  routes; Gemini routes mark only the last text block. A drill revealed that
  the old test did not assert the last markers: explicit assertions were
  added, and the same mutation then failed.
- Two expectations contradicted captures: OpenRouter's answer contains
  U+202F, and Groq reports eight reasoning tokens. Both now preserve the wire.
- An unrelated JSON object could open a response. Chunk presence and zod
  validation now guard it. Initial response events carry the captured id and
  model; malformed usage cannot discard valid deltas.
- Split opening thought tags leaked into the answer. Tags now survive every
  split boundary, including unfinished thoughts and ordinary partial text.
- Missing indexes needed both appearance-order and native-id fallback;
  float indexes truncate. Tool order and argument fragments stay stable.
- Empty/truncated streams previously completed successfully. They now end
  incomplete; length and filtered stops retain their distinct outcomes,
  and later chunks after an error are ignored.
- Cache-write counts and Mistral's flat error code were lost. Both are kept.
  Invalid usage, derived-count overflow and negative cost stay unknown;
  a provider cost is exposed only with valid usage, and cached input clamps
  to input. The captured cost settles without an estimate.
- Frame, total-stream, argument and output-item caps were absent. They are
  mandatory injected decoder limits, with UTF-8 byte accounting. Limits are
  positive safe integers; violations emit an explicit failed response.
- Strict type/lint failures, missing canonical `strict: false` in fixtures,
  readonly-array writes and unvalidated casts were corrected. Unchecked
  casts were removed rather than adding escape hatches. The filtered-turn
  message reuses `UI_TEXT.turnFailed` at runtime.

## Acceptance and integration seam

The 60 tests cover M95 acceptance 2, 4, 11, 12 and the codec portions of 13:
all eight preset request/tool-loop goldens, decoding text/reasoning/tools,
usage and actual cost; fixed bytes and growing prefixes; no empty tools or
hosted search; reasoning switches; routing, attribution and breakpoints.

Lane P/T supplies the real preset quirks; this lane adds no production
preset stand-in. `encodeChatRequest(body, nativeModel, quirks, options)`
returns only codec headers and the native JSON body. The transport supplies
path, auth, origin binding, redaction and HTTP error/retry handling.

`new ChatStreamDecoder(nativeModel, quirks, limits)` and
`decodeChatStream(payloads, nativeModel, quirks, limits)` require
`{frameBytes, streamBytes, argumentBytes, outputItems}` from the shared
constants owned by the integration lanes. Feed raw SSE data strings in
production to count their original bytes; parsed capture objects count
serialized JSON bytes. The SSE reader still needs to cap its framing buffer.

For configured providers, set `quirks.providerId` to the configuration id;
its built-in default is `presetId`. Replay also binds the exact native model.
Lane I keeps the complete tool declaration during compaction and projects
ObservationPack before encoding. OpenRouter breakpoint mode is selected
from the actual upstream route. Cache-write data is retained on the runtime
usage object; lane P's canonical `Usage` addition must expose that field to
callers. No shared schema, registry, transport or bundler file was edited.
