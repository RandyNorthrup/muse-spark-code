# M42 certification — replay as Meta validates it (PLAN.md M42, D35)

Recorded 2026-09-25.

A full read of Meta's Model API documentation for the parity audit found the
Model API backend breaking three documented rules of a client-built
conversation, and missing two retry rules. None had been seen live: there
has been no Model API key since 2026-09-22, and the fake API followed our own
assumptions. The tests below are written from the documented shapes.

## What changed and how it is tested

| Rule (Meta's docs)                                                                     | Test                                                                                 |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| Text before a tool call is replayed with `phase: "commentary"`, a final answer without | A narrated tool call, then a later turn: the replayed messages carry exactly that    |
| A replayed reasoning item carries `summary`, `[]` when none came                       | Reasoning without a summary field is replayed with `summary: []`                     |
| A reasoning item is followed by a message or a call before the next user message       | A reasoning-only reply is followed by the minimal assistant message, then the user's |
| A stream ended by `server_shutting_down` (and two more codes) is sent again whole      | The retry notice appears, the turn completes, only the retried reply is replayed     |
| Any other stream error ends the turn                                                   | `invalid_prompt` fails the turn after one request, no retry                          |
| A 502 is retried                                                                       | A 502 then a reply: two requests                                                     |

## Drills

| Drill | What was broken                         | Result   |
| ----- | --------------------------------------- | -------- |
| P1    | Commentary replayed as a final answer   | 1 failed |
| P2    | Reasoning replayed without its summary  | 1 failed |
| P3    | No reply after reasoning alone          | 1 failed |
| P4    | A retryable stream error fails the turn | 1 failed |
| P5    | A 502 is not retried                    | 1 failed |
