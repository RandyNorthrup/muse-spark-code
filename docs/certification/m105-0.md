# M105 lane 0 certification

Kubuntu, 2026-10-05; branch `m105/l0`, base `1262a926`.
Read the rig brief, shared common rules, AGENTS.md, PLAN D85 and M105 in
full, and the coverage audit. The rig brief overrides the old common merge
instruction: no merge, rebase or push. No dependency or credential access.

## Delivered contracts

- Portable `MediaInfo`, chip, upload-state/reference and cost-estimate schemas.
  Unknown duration/sound is explicit; metadata rejects content fields.
- Host-issued attachment-token request, audio actions and contributor choices;
  the existing attachment summary gains an optional media region. Existing
  image/PDF/text payloads keep their bytes and shape.
- Companion completion response with an opaque token, not a path or bytes.
- Recorder driver interface: explicit per-recording sound choices, bounded
  options, Stop/Cancel, preview and disposal; no implementation or tool is
  registered by this lane.
- Generated ISO-BMFF, QuickTime, RIFF, MP3 and EBML header fixtures; no binary
  assets. The loopback Files fake accepts injected bodies and follows the
  U6 multipart/expiry, retrieve/list/content/delete transport behavior.
- Capture summary and four upstream drafts; see `m105-captures.md`.

## Required integration and evidence

This base has no `src/core/providers/capabilityRecord.ts`,
`src/shared/usageJournal.ts`, or `src/shared/hostApi/`. No substitute M95,
M102 or M104 implementation is created. The lead must supply those contracts
and scrubbed raw U6/video frames before their record groups, units, MHP
methods and complete wire parsers can be updated. The summary is not a raw
wire capture. Storage billing remains unknown; no upload default is chosen.

`mediaAttachmentUpdateSchema` is deliberately a standalone contract. Adding
it to the host-message union requires a reducer handler in
`src/webview/state/uiState.ts`, owned by another lane. The attempted union
addition failed webview typecheck (TS2366) and was removed; lane E1 wires
that message and handler together. No other lane's files were edited.

Lane W owns README, CHANGELOG, package.json and bundle regions. The lead's
CHANGELOG entry should say: “Added portable multimodal metadata, upload and
recording contracts, generated media fixtures, and localized media wording;
provider and editor wiring remains in the M105 delivery lanes.” No command
or setting is advertised as available by this contracts-only delivery.
