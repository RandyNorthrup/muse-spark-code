## Native behavior

The app embeds the companion launch page in a nonpersistent WKWebView, starts a
credential-scrubbed runtime in its own POSIX process group and drains stdout
without logging it. Launch links are strict loopback URLs with code fragments;
the shared bootstrap removes the fragment and owns the bearer in its fetch
closure. The app discards its launch link after loading it. Other origins are
blocked. Stop is an unconditional app/menu-bar/toolbar/keyboard action and
terminates the process group, escalating after two seconds. App termination
also stops the runtime.

XcodeKit commands deliver one buffer/selection over a per-invocation loopback
callback. A 256-bit one-use launch code is exchanged for a separate 256-bit
bearer before context is returned. Only a matching bearer and invocation/digest
can return an edit. Unknown keys/types, oversized frames, bad positions and
multiple selections fail explicitly. Approval is in the app; the original
buffer and selection must still match. Replacement preserves UTF-16, Unicode,
LF/CRLF/CR/Unicode line endings and applies in one command transaction. Cancellation
closes the callback. XcodeKit commits/undo semantics are from the installed
SDK's `XCSourceTextBuffer.h`; actual editor acceptance/undo still needs the
owner's extension enablement.

The app does not read the OS credential store. Runtime and xed launches strip
all `*_API_KEY` and the shared named credential variables. Other descriptors
are closed before runtime exec. There is no app-group entitlement, token file,
clipboard token, cookie, UserDefaults credential or raw runtime output log.
Native labels are generated from all 15 shared tables; tunables and the native-only
English model block are generated from shared constants. The JS split gate
refuses that block in any shipped JavaScript bundle.

## Verification receipts

Initial compiler/project mistakes were corrected before qualification. The first
core run exposed blocking Foundation pipe reads: a launch line was buffered while
the process stayed alive. POSIX read now delivers partial pipe data immediately;
workspace/env and process-group tests pass. App-hosted UI evidence also exposed a
real Stop bug: same-origin navigation rejected the internal blank document. Blank
navigation is now allowed only while disconnected, clearing the page after Stop.

The separate XCUITest runner failed ad-hoc library validation. Two attempted
project-setting edits did not actually apply because the generated keys were
unquoted; this is an implementation mistake, not evidence that the entitlement
would fail. That route was stopped under common.md's two-fix rule. Final UI
coverage uses an app-hosted XCTest bundle; there is no skipped UI test or widened
product entitlement. Generated test-plan paths avoid Xcode's unexpanded scheme
`$(PROJECT_DIR)` environment values. Early failed runs remain failures.
