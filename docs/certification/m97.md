## Integration changes

- `src/host/ide/legalScanEntry.ts` admits the explicit workspace through S's
  bounded read-only snapshot and scanner, validates inputs, installs the
  caller's display table and refuses queued cancellation before returning.
  Both host backends and the runtime load it as `dist/legalScan.js`.
- The Model API manager forwards the runner to its workspace host; trial
  worktree hosts do not inherit the parent workspace scanner.
- The translated command-palette entry routes an active conversation's
  `requestLegalScan`; the existing slash palette and prompt route the same
  request. Report metadata now shows distribution/exclusions and uses Intl
  percentage/number formatting.
- Build/split/host-global/package gates cover the new lazy bundle. D6's
  proposed scanner cap is 150 KiB, from the 130,608-byte S probe plus 15%,
  rounded to 25 KiB. Existing caps stay unchanged. Identifier data is bundled;
  separate notice/provenance files ship, and the ACP package retains the data.
- The universal VSIX initially exceeded its cap by 7,758 bytes. Maximum
  DEFLATE compression, using Python's standard-library zipfile, preserves
  every entry's bytes/order/metadata and the archive comment. The package
  script applies it without changing the 2,252,800-byte budget. Archive tests
  exercise executable metadata and license preservation.
