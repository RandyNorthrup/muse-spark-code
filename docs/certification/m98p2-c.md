## What the adapter does

`createSystemOneJudge` is opt-in and does no I/O at construction. Two
frozen presets sit beside `PRESETS` (still length 18), not inside it:

| Preset           | Key provider | Origin                    | Path                | Wire capture | Request models                                        |
| ---------------- | ------------ | ------------------------- | ------------------- | ------------ | ----------------------------------------------------- |
| `openrouter-jev` | `openrouter` | `https://openrouter.ai`   | `/api/v1/systemone` | true         | `typesafe/jev-1.13`, `~typesafe/jev-latest`           |
| `typesafe-jev`   | `typesafe`   | `https://api.typesafe.ai` | `/v1/systemone`     | false        | `jev-1.13.0`, `jev-latest` (resolves to `jev-1.13.0`) |

`jev-preview` is not a row. Clef is not a preset, not a capability, and
has no parser. No origin contains `cloudflare`. Each row is frozen with
`tested: false`, `optIn: true`, `autoSelectable: false`. A success or a
failure does not rewrite those labels. Input is $0.042 per million
tokens. Output is $0. State plus the longest question is 32,000 tokens.
The whole request is 64,000 tokens. Both limits use the existing judge
constants.

Policy runs before a key, a reservation, or a send, in this order:
switched off (`explicit-off`), confidential workspace
(`confidential-refused`), anything other than `explicit`
(`source-untested`), declined consent, missing consent. An unknown
preset is `source-unavailable`. A model that is not on the capability
row, or a request model that disagrees with the selection, is
`capability-unavailable`.

The sent JSON is exactly `{state, model, questions}` for the selected
model. `redactSecrets` walks state and questions before that body
exists. Question ids are map keys and are not copied into state. The
key is a transport argument. It is not a JSON field, a result field, or
a log field. There is no caller-supplied URL.

The uncached input price is reserved before the send:
`(measuredBodyTokens * 0.042) / 1_000_000`, with output tokens reserved
as 0. Settlement uses reported `input_tokens` and `output_tokens` at the
same rates. Output stays free, so 20 output tokens add $0. If the
reported cost is above the reservation, the call is `engine-failure`
with no settle and no refund. A known non-send refunds (missing key,
local failure before `post`, caller abort or deadline before `post`,
config fingerprint change after reserve). A send that then fails stays
a liability: non-200, a thrown `post`, a parse error, a settle error.
Only HTTP 200 is parsed. Error bodies are not answers. There is no
retry.

The common wire is the captured shape: `model`, `answers`, and
`usage.input_tokens` / `usage.output_tokens`. Missing or malformed usage
is `systemone-usage`. The response model must be the request id or that
row's recorded resolution target. Noul may omit `probabilities`; the
adapter then stores `{true: noul, false: 1 - noul}`. Present
probabilities must be exactly `true` and `false` and must agree with
`noul`. Choice and score reuse the P0 schemas (A–Z, 2–26 keys; score
levels 0–10). A shifted legend, an extra probability key, or a choice
that is not a heaviest key fails closed. Top-level additions other than
`model`, `answers`, and `usage` pass through `judgeResultSchema`.

`muse.confidence` is local entropy, `1 - H / ln N`. Choice and score
keep the vendor number as `vendorConfidence`. Noul has no vendor
confidence. The prototype `|2p - 1|` is not our confidence.
`applySystemOneGate` copies the deterministic `passed` flag and its
checks, sets `cautionOnly`, and sets `advisory` only when the outcome is
`answered`. A safe noul does not clear a failing check. A high score
does not fail a passing gate.

Fixtures in `test/unit/fixtures/judgeSystemOneCaptures.json` replay named
shapes. The TypeSafe rows are the docs.typesafe.ai examples read
2026-10-06, not a live frame. The OpenRouter row uses the 2026-10-04
record for the served model `typesafe/jev-1.13-20260917` and 491 input
tokens. That record did not include `output_tokens`, so the fixture uses 0.
No `cost` field is parsed. 491 input tokens settle at $0.000020622.
The documented TypeSafe noul (296 input, 20 output) settles at
$0.000012432, which is below a 491-token reservation.
