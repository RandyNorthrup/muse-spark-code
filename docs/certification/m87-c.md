## Decisions taken here, for the lead

1. **The summary's list is a conjunction list, not D66's `unit` one.**
   `Intl.ListFormat` `type: 'unit'` joins with bare spaces in Turkish,
   Japanese, Korean, Russian and both Chinese tables ("X1 X2 X3"), which no
   list of actions reads as, and the acceptance asks for German, Turkish and
   Japanese to be grammatical. `type: 'conjunction', style: 'long'` gives
   "Edited 2 files, ran a command, and read 3 files", "… und …", "… ve …",
   "…、…、…". Measured on Node 24.20 / ICU for all 15 locales before the
   change; the `list-unit` drill shows the tests fail under D66's options.
   PLAN.md D66 and M87 C2 still say `unit`: lane W's to amend.
2. **Step-summary forms start lowercase.** The cs, de, pl and ru tables
   began each form with a capital, which reads wrong mid-list ("Eine Datei
   bearbeitet, Einen Befehl ausgeführt"). Only the first letter changed
   (104 forms; German nouns keep theirs); a test checks every shipped table.
3. **Muse Code sessions now have `withdrawQueued`**, so the controller keeps
   their steers for an Edit too; the backend answers a steer `tooLate`
   without a command, and the panel shows the delivered note instead.
4. **A Model API queued turn taken back ends with `turnWithdrawn`** carrying
   `UI_TEXT.turnUnqueued`, as Muse Code's `turn/unqueued` does; a steer
   emits nothing (lane P's warning). `messageAdmitted` is emitted for steers
   only: a queued turn's `turnStarted` already ends its card's queue.
5. **The queued "…" is always shown**, not on hover: the rewind and copy
   buttons are `visibility: hidden` until hover or focus inside the card,
   which Tab cannot reach; the queued card's menu must be reachable.
6. **A pending card's time is set when the host accepts it**: the
   `submitted` action carries no `at` and App is lane W's.
7. **Edit rows inside a folded group** fetch their patch only once the group
   opens (they are not mounted before), as a collapsed row already did.
