## Composition and adapter

`src/host/compose/conversationDeps.ts` assembles the complete existing
`ConversationDeps` from frozen `HostServices` and explicit feature/state
ports. `src/extension.ts` calls it with
`createVscodeHostServices(context)` from `src/host/vscode/hostServices.ts`.
Neither the frozen contracts nor existing settings/defaults changed.
Implementation and tests are committed as `a9c98ded`, with hooks on.

The composition preserves existing feature objects/callbacks and extracts
clipboard, save-all, external links, folder opens, confirmations, live
settings, paid/key/consent guards, voice budget ownership, board traversal,
Best-of-N edit admission/accounting and verify guidance. Confirmation uses
the stable numeric choice id, never a translated title. UI text is read
when an operation runs. Project trust includes the existing worktree hold.

Sync editor/trust/dirty-document snapshots and the original Insert/Apply
callbacks remain explicit ports. MHP requests are async; its selection range
also lacks the directed active caret and notebook inventory needed to replace
those callbacks without changing VS Code behavior.

The in-process VS Code adapter validates parameters and results against the
frozen method schemas. It supplies native workspace/document/editor/diff,
diagnostic, UI, settings/storage, GitHub-auth boolean and window primitives.
Versioned mutations refuse stale versions, distrust and invalid ranges;
trust is rechecked after document-open awaits, and edits after editor-show
also recheck version/trust. Apply-edits uses one editor transaction with
undo boundaries. Failed edits/saves and cancellation are explicit failures.
Selection excerpts use the frozen limit. Settings/storage refuse credential
names, credential environment entries and recognized secret-shaped text.
The adapter receives only global/workspace Mementos, never SecretStorage.

Existing specialized drivers remain explicit feature ports. Optional native
method/notification bindings pass the same schema validation; unbound methods
return typed unsupported-capability errors. Initialization declares only the
mandatory lifecycle group, not complete editor/event groups. Cancellation of
an in-process request uses its AbortSignal; carrier request-id cancellation,
notification routing and full native capability/event qualification belong
to the carrier/editor integration. This does not advertise a complete native
MHP transport or runtime panel.

## Exact handoff to B

Entry point:

```ts
import {
  composeConversationDeps,
  type ConversationCompositionPorts,
  type ConversationFeaturePorts,
} from '../../host/compose/conversationDeps'

const deps = composeConversationDeps(host, ports)
```

Signature: `composeConversationDeps(host: HostServices, ports: ConversationCompositionPorts): ConversationDeps`.

The runtime caller supplies these ports; the exported types are authoritative:

| Port               | Runtime responsibility                                                                                                                                                                                                                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `host`             | Validated frozen HostServices backed by native/editor/LSP adapters or the declared runtime fallbacks; async clipboard, save-all, confirms, external/folder opens                                                                                                                                                       |
| `features`         | The existing controller's surface/Tasks surface, auth and backend selection, root/files/mentions, editor snapshots and Insert/Apply, sandbox, hooks, reviews, Git/worktree/checkpoints, plans, sessions/memory, exports/imports/reports, account/usage, notifications, board prompts/coordinator, clock/path/log ports |
| `settings`         | Live schema-backed settings snapshot, using B's runtime store; do not cache mutable settings at composition time                                                                                                                                                                                                       |
| `paid`             | The real paid gate, per-use consent and usage accounting; runtime defaults/admission remain governed by the existing ACP/headless policy                                                                                                                                                                               |
| `modelApi`         | Account id, host/budget ownership, external-edit recorder and attempt-host operations from the shared backend manager                                                                                                                                                                                                  |
| `isKeyStored`      | Availability boolean only; credentials remain in the existing credential-store lane                                                                                                                                                                                                                                    |
| `museVoiceSetup`   | Runtime voice driver or an explicit unavailable result with its reason                                                                                                                                                                                                                                                 |
