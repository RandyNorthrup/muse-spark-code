## Readiness and implementation

The existing `PLAN.md` D66 and M87 acceptance, lane ownership and lane 0
strings were reviewed before implementation. `state.context` already supplies
the reported window, used tokens and uninterpreted pressure word; no new wire
field is needed. Reused Composer's compact handler, Palette's registry and
keyboard handling, MenuOption, token-window formatting, the Intl helpers and
the existing 70%/90% thresholds. ContextMeter is the one new production
component, responsible for drawing and describing the ring.

- **Item 1:** a 22 px SVG ring in a 26 px button, filling clockwise from the
  top. The whole number sits inside, without a percent sign, at 10 px (9 px
  for 100). It floors the share, shows `<1` for positive usage below 1%, caps
  the drawing and visible number at 100, and gives the actual whole share,
  reported token detail, pressure and exceeded-window note in its name/title.
  A missing or zero window hides the ring. Click keeps compact.
  The SVG has an editor-background circular plate: Dark Modern's composer
  input background is `#313131`, so the plate preserves the 3:1 arc floor
  measured against `#1f1f1f` in D66 while keeping the specified progress token.
- **Item 7:** registry tips use lane 0's installed-language table at call
  time. Skill descriptions are trimmed; blank/empty descriptions use the
  named skill fallback. Slash commands carry the same tip. Pointer titles and
  `aria-describedby` refer to the same text; description spans are hidden
  from the accessible name. Model choices and the disabled usage row also
  have tips. Loading/empty skill notes remain the planned exceptions.
- **Item 8:** Stop has `send-button-stop`. Hover and keyboard focus use the
  charts red token; both high-contrast themes use an error-coloured icon and
  border with a transparent background. Send retains its own styling.
