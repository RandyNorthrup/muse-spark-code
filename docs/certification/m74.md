## What was built

- `/handoff`, optionally with a goal after it (`/handoff Ship it Friday`),
  as a palette row, a slash-menu entry (Enter and Tab ready `/handoff `
  for the goal) and a prompt parse (`src/shared/handoff.ts`).
- The host asks the model, as the user's own turn in the current
  conversation, for a distilled brief (goal, decisions, files touched,
  open work, todo list). The request turn's card stays in the transcript.
- The brief opens in a dialog before anything starts: review it, edit it,
  then **Start new conversation**, or **Cancel** and nothing starts.
- Starting seeds the new conversation through M79's `startFromBrief`
  path (`ConversationBrief`, one path, no duplicate): the brief alone is
  the first message, the goal and the open items travel in the model's
  note, and the open items (never completed or dropped ones) become the
  todo list before the first request. The old conversation stays in
  History.
- Untrusted content stays labelled (D49): the request makes the model
  mark tool-output, fetched-page and imported-file content `[untrusted]`
  in the brief, and the seeded note tells the new conversation what the
  label means.
- Model API backend only: on Muse Code the command says it is unavailable
  there. Side chats are refused; one handoff runs at a time; a `/handoff`
  while a reply runs is refused ("Wait for the reply to finish, or stop
  it, first."; nothing waits or queues); an oversized (over 256 KB) or
  empty brief is refused with the reason.
- Sixteen UI strings in the English table and all fourteen `l10n/ui.*.json`
  tables with real translations (`/handoff` itself stays English in
  `untranslated.json`, as `/compact` does); six English-only model texts
  (`MODEL_TEXT`).
