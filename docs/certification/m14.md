## What the milestone rests on

- Muse Code's MSP schema for subagents (PLAN.md D17): a `subagent` item
  carries `role`, `objective`, `subagentId`, `childSessionId`, `depth`,
  `durationMs`, `controlStatus`, transitive `usage`, a `result` with
  `summary`, `text` and `errorKind`, and `agentPath`; a backgrounded
  `toolCall` arrives as `item/updated` with `background: true` and
  `backgroundInitiator`; a child session is read with `session/read` on
  its `childSessionId`.
- Muse Code 1.3.0 hides its subagent tools unless
  `run.subagent_delegation_mode` is `"auto"` in its settings file
  (`$XDG_CONFIG_HOME/muse/settings.json`, else `~/.config/muse/settings.json`).
  The CLI's own message when it is off: "Agent delegation: off; native
  subagent tools are hidden." The owner's file holds only `schema_version`
  and `tui`, so delegation is off on this machine.
- The CLI's trace logs (M13): the turn's own run is the one named by
  `runtime.run.lifecycle run_kind="turn"`; every other run in the file is
  one the CLI started. In the 2026-09-22 drill log the reminder runs
  register 1 tool each and the turn's run about 30, which is the basis of
  `classifyRun` (≤ 2 tools: reminder; otherwise a subagent).
- Meta's Model API prices (dev.meta.ai/docs/pricing-rate-limits, read
  2026-09-22): standard $1.25 input, $0.15 cached input, $4.25 output per
  million tokens; contributor $0.10, $0.002, $0.20. The estimate in the
  modal says so and names the dashboard as the bill.
- The M5 mechanism for hidden text parts: the note rides as its own text
  part and `displayText` keeps the typed text, so the transcript shows what
  the user wrote.

## Process-level drill (the fake CLI, real child process)

backgrounded tool call": the `subagents` scenario starts two subagents
(`explorer`, `verifier`), completes them with usage and results, backgrounds
a shell call mid-turn (`background: true`, `backgroundInitiator: 'user'`),
and answers `session/read` for each child session with that child's
transcript. Asserted: both subagent items reach `completed` with their
child session ids; the backgrounded call's flag on the parent; each child
session readable through the real `MuseCodeBackendManager`.

## Live verification

Not run. A live subagent turn needs `run.subagent_delegation_mode = "auto"`
in the owner's Muse Code settings (the extension never writes it) and a
prompt that makes the model delegate; on the 2026-09-22 measurement a
reply-only turn already costs 31 model attempts, and a turn with two
subagents is estimated at 60 to 100. It waits on the owner's yes. The
fake-driven e2e covers the wire shapes; the parser is tested against lines
copied from the drill log of M13.

## Security

- The CLI's settings file and its trace logs are read, never written; the
  insights posted to the webview carry counts, percentages and timestamps
  only, never prompt text or session ids.
- The steering note is a fixed string; nothing from the user or the model
  is interpolated into it.
- A child session is read through the same host command as History; the
  Model API backend answers from its own stored transcript.
- The settings file opens in an editor through VS Code; the extension
  offers no field to edit it from the panel.

## Findings recorded during the milestone

- The reminder runs and subagent runs are told apart by their registered
  tool count; the heuristic is labelled approximate in the modal, as
  Claude Code labels its own.
- Meta does not publish the prompt-cache lifetime, so no "warm for N
  minutes" countdown; the cache-hit rate is shown instead.
- `MUSE_DELEGATION_SETTING_PATH` was added and removed in the same
  milestone (knip: unused export); the path is computed by
  `museSettingsPath`.
