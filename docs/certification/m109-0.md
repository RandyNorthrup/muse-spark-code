## Validation and deliberate failures

The final owned suite has 91 distinct tests: contracts (19), digest (6),
fakes (13) and boundaries (53). The first three files run as one batch and
boundaries runs separately, each with `--maxWorkers=3 --testTimeout=120000`.

[Detailed mutation receipts](m109-0-drills.json) record 144 deliberate failures:
90 individual refinements, bounds and encoding checks; 38 strict-schema,
authority, digest, ownership and route mutations; 16 final channel, shared
encoding, store, broker, SSH and CDP guard mutations. Every mutation produced a
named assertion failure. Each file was restored in `finally` and its SHA-256
matched the pre-mutation bytes. The hash identifies each drill's source
snapshot, including earlier validated revisions before additive changes.
Two defensive SSH string-boundary guards were inverted rather than removed,
because later parser checks also reject malformed fields; the valid-session
assertions then failed. No mutant survived the final passes. All tests use the brief's direct command
and at most three files; none is skipped or filtered.

The initial pass revealed missing edge cases and redundant checks. Boundary
fixtures were added. z.int already supplies the safe-integer bound; handle
format plus name equality enforce the name; local hour ordering supplies the
coupled bounds. Final independent mutations all failed. No gate or security
condition was weakened. The CDP origin mutation initially survived because
both the origin and frame guards caught the same fixture; a changed top origin
with the approved frame origin now proves that guard independently.

The oversized base64 fixture first raised RangeError from the repeated-group
regex. The regex now uses a linear character/padding check plus a group-length
check; maxLength aborts subsequent checks. The same large and malformed inputs
then passed their rejection tests. Argv handles and approval TTL are bounded.

These fakes prove harness behavior, not runtime security. B/C/P/S/X/T/L/O/M/U/
H/R/W own runtime enforcement, native captures and integrated adversarial
drills. Full quality is lead-owned under the explicit rig rules; this is a
lane handoff, not a proposed release.
