## Address and frame boundary

Addresses use lane 0's private literal schema plus Node's IP syntax check.
Chosen binds must belong to an actual local interface. Every hostname lookup
checks all answers, rejects empty/oversized/mixed-public answers and loopback
substitution, then hands TLS a checked literal. Mapped IPv6, metadata,
wildcards, URLs, zones and public destinations are refused. Manual literal
entry needs no discovery or DNS. These are connection checks, never attempt
retirement or liability settlement.

The authored version-1 transport is newline-delimited UTF-8 JSON over TLS.
It caps bytes before concatenation, UTF-8 decoding, JSON and zod; rejects
invalid UTF-8, duplicate keys (including escaped spellings) and excessive
nesting; validates complete strict envelopes and bounds the ready queue.
Outgoing frames also have schema and UTF-8 byte checks. Unknown versions use
the fixed `incompatible` reason; peer input/errors are never reflected.
No upstream Muse/provider wire shape was added. The nesting stack uses the
existing 32-frame resource ceiling; no new tunable or shared constant edit.

## Integration handoffs

- **P pairing:** inject confirmed, durable per-pair certificates/private key,
  exact fingerprints, stable pair id and the channel's receiver incarnation.
  Re-read `isActive`/`isOffered` from current local state. `revoke(pairId)`
  closes that pair's listener and sockets; keys never reach a child or wire.
- **E receiver:** bind the channel's receive/disconnected port to actual
  receiver admission and durable disconnect handling. Authentication is not
  an execution/paid grant; disconnect never settles work or frees liability.
- **I discovery dependency:** lane 0 selected no mDNS implementation and the
  brief prohibits adding a dependency not named by the plan. Bind the explicit
  injected `DeviceMdnsPort` to a reviewed lazy DNS-SD implementation. It must
  bind only the chosen interface, decode only admitted bounded packets,
  advertise the rotating opaque service id/port/version only, withdraw on
  close, and expose no proxy, credentials, hostname or additional TXT fields.
  There is no fake/default production implementation or claimed live mDNS
  qualification in T. Manual TLS works independently of that binding.
- **I product:** lazy `dist/devices.js` inclusion and `DEVICE_MODEL_TEXT`
  reader registration, manifest/help/README/CHANGELOG/security/privacy and
  delivered-feature claims remain I-owned. No new command/setting or visible
  ordinary-chat feature is registered here. Carry equivalent unsupported-host
  reasons to ACP/headless and other editors under D80.
- **I rigs/floor:** Node 20.18.3 and installed four-device tests, routed
  multicast-blocked/manual success, default/denied OS firewall outcomes and
  true missing-route cases need installed-host evidence. Local loopback
