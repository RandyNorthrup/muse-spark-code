successful command still exits 3.

nothing could have been registered without consent (every register saves
consent first). Explicit `decide`/`firstSchedule`/`remove` paths still call
`entry.remove()` and surface errors. Red-first regression
`test/unit/scheduleBackgroundReconcile.test.ts` (4/4; the no-consent case
counted one removal before the fix). A restructure follow-up (`b6cc6cf2f`)
replaced the temp-dir boilerplate jscpd flagged as a clone of
`scheduleStoreRoot.test.ts` with per-test `onTestFinished` cleanup.
