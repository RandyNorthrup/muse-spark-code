## What landed

- `src/shared/constants.ts`: `TeamAgentSwitch` joins
  `EXTENSION_HOOK_EVENTS` (M91's region; no agent owns the name, so it stays
  out of the import tables).
- `src/core/backends/modelapi/extensionHooks.ts`:
  - `TeamAgentSwitch` is name-matched (role ids), refusable and
    decision-bearing. Exit-2 and deny answers refuse; `allowedTools`,
    `displayText`, `answer`, `additionalContext` and `continue: false`
    answers fail, so a hook can never choose an entry (D70: no hook widens).
  - `teamAgentSwitchFields()` sends D75's wire payload: `role_id`,
    `from_entry_id`, `to_entry_id`, both agent profiles and models,
    `reason`, `measure`, `window`, `amount`, `used`, `task_id` and
    `parent_session_id` (absent caps and session are omitted, never nulled).
  - `teammateIdleFields()` keeps the best-of-N shape and adds D75's team
    fields (`teammate_name` is the task id) when a team task fires it. A
    block keeps the task working inside its own ceiling; the firing site
    re-admits before continuing.
- `src/core/team/teamPool.ts`: `TeamAgentSwitchPayload` gains
  `from_agent_profile`/`to_agent_profile` (the profiles' stable keys) and
  `parent_session_id`; `switchHookPayload()` takes the parent session id.
  New `teamSubagentStartFields()`/`teamSubagentStopFields()` send M51's ids
  (`subagent_id`, `child_session_id`) with D75's fields (`agent_id` is the
  task id, `agent_type` the role id, plus role, entry, profile, provider,
  links, workspace mode, branch, working-copy path, pipeline, depth, model
  and provider). Paths are workspace-relative with `/` separators on every
  platform.
- Tests: new `test/unit/teamHookEvents.test.ts` (5 cases); `teamPool` switch
  payload expectations extended; `extensionHooks` gains the team
  `teammateIdle`/`teamAgentSwitch` payload, matcher, refusal and
  no-widening cases.
- Nothing fires the team events yet: `recordTeamSwitch`/`switchHookPayload`
  still have no production caller, and the team host has no hooks seam.
  Switch detection, refusal-exhausts-role and the Model API dispatch binding
  belong to lane X ("the wiring"). Teams stay hidden behind `museSpark.team`.
