## Implemented component

`createTabHooks` requires an explicit injected M91 dispatcher (`TabHooksDeps.run`)
and live trust, hook enablement and configuration version. No default or fake
production runner exists. Its `TabHookRun` contract requires configured-hook
selection using `TabRead`/`TabWrite`, Cursor adaptation, M51's shared process
cap, scrubbed environment, output cap, process-tree kill and a per-command
maximum timeout. Raw command results must be returned before fail-open or
onFailure handling; missing dispatch is `undefined`, not an empty success.
An empty result list means no matching configured hook.

- Read payload: the absolute path, full **unredacted local** text,
  workspace roots, request model and generation id. Serialized UTF-8 size,
  including the envelope, is checked before dispatch. Read commands receive
  the 1,500 ms maximum timeout. Only a strict exit-0 `permission: allow`
  succeeds; deny, exit 2, other exits, crashes, timeout, cancellation, invalid
  JSON/schema, missing output/dispatch and excess output all refuse.
- The path/content-SHA-256 LRU holds 128 promises, coalesces identical reads,
  refreshes hits and invalidates on configuration change. Denials have no
  time expiry while resident. In-flight results from old configuration and
  trust revocation refuse, and a stale completion cannot overwrite a new
  cache entry. As D73 specifies, model/generation changes alone do not change
  the cache key.
- Edit payload: bounded old/new strings and **line text**, the supplied
  1-based range, roots, model and generation. Four previews are each capped
  at 512 characters; omitted characters are counted without logging content.
  Full/partial acceptance is explicit; a typing event is ignored. Partial
  acceptance adds `inferred: true` to the local edit, and the Cursor adapter
  strips it. No output or exit can veto the accepted edit.
- The observation FIFO never waits in the editor callback. One batch runs;
  at most eight wait, and overflow drops/logs the oldest waiting batch.
  Trust/configuration changes or disposal prevent waiting dispatches. Logs
  contain fixed status words, exit/timeout/cancellation and byte/character
  counts, never source, completion, command, path, stderr or thrown messages.
- Cursor's two rows are extension-only, retain their original lower-case
  names and source citations, use the existing M91 table interpreter, never
  grant, and fail closed even with `failClosed: false`. Agent generation
  handling remains unchanged: only the Tab rows read `generation_id` directly.
