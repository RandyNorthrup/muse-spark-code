core redaction/counting; constants; English plus all 14 translations; the schema
script and two generated schemas; seven owned unit files and one shared test fixture.

F1: the raw budget uses `[0-9]+(?:\.[0-9]{1,6})?`, converted with BigInt digits directly
to integer micro-USD before any Number conversion. Range: 1–20,000,000 units.
`budgetMicroUsd` is canonical; `budgetUsd` is display only. Output identities
recover safe micro-USD integers before addition/comparison. Sub-micro output
amounts are refused. B must use integer comparisons and upward rounding of
sub-micro liabilities: contributor reservation $0.108135; image minimum $0.118135;
standard $1.409024/$1.419024. This is conservative, not an exact billing receipt.
F2's transport settlement payload and exactly-once transport behavior belong to B;
A preserves terminal/reason/usage/settlement in LastResponse and rejects priced
transport loss or completed results without latest verified completion evidence.

The result/event vocabulary is this application's own contract, not a guessed
provider frame. No provider wire parser changed. Synthetic faults and credentials
in these tests are test-owned, fabricated data; there were zero model attempts.

## How the binding decisions are built

- **D-M7 (one owner).** `lifecycle.mjs` `createLauncherOwner`: one stop latch, one
  current child, one SIGINT/SIGTERM pair. `phase()` and `child()` refuse after a stop;
  a stop forwards the exact signal to the current child, force-kills at
  `ACTION_KILL_AFTER_MS` (7 s, = exec grace 5 s + 2 s; equality tested), a repeated
  signal escalates at once, `ACTION_REAP_MS` bounds the reap. Every bound in SPEC §6.2
  is a named constant. Stdout (to a private file or memory) and stderr are capped while
  streaming; overflow latches `output_limit`. `cleanup()` stops and reaps a child still
  running, removes staging/temporaries within `ACTION_CLEANUP_MS`, zeroes stdin
  buffers and always drops the key/token references; a cleanup failure is recorded and
  leaves only private residue for tidy. run-exec's single owner spans the input diff,
  exec, extraction, patch Git, the scanner and publication; execCode (exec's own or
  128 + signal) stays separate from wrapper failure, and only an unstopped, unfailed
  wrapper may report `completed`.
- **D-M4 / M4 (one Git runner).** `git.mjs` `safeGit` is the only Git spawner. It
  prefixes `GIT_METADATA_OPTIONS` (source parity tested), core.fsmonitor=false, an
  empty private hooksPath, diff.external=, commit/tag.gpgsign=false, core.askPass=,
  credential.helper=, submodule.recurse=false, then re-lists filter driver names
  (clean/process/required plus smudge) before every command and suppresses them with
  gitFilterOptions' validation (parity tested; invalid names fail closed). Its
  environment drops every inherited `GIT_*` name and sets GIT_CONFIG_NOSYSTEM,
  an empty GIT_CONFIG_GLOBAL, GIT_ATTR_NOSYSTEM, GIT_TERMINAL_PROMPT=0,
  GIT_OPTIONAL_LOCKS=0 when read-only, and an http.extraHeader reset; a token is a
  one-command `AUTHORIZATION` header (via GIT_CONFIG_COUNT, never argv), refused
  unless the command is `fetch` (checkout) or `push`. Every child environment comes
  from `childEnvironment`'s allow-list (trusted Node dir and system PATH, locale,
  private home/temp/XDG, Windows system variables, caller proxy/CA) and never
  carries the key.
- **D-M5 / M5 (verified provenance).** `install.mjs` runs exactly
  `npx --yes npm@11.19.0 audit signatures --json --include-attestations --prefix <work/agent>`
  (trusted npx beside the trusted Node) and reads the predicate, subject, SHA-512
  digest (bound to the lock and registry `dist.integrity`) and the leaf certificate's
  URI SAN (Node `X509Certificate`, exactly one SAN) only from that record's

- **D-M6.** A binary diff (`GIT binary patch` / `Binary files … differ`, or non-UTF-8)

- **N2.** The key reaches only two children, over private stdin: `exec --key-stdin`
