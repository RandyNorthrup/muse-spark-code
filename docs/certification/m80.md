core redaction/counting; constants; English plus all 14 translations; the schema
script and two generated schemas; seven owned unit files and one shared test fixture.

F1: the raw budget uses `[0-9]+(?:\.[0-9]{1,6})?`, converted with BigInt digits directly
to integer micro-USD before any Number conversion. Range: 1–20,000,000 units.
`budgetMicroUsd` is canonical; `budgetUsd` is display only. Output identities
recover safe micro-USD integers before addition/comparison. Sub-micro output
amounts are refused. B must use integer comparisons and upward rounding of
sub-micro liabilities: contributor reservation $0.108135; image minimum $0.118135;
standard $1.409024/$1.419024. This is conservative, not an exact billing receipt.
F2's transport settlement payload and exactly-once transport behavior belong to B;
A preserves terminal/reason/usage/settlement in LastResponse and rejects priced
transport loss or completed results without latest verified completion evidence.

The result/event vocabulary is this application's own contract, not a guessed
provider frame. No provider wire parser changed. Synthetic faults and credentials
in these tests are test-owned, fabricated data; there were zero model attempts.
