## What this lane builds

`src/acp/teamContracts.ts`: pure frozen contracts (no `vscode`, no backend)
for the ACP team mapping PLAN.md M96b names — worker approvals as
`session/request_permission` with a title starting with the role and the
agent; tasks as `tool_call` updates (report as text content, diffs as `diff`
content); the merge as a permission request carrying the diff (plus its
Bypass completed-call shape); the agent map as a `plan` with one entry per
running task; and the `exec --team` admission contract. Grammar and
validation for `exec --team` live in `src/runtime/cliOptions.ts` and
`src/runtime/exec/execArgs.ts`. A valid `--team` request is refused out loud
(`execTeamNotReady`, exit 2) until the runner lane (C-M96b-2) admits it; it
is never run as a single session (no fake implementation, no silent
fallback). `serve --team` stays with C-M96b-1.

Wire provenance (AGENTS.md rule 14): every shape mirrors the installed
protocol definition (`node_modules/@agentclientprotocol/sdk/schema/schema.json`:
`ToolCallContent`, `Diff`, `PlanEntry`, `RequestPermissionRequest`,
`ToolKind`, `ToolCallStatus`) already exercised by `src/acp/translate.ts`
and `src/acp/agent.ts`. No new wire field was guessed; no live capture exists
yet because the feature does not run anywhere (C-M96b-1/2 capture against the
fake CLI/agent and fake Model API per PLAN.md M96b tests).

## Review pass (owner order 3)

- Validation/security: every inbound shape has a loose zod schema (D36:
  later wire additions arrive, never fail the parse); builders throw on
  empty/ambiguous ids, titles and contents. Permission titles forbid the `·`
  separator inside role/agent so a title parses back to exactly one triple.
- Failure paths/honesty: `--team` without Model API → `execModelApiOnly`;
  without acceptEdits → `execTeamNeedsEdits`; valid → `execTeamNotReady`
  (exit 2, mirroring the `execProviderNotReady` precedent). Nothing runs
  half-enabled.
- Concurrency/lifecycle: pure builders and schemas only; no state, no
  processes, nothing to leak or race. Schedulers/lifetimes stay with
  C-M96b-1/2.
- Docs: `docs/ci.md` flag table, CHANGELOG `[Unreleased]`, PLAN.md M96b
  status, this file. `acpTeamPermissionTitle` (slots plus separators, no
  English words) joins the `untranslated.json` allowlist beside the other
  frozen team formats (`teamRoleFileRefused`, `teamJsonRefused`,
  `teamSwitchRow`); every other new key is translated in all 14 tables.
