## Findings recorded during the milestone

- jsdom reports 0 for `clientHeight` and `scrollHeight`, so the row count
  falls back to newlines there; the M1 tests keep their meaning and the new
  test stubs the heights on the element, the way the M15 scroll test does.
- Setting the `rows` attribute on the element rather than through a prop
  keeps React out of the loop and the React compiler lint quiet (no state
  set in an effect).
- The PLAN.md M18 status line said "version 0.4.4"; it is 0.5.0, fixed
  here.
