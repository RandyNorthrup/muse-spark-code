# M38 certification — "/" in the prompt: the palette, then slash commands (PLAN.md M38)

Recorded 2026-09-24.

## The change

- **`/` alone:** the `/` stays in the prompt and the palette shows above
  the box, with no filter box of its own. The box keeps the focus and hands
  the palette its keys through a `PaletteKeys` handle (`keys`). The box's
  `aria-activedescendant` follows the palette's active row
  (`onActiveRowChange`).
- **One character more:** the palette gives way to `SlashMenu`, a flat list
  from `slashCommandsOf` ranked by `rankSlashCommands`
  (`src/shared/slashCommands.ts`). The ranking:
  1. names that start with the text;
  2. names with a word that does;
  3. names holding the text;
  4. descriptions holding it.
- **Choosing:** a command runs through the palette's own routing, and the
  prompt is emptied first. The exception is a palette row that changes a
  value in place, which keeps the `/`. A skill completes `/selector `.
- **Escape:** it holds for that draft only. The composer forgets it once
  the draft changes, adjusting its state during render as React documents
  for state derived from props.
- **Slash names:** `PaletteItem.slashName` gives the palette rows that
  have one in Claude Code their names there: `model`, `resume`,
  `permissions`, `config`, `mcp` and `hooks`.
