### Finding: `knip --strict` analysed nothing

The template recommends `knip --strict`. In knip 6.37.0 `--strict` implies
production mode, and production mode only reads `entry` patterns suffixed with
`!`. This config has none, so strict mode had zero entry files, analysed
nothing and exited 0 with a planted unused export in place. Plain `knip`
reported the plant and exited 1. The `deadcode` script is now `knip`; the
reason is recorded in `knip.jsonc`, `AGENTS.md` and `PLAN.md` §2 D3.

### Finding: integration test raced the UI

The first run of "opens a chat panel in a new tab" read `window.tabGroups`
immediately after `executeCommand` and found no tab (2 passing, 1 failing).
Tab groups update asynchronously; the test now polls for a
`TabInputWebview` whose `viewType` contains `museSpark.chatPanel` (5 s
timeout, 50 ms interval) and then asserts the label. 3 passing afterwards.

### Finding: `npm audit` high severity in the test toolchain

`@vscode/test-cli 0.0.15 → mocha 11 → serialize-javascript ≤ 7.0.4` (RCE via
`RegExp.flags`, CPU DoS) plus `diff 6.0.0–8.0.2` (DoS in `parsePatch`).
Dev-only chain, never shipped in the `.vsix`. Resolved with npm `overrides`
(`serialize-javascript` 7.1.1, `diff` 8.0.3); integration tests still pass
under the overridden mocha. `npm audit` reports 0 vulnerabilities.
