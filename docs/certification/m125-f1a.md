## Scope and activation

`native/confine/MuseSparkConfine.c` and
`src/core/judge/fast/inspectExec.ts` implement the D107 §9.4 boundary.
`inspectGrammar.ts` admits only one argv and the documented positive option
shapes. The caller must provide the governed launcher; there is no ambient
spawn, shell, PATH lookup or in-place fallback. The helper selects a fixed
system path, verifies its resolved file and root-owned non-writable ancestry,
and executes that resolved file with the requested program name as argv[0].

`npm run build:confine` creates the native helper, generated header and Node
API in `temp/confine/`. Neither the product build nor either package includes
these artifacts. The knip entry is an actual standalone build entry, not an
ignore. No new user-facing strings, Help rows or localization keys exist:
refusals are typed internal protocol words, never display text.

The shared protected/private policy and limits generate the C header directly
from `src/shared/constants.ts`. The helper opens the resolved workspace root
and checks its exact device/inode identity against a binding the trusted host
captures when the workspace/session binds, never a newly derived identity
for each command. Retargeting the workspace itself is refused. Operands and descendants use
`openat2` with beneath, no-symlink, no-magic-link and no-mount resolution;
regular files require one link. Non-ASCII names, ambiguous path spelling,
unknown ELF layouts, RPATH/RUNPATH, unsupported ABIs/architectures and resource
limits refuse rather than widening the read set. There is an additional
128-level walk cap; entry and time caps remain 20,000 and 100 ms.

READ_FILE is granted only on held file descriptors. READ_DIR is a separate
hierarchical permission. ELF DT_NEEDED dependencies and interpreter are
resolved recursively through fixed system library paths, verified like the
program, and granted individually; `/etc/ld.so.cache` is the only additional
Linux system data file. No ldd, loader, repository executable or child runs to
discover dependencies. Loader lookups that differ from this verified closure
fail in Landlock; the helper never grants a library directory.

The child receives exactly PATH, LC_ALL, TZ and an empty private HOME; stdin
is `/dev/null`, and close_range removes every descriptor above stderr.
Landlock handles all filesystem rights of captured ABIs 3–8 (ioctl from 5,
TCP bind/connect from 4, signal/abstract socket scopes from 6); newer ABIs
refuse until their rights are qualified. Seccomp validates the architecture,
rejects x32, all socket operations, process creation, io_uring, key operations,
ptrace, process-memory access, namespace/mount calls and metadata mutations.
Core file creation is disabled before exec. No tested guard was relaxed.

Once per session, the real self-test runs the syscall probe,
inserts/replaces canary inodes after adding per-file rules, and runs cat and
recursive grep over allowed, symlinked, hard-linked, protected and private
canaries. It creates no pre-confinement child. Failed readiness latches off;
native refusal words are parsed and preserved. Concurrent requests share
readiness. Cancellation, disposal, output overflow and timeout withhold
output and await close before cleaning private folders. Complete stdout and
stderr are checked for secrets before delivery; no truncated success.

## Linux capture

Capture: local synthetic tree under this lane's private TMPDIR, no repository
content or credentials. Model attempts: **0**. No network operation succeeds
inside the helper. The capture records ABI, exact installed system grant closure and fixed
environment, with personal/scratch paths normalized. Source/hash manifest and
receipts are in `docs/certification/m125-f1a-linux.json`.

This rig's fixed `/bin/cat` and `/usr/bin/du` resolve to root-owned Rust
coreutils under `/usr/lib/cargo/bin/coreutils/`. Their actual dependency list
includes libm; libz is the unused-library canary. The rig's du asks for a
thread and fails under the process-creation filter. Its abnormal exit is an
explicit confinement refusal, never usable output or an in-place retry.
GNU du on other Linux machines still follows the same fixed table and filter;
no success there is claimed by this receipt.

Linux's guarantee is contents of the granted inodes plus the exact system
closure. READ_DIR/stat expose protected names and metadata as D107 states.
New aliases of an already granted inode remain readable; new ungranted
inodes, including a replacement at a previously allowed name, do not.
Excluded counts describe skipped walk entries, not all later denied opens or
the number of hidden descendants. No claim about the origin of bytes written
by another process with the user's rights.
