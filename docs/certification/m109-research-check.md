# M109 lane 0 research recheck

Checked 2026-10-05 (Kubuntu; UTC retrieval continued 2026-10-06). All 82 linked
primary sources were opened again; JavaScript-only pages were read through
official indexed content, document JSON or source declarations. This record
paraphrases the claim being checked rather than copying the original quotations.
The source-date column preserves the research record’s date/version; discrepancies
and moving-page limitations are explicit below. No runtime support is inferred
from documentation, and model attempts and paid calls were zero.

The original research remains historical evidence. These corrections govern the
M109 handoff: PIN caching is not proven per-use PCP presence, Git ephemeral
credentials require capability negotiation, and Apple keychain access depends
on the API and provisioning arrangement. The P/X/S lanes must certify their
actual mechanisms through the captures in the threat model.
