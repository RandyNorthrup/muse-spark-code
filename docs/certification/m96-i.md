## Findings during implementation

1. **Fetch, not update-ref, publishes the task ref.** The end-of-task commit's
   objects live only in the clone (alternates point clone→user, never
   user→clone), so `git update-ref` in the user's repository refuses the new
   head as a nonexistent object (reproduced manually). `publishTaskRef` runs
   `git fetch <clone> <branch>:<agentsRef>` in the user's repository after a
   compare-and-swap pre-read — exactly the plan's "fetched … into the user's
   `agents/` ref".
2. **`git diff --raw -z` separates status and path with NUL, not TAB.**
   Fixed the parser; the first merge run caught it.
3. **`confineWorkspacePath` cannot confine not-yet-existing (added) files.**
   `teamMerge.ts` walks to the deepest existing ancestor, refuses any link on
   the chain (matching M77's take checks), and re-anchors the name; a symlink
   at the target is refused by `lstat` before any write.
4. **Added files compare the executable bit against `0o100644`.** Without the
   default, a `+x` flip on a new file went unseen.
5. **The no-repository-program canary must not be swept into the branch.**
   The first canary run "fired" because `git add --all` had committed the
   canary file itself into the task branch, which the merge then faithfully
   merged. The test commits only the intended file.

## Seams for parallel lanes (explicit interfaces, no fakes)

- The read-only command list is injected as `ReadOnlyCommandEntry[]`
  (lane 0's `TEAM_READ_ONLY_COMMANDS` fills it at wiring).
- Reviewer entries arrive as `{ entryId, modelId, hasHeadroom }`
  (lane A); model sameness is an injected `isSameModel` (lane R).

  merge/task (lanes R/T). No lane-0 `TEAM_*` constant is referenced; the two
  protocol shapes used (`agents/` prefix, `muse-spark-refuses-ssh`) are
  exported from `refFence.ts` for lane 0/X to adopt.
- No `en.ts`/`l10n` keys added: lane I produces no user-facing text — every
  outcome is a structured verdict with a stable reason code for lanes T/U2
  to render; core errors carry fixed technical English per the BestOfN
  precedent. `node scripts/check-l10n.mjs` reports 0 problems.
