## Security

- Rules and skill files are workspace content and may carry prompt
  injection. On the CLI backend they already reach the model by Muse Code's
  design once trusted; on the Model API backend they are read only in a
  trusted workspace, under the same permission modes, with the size caps,
  and never executed. `read_skill` resolves catalogue ids, never paths.
- Restricted Mode: `--disable-shell` for the CLI and no shell tool on the
  Model API, `restrictedConfigurations` for the two settings that name an
  executable or its environment.
- The personal skill root is read, never written; the memory directory is
  written only through the ordinary file tools the permission mode governs.
