rejects unsafe shell paths before reading. Markers select 18 project kinds;

vcgencmd runs only after a Raspberry Pi identity and executable presence

get_throttled and measure_temp are sent. Each process has an empty inherited
environment, a 2000 ms cap and an 8192-byte output cap. Failed or absent
optional probes omit their facts; throttle bits are retained whole.

absent without those detected ids; user/project skills retain their existing
precedence. The marker-free catalogue and rendered Model API instruction
