## Decisions and deviations

- `TEAM_ROLE_REPORT_SHAPES` (summary default, `review` for code-review, `qa`
  for qa) is a lane-0 judgement call: D75 names the shapes but not the
  mapping. Lane R's charter generator and lane W's report parser read it.
- `TEAM_MAX_CONCURRENT_COMMANDS` is the floor (1) of the half-CPUs formula;
  lane K applies the formula. A static file cannot hold a machine value.
- `TEAM_ROLE_WRITE_PATHS` omits `engineering`: per D75 narrowing, a missing
  entry means the whole branch.
- `teamSwitchRow`/`teamCapabilityWarning` stay English-shaped in every table
  (slots and punctuation only, like `exportThenRunSkipped`) and are listed in
  `untranslated.json`; `teamTemplates.solo`, `teamIntensityLevels.max` and
  `teamSetupSteps.pools` stay English where the language uses the loanword;
  `teamOrchestratorSlot` (de), `teamIntensityLevels.minimal` (de) and
  `teamRolesTitle` (es) are true cognates. Each follows the file's existing
  per-language pattern (e.g. de `effortLevels.minimal`).
- `package.nls*.json` unchanged on purpose: the gate requires every key used,
  and the only new user-visible manifest text (settings, commands) is lane
  X's `package.json`. Lane X adds those keys with their package.json refs.
- Capture-set constants (the `collect` wait bound, MCP timeouts) are pending
  lane P's step-1 captures and are not defined here.
- `src/webview/state/uiState.ts` got one case (`teamTree` ignored until lane
  U2 reads it): lane 0's protocol addition broke the state's exhaustive
  switch (TS2366). Minimal seam, flagged for lane U2. This is the only file
  outside lane 0 touched.
- One `eslint-disable` (`unicorn/consistent-boolean-name` on
  `TEAM_CONTINUE_ON_NEXT_DEFAULT`): the `TEAM_<SETTING>_DEFAULT` scheme lane
  X reads cannot take a boolean prefix. Inline reason recorded; §8 row added.
- Owner rulings (2026-10-04) applied: paid strings ask once with price plus
  shared daily budget (`teamPaidDetail`), enhancements-on and single-model
  behaviour need no lane-0 strings beyond `teamNoSecondModel`.
