### Design and acceptance

- **W-F1:** `workerFence.ts` owns root admission. Native realpath followed
  by the existing `src/core/fs/fileIdentity.ts` BigInt sampler/key yields
  Windows volume serial/file index (from a native
  handle) or POSIX device/inode. Either direction of ancestor overlap
  refuses. Engine in-place requires equality; external in-place refuses.
  Every spawn uses the resolved cwd, never the supplied alias.
- **W-F2:** mediated paths recheck roots and compare native ancestor
  identities. Home and relative paths expand first. Unresolved paths,
  including nonexistent write destinations, refuse; no textual fallback.
  Role globs/private/protected names apply after identity containment.
  ACP's path extractor handles path-valued fields and bounded nested data.
  M77's engine host receives a path IO bound to this same fence.
- **W-F3:** one Git classifier sees executable paths, suffixes and wrappers.
  Ref changes/unknown Git commands, unsafe read options, wrappers and
  escaping path arguments refuse without a card. Spawned Git inherits empty
  credential.helper/core.askPass and a refusing `false` SSH command.
- **W-F4:** ACP chunks group by messageId; only the final message supplies
  the result. Non-end-turn stop reasons refuse success and retain the raw
  reason, including future values. Mode/protocol/model
  confirmation precedes prompting; cancel flush gets bounded terminal grace
  before transport/process closure. Invalid engine report calls retain the
  last message, and report clipping uses Intl.Segmenter to preserve graphemes.
- **W-F5:** complete Windows suites, finding-named regressions, deliberate
  production mutations and committed-blob restoration hashes supply scoped
  evidence. This is mediated admission, not an OS sandbox or vendor/live
  certification. Hard links to secret files and agent-native arbitrary tools
  retain the recorded OS-sandbox residual.
