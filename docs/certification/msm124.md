## Real-life steps for the lead (no model call)

1. `npm run build`, then `node dist/acp.js mcp status` → `Connector:
on`, `No connection grants yet.`
2. In your own terminal: `node dist/acp.js mcp grant --workspace
<folder> --scope prompts:read`, type the confirmation → grant
   listed by `mcp status`.
3. Register with a real client without touching global config twice:
   `codex mcp add muse-spark-code -- node <repo>/dist/acp.js mcp`
   (README has the Claude Code and Gemini CLI forms). In the client:
   list tools → only granted families appear; ungranted calls refuse.
4. Call a granted read (e.g. `muse_prompt_list`) → scrubbed result;
   call `muse_prompt_save` → the loopback approval page opens in the
   browser; Approve → result delivered; Deny/disconnect/revoke/kill
   first → `cancelled`/`refused`, nothing written.
5. `mcp kill` → reads refuse, Stop still answers; `mcp resume` →
   owner flow resumes. `connector/audit/default.jsonl` in the agent
   data folder records every step.
