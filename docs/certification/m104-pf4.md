## Native command/navigation/focus checkpoint

The real loopback regressions first reproduced cancellation before queued
listener startup (a port reopened after cancellation), repeated startup (the
original owner's completion was overwritten), and a closed command client
restarting its authenticated exchange. Startup now refuses in the correct
terminal state; a repeated listener start cannot replace its original owner.
Each rejected invocation receives an explicit error and no new exchange.

write, then retains the existing digest, selection, UTF-16 and approval checks.
The XcodeKit command uses that commit for its single completeBuffer mutation;
its queued app launch is also cancellation-fenced. Core tests prove zero writes
after cancellation or stale content, one write for a valid reply, and that an
