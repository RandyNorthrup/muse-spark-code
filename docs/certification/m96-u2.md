## Acceptance coverage (plan items for this lane)

- **25, the tree.** Orchestrator root (model, backend, Default/override,
  today's spend of budget); roles with charter summary, mode and tool
  groups; entries in order with provider, model, pay kind, caps "used of
  amount" reported or marked estimated, headroom, running of concurrent,
  state and warnings, and Reset; workers with brief, branch, status,
  elapsed, tokens, cost and Open transcript, Stop, Review diff, Merge /
  Discard; queued, unmerged and interrupted nodes of their own. Merge and
  Discard post through the orchestrator's `merge` decision message, so the
  merge card stays the approval point. Edits post `openTeamRoles` at the
  node. Keyboard: one tab stop, arrows, Home, End, type-ahead (WAI-ARIA
  tree). Each item's name gives role, model and status. At 320 px the same
  indented list with the same actions; no animation of its own, so reduced
  motion has nothing to stop. The tree is not a live region.
- **Transcript rows.** The delegation card and plan (delegated/kept with
  rubric reasons, `dry_run` marked), one switch row per switch (role, from
  and to, translated reason, unknown shown as it came), the four-choice
  "waiting for you" card (Queue it / Main agent does it / Raise a limit… /
  Cancel, locking on answer like a decided approval), the merge card
  (review state, branch-moved and conflict notes, Merge / Discard / Review
  diff), and each task's report row. Without answer handlers the cards
  read only (history).
- **Worker label (T8).** A worker's own approval card (in the dock) and
  question row carry the panel's own `role · agent · task` chrome, drawn
  from the task, never from worker text.
- **Usage Team section.** Tasks, tokens and cost today and in this window,
  per role and per entry, key/subscription/local apart, estimated marked.
- **Header pill.** Counts team tasks beside agents and background tasks;
  the running dot covers running team tasks. Zero is today's pill.
- **47, single-model.** `team`/`teamTree` undefined renders byte-today's
  map, pill, dialog and transcript (covered by the pre-existing suites
  plus explicit absence tests and the no-team App test).
