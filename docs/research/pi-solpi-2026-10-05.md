## Does M74's automatic compaction exist? No

The integrator was right. Automatic compaction, cache-debt accounting, the memory flush and the hidden todo follow-up do not exist on main (PLAN.md:11017–11028 and Q-M74 at PLAN.md:4975).

- **Code:** there is only the manual `/compact` (`compactNow`, ModelApiHost.ts:9226, trigger `'manual'`) and `/handoff`. The word "debt" appears nowhere in `src`.
- **The pricing bugs:** SoL-Pi's pricing fixes have nothing to correct in our code. They become the specification for M74 (section 3).
- **m95/int:** it still sends `tools: []` on compaction and uses the fixed 1,048,576-token window.

**What each change is:**

1. **Goal progress.** `goalInstructions` puts "Tokens used: N of B", the percentage and current/next work into `instructions`, which is part of the `prompt_cache_key` digest. While a goal is active, the cached prefix and the key therefore change after nearly every response. That makes whole-context re-reads uncached: about $1.25/M instead of $0.15/M on Meta's standard models. Fix: keep only the objective and the rules in `instructions`. Send progress, tokens and the reminder as a trailing input item that is rebuilt per request and never saved into the replay, the way packing projects. The Anthropic codec must put its rolling cache breakpoint before that trailing item, not on it. Not measured live.
2. **`recall_output`.** `hasPackedRecall` is true only when the request already holds a placeholder. So the first packed request changes the tool list and the cache key, and the whole prefix misses; it changes again after `/compact`, resume and fork. Fix: declare `recall_output` on every request of a packing session, as `this.packing !== undefined`. Reviewer turns stay unpacked. Update `modelApiPacking.test.ts:176-209` and `evalPacking.test.ts:76-82`.
3. **Compaction cache.** The compaction request drops the tools and sends the unpacked replay. It shares no prefix with the last turn and pays full uncached input on the largest request of the session. On Anthropic, the rolling breakpoint also writes the whole conversation into a cache entry that is never read again (1.25×, or 2× for the 1-hour TTL). Fix: send the last turn's exact body (same instructions, tools, key and packed input) with the compaction prompt appended. Meta rejects `tool_choice: "none"` according to its docs (not checked live). So if the reply holds a `function_call`, discard it and fall back to today's tool-less request; Pi rejects tool calls in summaries too. On m95, honour the `keepToolsWithHistory` flag that is declared but never read. The codec goldens there already assume the tools are kept (anthropicCodec.test.ts:315, geminiCodec.test.ts:412).
4. **Placeholder lines.** Reproduced. When lines are long, the trimming loop drops the final lines first, so a packed shell or `then_run` output loses its exit-code line. Fix: trim the tail from its front (`tail.slice(1)`), budget head and tail separately, and always keep the final line when it fits.
5. **Todo list after `/compact`.** The host keeps `this.todos`, but the model never sees it. The summary prompt does not ask for it, and the replay is replaced by the summary alone. Fix: append the exact open todos, as host data and not the model's guess, to the compaction prompt and to the summary entry. Snapshot them at compaction time so the bytes stay fixed afterwards. M74 reuses this (Q-M74 item 2).
6. **Overflow.** Nothing classifies overflow, so an over-long request is a generic 400. Fix: add a pure `providers/overflow.ts` with Pi's pattern table. Keep its guards: 429 and rate-limit texts never count. Also catch Pi's two silent-overflow signals: input above the window on a completed reply, or zero output with input at 99% of the window. Use the model's `contextTokens` instead of `MODEL_API_CONTEXT_WINDOW`. Until Q-M74's consent contract exists, show "Context window full: /compact or /handoff". After it, allow one guarded automatic compact-and-retry per turn, plus a check before each request against window minus reserve.
7. **Pack state.** Persist an optional `packedCallIds` in `StoredSession` and copy the ids that survive the cut in `copyInto`. A resumed or forked session then re-sends the same placeholders.
8. **Cut-short replies.** When a reply ends incomplete, answer each call whose status is not completed with an error ("output hit the token limit; split the write") instead of running half-formed arguments.
9. **Paths.** Add one `normalizeModelPath(given, platform)`, applied at every place a model-given path is resolved. It replaces U+00A0, U+2000–200A, U+202F, U+205F and U+3000 with a space; strips a leading `@`; converts `file://` with `fileURLToPath`; and on win32 maps `/c/…`, `/mnt/c/…` and `/cygdrive/c/…` to `C:\…`. Refuse `~` instead of creating a literal `~` folder. On POSIX today, `file:///x` writes `<root>/file:/x`. All sites must share the one function; a permission check and a write resolving different paths is exactly the bug class SoL-Pi fixed three times. Optionally add Pi's read-only fallbacks (NFD, AM/PM narrow space, curly quote) when the file is not found.
10. **Summary.** Adopt Pi's structured format: Goal / Constraints / Progress / Decisions / Next steps / Critical context, with "keep exact paths and errors". When the replay already starts with a summary, use Pi's update prompt with the previous summary. Append file lists built from the replay's `read_file`, `write_file` and `edit_file` calls, outside the model's text.
11. **Guards.** Refuse a summary that is blank after trimming and keep the replay. Return NOOP when every replay entry is the previous compaction's. Retry `collectText` like turns, with `RetryableStreamError` and backoff, re-reserving the budget each time.
12. **Fuzzy edit.** Try the exact match first. Otherwise normalise both sides (NFKC, trailing whitespace, curly quotes, dashes, Unicode spaces), require a unique match, and copy the untouched lines back from the original. Refuse when `find` equals `replace`.

## 4. Rules for M74 automatic compaction, from SoL-Pi's fixes

These are not ports, because the feature does not exist yet; they should be written into M74 before it is built.

1. **Removable tokens.** Measure them from the last request actually sent, with packing placeholders at their sent size. If nothing is removable, do not compact (`5213f225db`, `efacbbf883`).
2. **Cost after compaction.** Charge the cache premium on the context written after compaction, `max(0, write − (archive − memo))`, not on the whole context before it (`b20b7f75b1`).
3. **Debt adds up.** Debt accumulates across compactions, and the break-even is (carried + new) / (repayment + saving) (`5c85108811`).
4. **Failures.** Clear pending debt when a compaction fails (`1d90af233f`). A benign refusal or an incomplete summary continues with the original context and does not retry until real tool work or new user input happens (`06814c1905`).
5. **Todo transitions.** Only a todo that was already registered unfinished and then completes counts as a boundary. A todo first seen already completed is history. Keep the list across compaction (`4101906501`, `2f9f748574`, `f997dde278`). Our todos have no ids (agentEvents.ts:278-283), so match by text or position. Adding ids would change the tool schema bytes.
6. **Cooldown.** Wait 2 requests before the cost-based path may compact again; the near-window path can still compact. A new user task after a fully completed list resets the request-horizon samples but keeps the debt ([#71](https://github.com/NVlabs/SoL-Pi/pull/71), issue [#70](https://github.com/NVlabs/SoL-Pi/issues/70)).
7. **Occupancy floor.** Do not compact on cost alone below a minimum occupancy ([#101](https://github.com/NVlabs/SoL-Pi/pull/101), today). It measured compactions firing at a median of 28.7% occupancy on a 262k window.
8. **Do better than upstream.** Estimate the summary's size from the previous real summary, not SoL-Pi's fixed 1,000 tokens (#70 measured 2.3–7.6k). Also price the summarizer call itself.
9. **Gate on the price card.** Ratio r = cacheWrite / cachedInput where a write price exists: Anthropic 12.5 for the 5-minute cache, 20 for 1 hour. Otherwise r = input / cachedInput: Meta standard 8.33, contributor 50; OpenAI, xAI, DeepSeek and Gemini implicit caching.
   - Pricing kind `local`: use a re-prefill-time cost plus the occupancy floor.
   - `unpriced` or `plan`: only the near-window protection.
   - Long-context price tiers change r.

## (b) Already handled

- **`then_run` path mismatches** (SoL-Pi #4, #9, #35, `7d7f082eea`): structurally impossible here. The guard re-reads the edit's own resolved target (ModelApiHost.ts:7537-7553). The missing normalisation underneath is item 9.
- **`then_run` failures** ([#99](https://github.com/NVlabs/SoL-Pi/pull/99), #100, [#95](https://github.com/NVlabs/SoL-Pi/pull/95)): the outcome comes from the exit code, and a spawn error, timeout or refusal each reports clearly (verifyLoop.ts:69-77; test verifyLoop.test.ts:1159).
- **`then_run` shell path** ([#82](https://github.com/NVlabs/SoL-Pi/pull/82), [#77](https://github.com/NVlabs/SoL-Pi/pull/77)): it uses the same shell as the shell tool (ModelApiHost.ts:6154-6169). Side note: it ignores a user-raised time limit (`:6167`).
- **Advertised but unreachable `then_run`** ([#23](https://github.com/NVlabs/SoL-Pi/pull/23)): the instruction and the parameter share one gate (instructions.ts:238-241, tools.ts:570).
- **Recall at an offset inside a character** ([#34](https://github.com/NVlabs/SoL-Pi/pull/34)): refused, and page ends back off (observationPack.ts:310-322).
- **Packing without the recall tool** ([#72](https://github.com/NVlabs/SoL-Pi/pull/72)), **recall after a fork** (#97's failure side): the replay keeps the originals.
- **Incomplete compaction summary** (`06814c1905`): rejected before the replay is replaced (ModelApiHost.ts:8796-8802).
- **Context after compaction:** the stale base is reset and the context re-counted (8920-8941).
- **Prompt-cache key and retention:** the key is a digest of the prefix (promptCache.ts:23-29), as Meta's guide asks; the retention setting exists.
- **Edit and write tools:** empty, missing and ambiguous `find` refused; CRLF and BOM preserved; `write_file` refuses to overwrite a file the model has not seen; non-UTF-8 and >10 MiB files refused; image sniffing by header; the shell exit line is never clipped.
- **Sessions:** atomic writes; saved from the turn's start and never with an unanswered call; orphaned calls answered.
- **Reasoning replay** (encrypted reasoning, Anthropic thinking `drop_block`, dropped across providers).
- **Usage:** cached tokens are not double-counted; provider-reported cost is used where it exists; Retry-After is parsed.
- **Hooks:** they cover Pi's interception points (hooks.ts:39-57).
- **Anthropic cache breakpoints:** already in the m95 codec, on the system prompt plus a rolling one (anthropic.ts:470-498).
