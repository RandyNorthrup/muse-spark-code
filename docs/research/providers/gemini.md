# Google Gemini API, Vertex AI and Gemini CLI hooks: models, features, limits — research and product comparison

Research date 2026-10-17. Official sources only (§1); every value read on
2026-10-17. Product: `main` at `3d30a73214` (read only). Owner's rule
(2026-10-17, binding): "the limits we set on our agents hardcoded are **ONLY**
the limit set from the providers" and "**ALL** every model available through
every provider all hooks all features all limits etc".

Classes: **(a)** matches Google; **(b)** differs (both values given); **(c)**
missing from the product; **(d)** hard-coded in the product but not a Google
limit. "not documented" / "not verified" rows name the capture that would
settle them (§7).

How the product reaches Gemini: preset `gemini` (`presets.ts:407-428`:
origin `https://generativelanguage.googleapis.com`, `x-goog-api-key`, models
list `/v1beta/models`), codec `codecs/gemini.ts` (`POST
/v1beta/models/{model}:streamGenerateContent?alt=sse`, `codecs/gemini.ts:43-45`;
request built at `codecs/gemini.ts:615-695`). Vertex AI has **no preset**
(searched `vertex`, `aiplatform`). Gemini CLI hooks are imported through the
M91 contract `hookFormats/contracts/gemini.ts`.

## 2. Summary

- **Models.** The Gemini API models page lists **47** model codes (MODELS);
  all 47 are covered in §5 (one table each). The snapshot also carries 7 ids
  not on that page (`gemini-3.1-pro-preview-customtools` — named on the 3.1 Pro
  page —, `gemini-3.5-flash`, `gemini-3.7-flash`, `gemini-flash-latest`,
  `gemini-flash-lite-latest`, `gemma-4-26b-a4b-it`, `gemma-4-31b-it`): not
  documented on the pages read. Vertex AI names the same Gemini family (§6);
  Gemini CLI documents **11** hook events (§7), all mapped by the product.
- **Counts** (class tags on the 250 classified rows of §3-§7; a row may
  carry two): **(a) 113, (b) 7, (c) 130, (d) 5**. Itemised changes (§8):
  6 (b), 9 (c), 5 (d).
- **Most important mismatches.**
  1. **`gemini-4-argon`, the new flagship (Oct 2026), has no request-time
     record**: context unknown, output 32,768 (`ModelApiHost.ts:4452-4455`),
     and any Thinking-on request throws `gemini_unknown_thinking_mode`
     (`codecs/gemini.ts:665-666`) because the live `inputTokenLimit`,
     `outputTokenLimit` and `thinking` fields are kept only by the scan.
  2. **Thinking off does not turn thinking off on level models**: Thinking off
     sends no `thinkingConfig` (`codecs/gemini.ts:640,687-692`), so 3.x models
     run at their default level (medium on 4 Argon / 3.8 / 3.6 Flash, high on
     3.1 Pro and 3 Flash Preview, THINK). The lowest documented level is
     `minimal` where listed; 4 Argon, 3.8 Flash and 3.1 Pro start at `low`.
  3. **Models list paging**: `models.list` returns 50 per page by default, at
     most 1,000 (`pageSize`), with `nextPageToken` (MAPI); the scan requests
     `/v1beta/models` with no `pageSize` and no paging (`presets.ts:425`,
     `configured.ts:414`), while the codec's key-test path asks for
     `pageSize=1000` (`codecs/gemini.ts:48`).
  4. **Media**: Gemini images are PNG, JPEG, WEBP, HEIC, HEIF, up to 3,600 per
     request, inline requests capped at 20 MB (IMG) — FILES says to switch to
     the Files API above 100 MB; PDFs up to 50 MB or 1,000 pages (DOC). The
     product applies Meta's list (with GIF, without HEIC/HEIF,
     `constants.ts:1305`), 10 MiB per image (`constants.ts:1316`), 50 per
     request (`constants.ts:1492-1494`), inline only, and no PDF bound.
  5. **Not used**: structured output (`responseSchema`), sampling and stop
     parameters, safety settings, explicit caching, Files API (2 GB per file,
     20 GB per project, 48 hours), Batch, `serviceTier` (Flex, Priority),
     Google Search / Maps grounding, code execution, URL context, file search,
     computer use, the Interactions API, audio/video input.
  6. **Retry**: Google's guidance for 429 `RESOURCE_EXHAUSTED` is "Wait a
     short period and retry" (RL); the product's Gemini retry table
     (`retryPolicy.ts:89-100`) is never read and Meta's is used
     (`transport.ts:1087`); both cover 429 and 5xx, so the effect is the same.
  7. **Vertex AI is not supported at all** (no preset, no OAuth / ADC).
