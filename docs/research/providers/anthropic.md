## 2. Summary

- **Models.** Anthropic's models overview lists **13** models (4 current, 9
  legacy; OVERVIEW); the deprecations table has 23 rows (15 active, 2
  deprecated, 6 retired; DEPREC). **17 models are callable** on the Claude API
  today (the 13 plus `claude-mythos-5-1`, `claude-mythos-5` (verification
  required), `claude-mythos-preview` (deprecated, invitation only) and
  `claude-sonnet-4-5-20250929` (deprecated, retires 2026-11-30)). All **17**
  are covered in §5; the 19 retired ids are listed in §3.
- **Counts** (class tags on the 229 classified rows of §3-§5; a row may carry
  two): **(a) 110, (b) 27, (c) 92, (d) 10**. Itemised changes (§6): 13 (b),
  17 (c), 12 (d).
- **Most important mismatches.**
  1. **Thinking off is not sent.** The codec omits `thinking` when the user
     turns Thinking off (`codecs/anthropic.ts:670-680`). On 9 of the 17 models
     an absent `thinking` field means adaptive thinking **on** (THINK table),
     so "off" silently thinks and bills. Anthropic's off switch is
     `thinking: {type: "disabled"}` (Opus 5, Sonnet 5, Haiku 5.5 at `high` or
     below, the 4.x models) or `{type: "between_tools"}` (Sonnet 5.5 only);
     the product never sends either.
  2. **Four callable models have no request-time record.** `claude-haiku-5-5`
     (released 2026-10-07), `claude-mythos-5-1`, `claude-mythos-5` and
     `claude-mythos-preview` are absent from the 2026-10-05 snapshot, so the
     record is empty: context unknown, output falls to 32,768
     (`ModelApiHost.ts:4452-4455`), and **any Thinking-on request throws
     `unsupported_thinking_mode`** before sending (`codecs/anthropic.ts:446-447`),
     because the live `/v1/models` capabilities are read only at scan time
     (`configured.ts:414-416` vs `configured.ts:438-454`).
  3. **Overload is never retried.** The transport classifies every provider
     with Meta's table (`transport.ts:1087`); Anthropic's own table with 529
     and `overloaded_error` (`retryPolicy.ts:74-88`) is dead data. A 529
     `overloaded_error` (ERR) fails at once.
  4. **Rate limits are not read.** Pacing reads only `x-ratelimit-*`
     (`pacing.ts:30-44`); Anthropic sends `anthropic-ratelimit-*` with RFC 3339
     resets (RATELIM), which the product only journals (`usageJournal.ts:73-84`).
     Buckets per model family (Fable 5.x, Mythos 5.x, Opus 4.x, Sonnet 4.x
     combined pools) are not modelled.
  5. **Media bounds are Meta's.** 50 images per request (`constants.ts:1492-1494`)
     and 20 attachments per message (`constants.ts:1332`) apply to Anthropic,
     which takes 600 images or PDF pages per request (100 on 200k-context
     models), 8000x8000 px, 32 MB per request (VISION, PDF, OVR).
  6. **Snapshot errors.** `claude-sonnet-4-5` and `claude-sonnet-4-5-20250929`
     carry a 1,000,000-token context in the snapshot; Anthropic documents
     200k for Sonnet 4.5 (CTXWIN, P-SONNET45).
  7. **Missing features**: strict tools and structured outputs
     (`supportsStrictTools: false`, `presets.ts:201`), every server tool (web
     search, web fetch, code execution, tool search; `codecs/anthropic.ts:429-431,611`),
     1h cache TTL (never passed, `configured.ts:659-664`), Files API, Message
     Batches, token counting endpoint, `inference_geo`, `service_tier`,
     `speed: "fast"`, citations, compaction and context editing.
  8. **The thinking-binding opt-in never rides the configured path**: the
     configured record keeps `prefixEditPolicy: 'refuse'`
     (`capabilityRecord.ts:252`), so `drop_block` (`codecs/anthropic.ts:473-474`)
     is never sent, while Anthropic rejects replayed thinking after an earlier
     turn changed for accounts created on or after 2026-08-31 (ERR, THINK-TS).
