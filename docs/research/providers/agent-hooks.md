# External agents' hooks and plugins (Codex, Copilot CLI and VS Code, Cursor, Windsurf/Devin, Kiro, Cline, Amp, OpenCode) — research and product comparison

Research date 2026-10-17. Official sources only (§1): each vendor's own
documentation. Product: `main` at `3d30a73214` (read only). Owner's rule
(2026-10-17, binding): "the limits we set on our agents hardcoded are **ONLY**
the limit set from the providers" and "**ALL** every model available through
every provider all hooks all features all limits etc".

Classes: **(a)** matches the vendor; **(b)** differs (both values given);
**(c)** missing from the product; **(d)** hard-coded in the product but not a
vendor limit.

Claude Code hooks are in `claude-code-hooks.md` and Gemini CLI hooks in
`gemini.md` §7. The product imports these vendors' hooks through the M91
import (`src/core/import/agentImport.ts`, `importConvert.ts`) and runs them
through per-vendor contracts (`src/core/backends/modelapi/hookFormats/contracts/*.ts`,
plugin systems in `pluginFormats.ts`). The product's own runner limits (600 s
timeout maximum, 4 commands at once, 256 KiB stdin, 16 KiB stdout,
`constants.ts:880-917`) apply to every imported hook; they are compared with
Claude Code's in `claude-code-hooks.md` §3 and are class (d) for every vendor
below that documents no such limit.

## 2. Summary

- **Counts** (class tags on the 22 classified rows of §3; a row may carry
  two): **(a) 17, (b) 4, (c) 5, (d) 3**. Itemised changes (§4): 4 (b), 2 (c),
  3 (d).
- **Most important mismatches.**
  1. **Cline's documented hooks changed.** The hooks page is now a stub
     pointing to SDK plugins: hooks `beforeRun`, `afterRun`, `beforeModel`,
     `afterModel`, `beforeTool`, `afterTool`, `onEvent`, each call timing out
     after **3 seconds**, fail-open by default (CLINE). The product's Cline
     contract is for v1 script hooks (TaskStart, PreToolUse, …) from the
     2026-04-24 doc with a 30 s timeout (`contracts/cline.ts:1-192`,
     `constants.ts:3506`).
  2. **New vendor events not imported**: Copilot `userPromptTransformed`;
     Cascade `post_cascade_response_with_transcript`; Cursor `subagentStart`
     (searched the contracts).
  3. **Handler types and fields refused**: Codex `mcp_tool` handlers and
     `additionalContextLimit` (default 2,500 tokens) are refused at import
     (`importConvert.ts:897-916`); Copilot `http` and `prompt` handlers and
     `modifiedArgs` are not converted (not verified line by line).
  4. **Timeouts**: Codex `SessionEnd` and `Interrupt` default to 1 s with a
     3 s maximum (CODEX); the product's SessionEnd wait is 10 s
     (`constants.ts:913`). Copilot hooks default to 30 s and always fail open
     on timeout (COPILOT); Kiro command actions 60 s (`0` disables, KIRO).
