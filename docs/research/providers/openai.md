# OpenAI API: models, features, limits — research and product comparison

Research date 2026-10-17. Official sources only (§1); every value below was
read on 2026-10-17. Product: `main` at `3d30a73214` (read only). Owner's rule
(2026-10-17, binding): "the limits we set on our agents hardcoded are **ONLY**
the limit set from the providers" and "**ALL** every model available through
every provider all hooks all features all limits etc".

Classes: **(a)** matches the provider (or the product reads it live);
**(b)** differs from the provider (both values given); **(c)** missing from the
product; **(d)** hard-coded in the product but not a provider limit. "not
verified" marks a row where the provider page is silent; §7 names the capture
that would settle it. No value is guessed.

How the product reaches OpenAI: preset `openai` (`src/core/providers/presets.ts:302-328`),
Responses wire (`POST https://api.openai.com/v1/responses`, `configured.ts:644,691-698`,
`codecs/responses.ts:397-457`), request body built by `ModelApiHost.ts:4504-4521`
(`tool_choice: "auto"`, `reasoning: {effort, summary: "auto"}`, `stream: true`,
`store: false`, `include: ["reasoning.encrypted_content"]`, `max_output_tokens`).
Per-model limits come from the vendored models.dev snapshot
(`vendor/models-dev/snapshot.json`, fetched 2026-10-05, 44 `openai` rows) read
at request time (`configured.ts:436-454`), else the user's `modelLimits`.

## 2. Summary

- **Models.** OpenAI's full catalogue (ALL) lists **102** model ids, 55 marked
  "Deprecated" there. All **102** are covered: the 64 text, reasoning, chat,
  coding and open-weight models in §5.1 (one table each), the 38 realtime,
  audio, speech, transcription, image, embedding and moderation models in §5.2.
  ALL has no video models (DEP: Sora 2 and the Videos API shut down
  2026-09-24). Pricing and deprecation pages name a few more ids not on ALL
  (`gpt-5-search-api`, `gpt-5.5-cyber`, `gpt-rosalind-discovery`,
  `gpt-5.4-cyber` (shut down 2026-10-01), `gpt-5-codex-mini`).
- **Counts** (class tags on the 558 classified rows of §3-§5; a row may
  carry two): **(a) 256, (b) 12, (c) 295, (d) 8**. The 38 snapshot prices
  checked all match OpenAI's pages. Itemised changes (§6): 7 (b), 12 (c),
  7 (d).
- **Most important mismatches.**
  1. **Thinking off and unlisted efforts send `reasoning.effort: "none"`**
     (`modelPolicy.ts:157-172`, `shared/effort.ts:91-96`). OpenAI: "GPT-6
     Astra does not support `none` reasoning effort" (400), GPT-6.1 Sol "does
     not support `none` or `minimal`" (M, REAS); gpt-5, gpt-5-mini, gpt-5-nano,
     the `-pro` models, o3, o3-pro, o4-mini, o1, o3-mini and gpt-5.3-codex list
     no `none`. A request at an effort the record does not list (e.g. `xhigh`
     on o3) is also sent as `none`, not the nearest listed level.
  2. **OpenAI's error codes are thrown away.** `parseError` for the Responses
     format returns a generic `ModelApiError` with no `type` or `code`
     (`configured.ts:638-640`, used by `providerClient.ts:145`), so
     `insufficient_quota`, `credit_balance_exhausted` and the spend-limit 429s
     (ERR: "retrying won't restore access") are retried as rate limits, four
     times (`constants.ts:2316`), and the preset's `server_error` quirk
     (`presets.ts:322-323`) can never match.
  3. **26 of the 64 text models have no request-time record** (no snapshot
     row): context unknown, output 32,768 (`ModelApiHost.ts:4452-4455`),
     effort unknown → every request sends `none`.
  4. **Rate limits**: OpenAI's tiers are now Free, Build, Launch, Grow (RL);
     the reader takes `x-ratelimit-limit/remaining-*` but not
     `x-ratelimit-reset-*` or the project headers (`pacing.ts:30-44`) and
     assumes a 60 s window (`constants.ts:2257-2260`).
  5. **Structured-output limits**: OpenAI allows 10 nesting levels, 5,000
     properties, 120,000 characters, 1,000 enum values (SO); the product checks
     depth 12 only (`constants.ts:2393-2400`).
  6. **Media**: OpenAI takes up to 1,500 images and 512 MB per request with no
     per-image byte limit (VISION) and files under 50 MB (FILEIN); the product
     applies 50 images (`constants.ts:1492-1494`), 20 attachments
     (`constants.ts:1332`) and 10 MiB per image (`constants.ts:1316`).
  7. **Not used**: prompt-cache key/retention (never sent: the catalogue sets
     no cache facts, `configured.ts:694-696`), `service_tier` (Flex, Fast,
     Ultrafast), `reasoning.mode: pro`, `text.verbosity`, hosted tools, Batch,
     Files, data-residency endpoints (`us.`/`eu.api.openai.com`),
     `OpenAI-Organization`/`OpenAI-Project` headers, Models API `shutdown_date`.
