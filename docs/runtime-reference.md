| lsp                                                        | Stdio LSP frontend. One broker per canonical workspace, with private directories created with final owner-only permissions and verified through a no-follow fd or Windows handle; private records created exclusively with held-file permissions/ACL, resolved record identity and directory identity verified before contents are written; one StrictModes verifier checks the full real ancestry to the filesystem root, including root-owned sticky parents only with user-owned children; platform root selection records refusals and its chosen path, refusing startup if none qualifies; UTF-16 full document sync; cancellable requests and standard initialization/method error codes; ordinary invoked completion items plus inline completion when negotiated.                                                                                                                          |

Model API key stays in the OS store.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

| supervise <runtime arguments>                              | Run the installed runtime behind independent authenticated Stop control. Stop during guardian startup waits for the child and cleanup. Workload launches wait for exact M107 process registration. All Stop actions use verified per-member signals and exit receipts; POSIX EOF guardian uses the same authority, zombies count as exited, and observed detached descendants remain enrolled. Windows uses a named native job. Intentional Stop exits 0, including job 143/137; ordinary exit codes are preserved; unexpected POSIX signal death exits 128 + signal and names it on stderr. POSIX retains the final exact-read-to-signal interval without a pidfd; native Windows/Linux qualification remains pending.                                                                                                                                                                            |
| stop                                                       | Stop supervised owners in the current canonical workspace without entering the request queue. Search every verified platform root, then verified prior roots from path-only locators in the stable home fallback, even after XDG/TMPDIR changes. Supervision requires that verified locator namespace. Preflight every owner before signalling; canonical trust-root mismatches and duplicate owner UUID/generations refuse with ownership retained. No matching run exits 1 (ESTOP_NO_RUN); duplicates exit 1 (ESTOP_AMBIGUOUS). Owner death requires an exclusively created completed guardian receipt bound to the current random generation, owner UUID, resource ticket, guardian/root birth identities and observed members; copied, stale and incomplete receipts refuse; without one, exit 1 reports inability to verify and observed PIDs, retaining ownership for a later verified Stop. |
