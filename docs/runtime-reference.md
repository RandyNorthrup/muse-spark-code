| supervise <runtime arguments>                              | Run the installed runtime behind independent authenticated Stop control. POSIX control sockets use the verified platform runtime root independently of registry depth; oversized addresses refuse before control state or child launch. Stop during guardian startup waits for the child and cleanup. Workload launches wait for exact M107 process registration. All Stop actions use verified per-member signals and exit receipts; POSIX EOF guardian uses the same authority, zombies count as exited, and observed detached descendants remain enrolled. Windows uses a named native job. Intentional Stop exits 0, including job 143/137; ordinary exit codes are preserved; unexpected POSIX signal death exits 128 + signal and names it on stderr. POSIX retains the final exact-read-to-signal interval without a pidfd; native Windows/Linux qualification remains pending.                                                                                       |
| stop                                                       | Stop supervised owners in the current canonical workspace without entering the request queue. Search every verified platform root, then verified prior roots from path-only locators in the stable home fallback, even after XDG/TMPDIR changes. Supervision requires that verified locator namespace. Preflight every owner before signalling; unusable records and canonical trust-root mismatches are reported and skipped without signalling; duplicate well-formed owner UUID/generations refuse with ownership retained. No matching run exits 1 (ESTOP_NO_RUN); duplicates exit 1 (ESTOP_AMBIGUOUS). Owner death requires an exclusively created completed guardian receipt bound to the current random generation, owner UUID, resource ticket, guardian/root birth identities and observed members; copied, stale and incomplete receipts refuse; without one, exit 1 reports inability to verify and observed PIDs, retaining ownership for a later verified Stop. |
