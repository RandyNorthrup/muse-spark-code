# Runtime and shim reference

Generated from `src/shared/featureCatalog.ts` by `node scripts/gen-reference.mjs`.
This catalog covers the M104L additions. Existing extension settings and commands remain in README.md.

| Command or editor route                                    | Behavior and qualification                                                                                                                                                                                                                                                                                                         |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| lsp                                                        | Stdio LSP frontend. One private broker per canonical workspace; UTF-16 full document sync; cancellable requests and standard initialization/method error codes; ordinary invoked completion items plus inline completion when negotiated.                                                                                          |
| lsp --workspace <directory>                                | Choose the workspace root. Defaults to the process working directory.                                                                                                                                                                                                                                                              |
| lsp --tab --trust-workspace                                | Opt into paid, invoked Tab completions. Uses M94 engine, output and context caps, private-file/ignore checks, cross-process daily ledger and paid-use consent. Deny or closing consent snoozes Tab for that editor connection until reconnect. Model API key stays in the OS store.                                                |
| lsp --tab-model <model> --tab-daily-budget-usd <amount>    | Select a supported M94 Tab model and daily USD budget from 0.05 to 50. Contributor models also require --allow-contributor-models.                                                                                                                                                                                                 |
| supervise <runtime arguments>                              | Run the installed runtime behind independent authenticated Stop control. Stop during guardian startup waits for the child and cleanup. POSIX guardian observes detached descendants and refuses unverified signals after a process-table failure; Windows uses the existing kill-on-close job launcher.                            |
| stop                                                       | Stop supervised owners in the current canonical workspace without entering the request queue.                                                                                                                                                                                                                                      |
| muse.stop / muse.usage / muse.help                         | LSP executeCommand routes for Stop, paid Tab usage and localized help. Stop and shutdown have two reserved request slots independent of ordinary saturation.                                                                                                                                                                       |
| muse.openPanel / muse.fix / muse.explain / muse.apply      | Controller integration contract. Production panel/review controller is absent from this base: panel, Fix and Explain return an explicit error; review code actions are not advertised. Injected conformance services prove version/hash checks, approval and cancellation after final policy admission before workspace/applyEdit. |
| Neovim: MuseLsp / MusePanel / MuseStop                     | Native LSP with invoked omnifunc items and negotiated inline requests, supervised companion launch and independent workspace Stop; CodeCompanion ACP uses supervision. Neovim 0.12.5 lacks a public fresh-inline invocation API.                                                                                                   |
| Emacs: muse-spark-lsp / muse-spark-panel / muse-spark-stop | Eglot LSP, supervised companion and independent workspace Stop; agent-shell ACP uses supervision. Native batch qualification is pending on this rig.                                                                                                                                                                               |
| Sublime: LSP-muse-spark / muse_panel / muse_stop           | Optional LSP package registration and supervised companion/independent workspace Stop. Native GUI qualification is pending.                                                                                                                                                                                                        |
| Qt Creator: generic language client / panel / stop         | Configure the installed LSP in the native generic language client; the Lua shim supplies supervised companion and independent Stop. Native GUI qualification is pending.                                                                                                                                                           |
| Zed: muse_spark language server / panel task / stop task   | Rust LSP extension source plus quoted shell tasks and supervised ACP. Offline SDK compilation and native edit-prediction qualification are pending.                                                                                                                                                                                |
