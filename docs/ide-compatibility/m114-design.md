# M114 design across editors and surfaces

All editors consume the same D94 token contract. These are binding and
certification rows, not upgrades to the existing host-support claims.
S's screenshots exercise the shared React panel with captured host colours;
they do not certify a native host that is absent from this branch.

The reviewed visual contract and archive manifest live in
[`test/harness/goldens`](../../test/harness/goldens/README.md). The original
[A before captures](../certification/m114-a-before/index.md) stay at their
read-only archive. S owns the integrated after captures; C/N/D supply equivalent
native, node and desktop evidence when those implementations join.

The font asset publication pin and feature-reference catalogue binding stay
with the integration lead. This base lacks `src/shared/featureCatalog.ts`;
F's exact pending rows are in [the font contract](../../design/fonts/README.md).
No command or setting is silently invented for an editor.
