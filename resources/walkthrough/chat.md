![The slash palette over the composer](chat.png)

**Type a message and press Enter.**

- `/` on an empty draft opens the palette: models, permission modes, thinking, skills, history and more.
- `@` mentions a file; select code in the editor and press `Alt+K` to mention the selection.
- `Shift+Tab` cycles the permission mode. **Bypass permissions** stays hidden until the setting allows it.
- The microphone dictates with your operating system's own recogniser, at no cost, on Windows and macOS.

**Muse Spark: Create AGENTS.md** writes the rules file Muse reads at the start of every conversation. The History dialog brings past conversations back.
